## papers/ 理论基座

| 文件 | 字节 | 说明 |
|---|---:|---|
| `ap2024143_341134453.pdf` | 1,026,309 | 熊瑛《维度情感模型研究现状综述》，《心理学进展》2024,14(3) DOI 10.12677/ap.2024.143158 |
| `Hatice Gunes2013.pdf` | 1,133,541 | Gunes & Schuller (2013), Image and Vision Computing 31(2):120–136, DOI 10.1016/j.imavis.2012.06.016 |

情绪动力学**以 PAD emotional state model 为基础**（Mehrabian & Russell 1974，源头 Osgood 1966）。
Gunes & Schuller 2013 提供**第 4/5 维**的出处：期望维（预测与准备能力的缺失程度）、强度维（偏离冷静状态的程度）。
