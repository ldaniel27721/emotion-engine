## 零、先说抽取：**公式不是「识别不到」，是要换个读法**

`pymupdf.get_text()` 按**阅读顺序**吐字符，而 PDF 里的数学公式是**按坐标摆放的字形**。
两者顺序不一致 → 公式被打散成碎片：

```
1946: 2        ← 这就是 G(TR(x,y/d,ω)) = Σ|C_i|²/|U|² 在 get_text() 眼里的样子
1947: 1
1948: 2
1950: ( ,
1952: m
1956: G TR x y d
1960: = ∑
```

**⚠️ 而且它不报错** —— 静默产出垃圾。这与 `§MEMORY` 里那条「静默失败」是同一族问题。

### 两个解决办法（本仓库都已实现）

| 办法 | 脚本 | 效果 |
|---|---|---|
| **① 按坐标重建** | `scripts/pdf-formula-extract.py` | 取 span 的 bbox，按 (y,x) 排序重排 → **表格类内容完全修复**（Table 1 从碎片变回整齐的 24 行） |
| **② 渲染成图直接读** | 同上（同时输出 PNG） | 公式**肉眼可读**（本文档的全部公式都来自这一步） |

```bash
py -3 scripts/pdf-formula-extract.py "papers/JOC2901-09.pdf" out/pages
# 每页产出 page-NN.txt（坐标重建）+ page-NN.png（150 dpi 渲染）
```

**⭐ 纯文本公式仍然会碎；渲染成图后，公式的上下标、分式、求和号**全部**正确可读。**

## 一、距离函数（Definition 3.9，PDF p.5 / 印 p.103）

满足以下四条者，称为 U 上的距离函数 `d(x, y/ω)`：

```
(1) d(x, y/ω) ≥ 0
(2) d(x, x/ω) = 0
(3) d(x, y/ω) = d(y, x/ω)
(4) d(x, y/ω) ≤ d(x, z/ω) + d(z, y/ω)
```

> 原文：*the elements constituting U is a vector with n-dimensions and **ω is the weight of dimensions**.*

**→ `ω` 就是维度权重向量；在 PAD 里 n = 3。**

## 二、一致性关系 TR（Theorem 3.2，PDF p.5）

```
                ⎧ 1     d(x, y/ω) ≤ r
TR(x, y/r, ω) = ⎨                            r ≥ 0
                ⎩ 0     others
```

**原文证明了**它同时满足**自反性**（`TR(x,x/r,ω)=1`）与**对称性**（`TR(x,y,r,ω)=TR(y,x,r,ω)`），
故 `TR` 是 U 上的一致性关系。

**⭐ 直观**：`TR` 问的是「两点的加权距离是否落在半径 r 之内」。
**r 越大，连通的点越多 → 粒越粗。**

## 三、粒度函数（PDF p.8 / 印 p.106）

```
                       m
                      Σ |C_i|²
                     i=1
G(TR(x, y/d, ω))  =  ──────────
                        |U|²
```

| 符号 | 含义 |
|---|---|
| `U` | 论域（在本文里即 PAD 空间 `P×A×D`） |
| `C = {C₁, C₂, …, C_m}` | 极大一致覆盖粒的集合（`∪C_i = U`，且 `C_i ∩ C_j ≠ ∅`） |
| `Σ\|C_i\|²` | 各粒大小的平方和 |
| `\|U\|²` | 论域大小（元素数）的平方 |

### Theorem 5.2（单调性）

```
d₁ ≤ d₂  ⟺  G(TR(x,y/d₁,ω)) ≤ G(TR(x,y/d₂,ω))          ∀ d₁, d₂ ∈ [0, ∞)
```

**⭐ 意义**：**半径 d 越大 → 粒度 G 越大**（粒越粗、越笼统）。二者**一一对应、可互推**。
**这给了「调整粒的粗细」一个严格可控的旋钮。**

## 四、情绪模糊集与上下近似（PDF p.11 / 印 p.109）

### 4.1 求 ΔU

```
ΔU(x) = sup{ 1 − d(x, y/ω) | y ∈ ΔU }
```

### 4.2 上下近似隶属函数

```
下近似：ΔU‾(x) = sup{ ΔU(y) | y ∈ Md(x) }
上近似：ΔU_(x) = inf{ ΔU(y) | y ∈ Md(x) }
```

### 4.3 确定性与似然性

```
确定性 Bel(C) = min{ ΔU(x) }
似然性 PI(C)  = max{ ΔU(x) }
```

**⭐ 这两个量就是「某情绪到底有多属于这个粒」的**定量答案** —— 正是复合情绪需要的。**

## 五、例 5.1 的实际参数（PDF p.8 与 p.11）

```
d₁ = 0.15          ← 半径
ω  = [1, 1, 1]     ← 维度权重（三维均匀）
```

**并且给出了一个真实的覆盖粒：**

```
C₁ : { admiration, grateful, happy, hope, delight, like, love }

Bel(C₁) = 0.84
PI(C₁)  = 0.9832
ΔU is close to C₁ (points marked with '*', numbered 1, 10, 11, 13, 14, 15, 16)
```

> 编号 1/10/11/13/14/15/16 与 Table 1 的对应：
> 1=admiration · 10=grateful · 11=happy · 13=hope · 14=delight · 15=like · 16=love —— **正是 C₁ 的七个成员。**

### ⭐⭐ 这个粒**横跨两个象限**

| 成员 | 所属象限 |
|---|---|
| admiration · grateful · hope · like | **Dependent** (+,+,−) |
| happy · delight · love | **Exuberant** (+,+,+) |

**→ 一个「一致覆盖粒」可以跨象限。** 这正是 Xu 那套「一词一象限」做不到、
而大肥鱼骨架里那 **173 个正负混杂的词**需要的能力。
**「复合情绪」在数学上就是「一个粒横跨多个象限」。**

## 六、完整公式一览（便于实现）

```
距离        d(x, y/ω)                    满足 4 条公理；ω = 维度权重
一致性      TR(x, y/r, ω) = 1 if d(x,y/ω) ≤ r else 0
覆盖粒      C_i  = 由 TR 连通的极大点集；∪C_i = U，C_i ∩ C_j ≠ ∅
粒度        G(TR(x,y/d,ω)) = Σ_{i=1..m} |C_i|² / |U|²
单调性      d₁ ≤ d₂ ⟺ G(d₁) ≤ G(d₂)
模糊集      ΔU(x) = sup{ 1 − d(x, y/ω) | y ∈ ΔU }
下近似      ΔU‾(x) = sup{ ΔU(y) | y ∈ Md(x) }
上近似      ΔU_(x) = inf{ ΔU(y) | y ∈ Md(x) }
确定性      Bel(C) = min{ ΔU(x) }
似然性      PI(C)  = max{ ΔU(x) }
例参数      d = 0.15，ω = [1,1,1]
```

## 七、与「情绪动力学」的接口

> ⚠️ 以下**全部是助手推导**，不是论文主张，也**不是设定者的裁定**。

| 论文 | 情绪动力学 |
|---|---|
| `d(x, y/ω)` 是 PAD 空间里的**加权距离** | 「强度 = 到原点的**径向距离**」用的正是同一族度量 |
| `TR` 以半径 r 划「连通与否」 | 「球面」划「极致与否」—— 都是**半径阈值** |
| `G = Σ\|C_i\|²/\|U\|²` 衡量**粒的粗细** | 可用来衡量「一组情绪被归得多粗」 |
| 粒可**跨象限** | 「二、复合情绪」类正需要这个 |
| `Bel` / `PI` 给**隶属的确定性与似然性** | 正好回答「一个词到底算不算这一类」 |

**⭐ 一句话**：**Xu 给了「一个词怎么落到一点」，Chen 给了「一组点怎么被覆盖成一类，以及这个类有多确定」。**
**两者缺一不可 —— 前者是坐标，后者是分类。**
