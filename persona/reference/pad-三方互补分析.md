## 二、C（2106）的三项新增

### 2.1 情绪转移公式（Equation 4）

```
V_r = V_i + P_V · ΔV
A_r = A_i + P_A · ΔA                                    (4)
D_r = D_i + P_D · ΔD

E_r = F_c( V_r , A_r , D_r )
```

- `V_i, A_i, D_i` = **前一个情绪**的 VAD 向量
- `P_V, P_A, P_D` = **人格权重**（见 2.2）
- `ΔV, ΔA, ΔD` = 由**上下文**算出的变化量
- `F_c` = 线性层 → 离散情绪类别的概率分布

**⭐ 意义**：状态是**相对前一状态**定义的，**不存在"回到原点"这一步** ——
这正是设定者裁定「角色从原点出发后由情绪记忆引导，没有回到原点这回事」的数学形式。

### 2.2 人格 → VAD 权重（Equation 2，Mehrabian 1996a）

```
P_V = 0.21E + 0.59A + 0.19N
P_A = 0.15O + 0.30A − 0.57N
P_D = 0.25O + 0.17C + 0.60E − 0.32A
```

**⭐ 三条各由不同特质支配：**

| 权重 | 依赖 | 主导项 | 方向 |
|---|---|---|---|
| `P_V` | E, A, N | **A 宜人性 +0.59** | 宜人性越强 → 愉悦权重越大 |
| `P_A` | O, A, N | **N 神经质 −0.57** | 神经质越强 → 唤醒权重越**小** |
| `P_D` | O, C, E, A | **E 外向性 +0.60** | 外向性越强 → 支配权重越大 |

**注意：`P_V` 不含 O/C，`P_A` 不含 C/E，`P_D` 不含 N** ——
**人格不是整体缩放，而是三个权重各被不同特质支配。**

### 2.3 六基础情绪的 VAD 坐标（Table 1，源自 Russell & Mehrabian 1977）

```
Anger      (-0.51,  0.59,  0.25)
Disgust    (-0.60,  0.35,  0.11)
Fear       (-0.62,  0.82, -0.43)
Joy        ( 0.81,  0.51,  0.46)
Neutral    ( 0.00,  0.00,  0.00)      ← 原点
Sadness    (-0.63, -0.27, -0.33)
Surprise   ( 0.40,  0.67, -0.13)
```

原文：*"As for the utterances with no explicit emotion, we use the **Neutral with (0.00, 0.00, 0.00)**."*

**⭐⭐ 这一条直接回答了此前挂在 #23/#25 的问题：「三、中性情绪」与「底情绪 = 原点」是什么关系 ——**
**原点就是中性。无情绪 = (0,0,0)。**

## 四、🔴 三方拼起来之后暴露的最大缺口：**转移无界 vs 球面有界**

| | 说法 |
|---|---|
| **设定者** | 「**球面的表面 = 强度的极致**」→ **情绪状态有界**，落在半径 1 的球内 |
| **C · Eq (4)** | `E_r = E_i + P·ΔE` → **每次在上一个状态上加一个增量，没有任何回归力** |

**⭐⭐ 这是一个真缺口，不是措辞问题：**

- `E_r = E_i + P·ΔE` 是**无约束**的随机游走（带漂移）。
  只要 `ΔE` 长期偏某一个方向，状态会**无限漂出球外**。
- 设定的球面是**硬边界**。

**三种可能的缝合方式：**

| | 做法 | 代价 |
|---|---|---|
| **(a)** | **每步归一化到球面**（`E ← E / ‖E‖`） | 简单，但会**抹掉强度信息**（所有状态都被拉到球面） |
| **(b)** | **限幅**（`‖E‖ ≤ 1`，超过则截断到球面） | 保留强度，但状态会**贴在球面上不动**，失去"离原点远近"的区分 |
| **(c)** | **加一个恒向原点的弱回复力**（`E_r = E_i + P·ΔE − k·E_i`） | 有界且保留强度分布，**但「回复力」与「没有回到原点这回事」的裁定存在张力** —— 需要说清是"不归零"还是"不衰减" |

**⭐ 助手不知道设定者要哪一种。** 而且 (c) 触到了一条已裁定的边界：
「**没有回到原点这回事（不存在复位或衰减归零）**」——
**若加回复力，是否违背这条？还是说那条只禁止"归零"、不禁止"向原点收敛但不达到"？**

**→ 这是本次最需要裁定的一条。**

## 六、三方合起来能做什么（供裁定参考）

```
① 用 C 的 Neutral=(0,0,0) 定原点，用 B 的 24 点 + C 的 6 点做锚
② 用 A 的 μ = λ·γ 把 605 个词各自定位（λ 待定 → 问题 2）
③ 用 B 的覆盖粒把落在两型之间的词归成一类（→ 问题 6）
④ 用 C 的 Eq(2) 把大肥鱼的人格变成 P_V/P_A/P_D 三个权重（→ 问题 7、8）
⑤ 用 C 的 Eq(4) 让情绪逐轮转移（→ 问题 1 决定它有没有边界）
```

**⭐ 这五步走完，「每个情绪应到什么位置」以及「它下一步会去哪」就都有答案了。**
**目前卡在第 ① 之外的 ② 与 ①（λ 与边界机制）。**
