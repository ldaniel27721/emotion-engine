## 一、⭐ 习惯化那篇（重点）

**完整出处【原文】**：
> A Simple Habituation Mechanism for Perceptual User Interfaces
> O. Déniz, J. Lorenzo, M. Hernández
> Universidad de Las Palmas de Gran Canaria
> *Inteligencia Artificial, Revista Iberoamericana de Inteligencia Artificial. No. 23 (2004), pp. 87-96. ISSN: 1137-3601.*

### 1.1 它的机制（公式逐字）

**关键认知：这篇论文自己并没有提出新的习惯化公式。它借用 Stanley (1976) 的一阶常微分方程，自己贡献的是"如何从频谱图里造一个二值刺激信号 S(t)"。** 这一点很重要 —— 所以别指望它给 n 次重复的离散递推式。

**【原文】正文第 2 页（Eq. 1）—— 核心习惯化方程逐字**：

```
τ dy(t)/dt = α(y₀ − y(t)) − S(t)          (1)
```

**【原文】紧接着的定义逐字**：
> "where y₀ is the normal, initial value of y, S(t) represents the external stimulation, τ is a time constant that governs the rate of habituation and α regulates the rate of recovery. Equation (1) ensures that the synaptic efficacy decreases when the input signal S(t) increases and returns to its maximum y₀ in the absence of an input signal."

**【原文】正文第 2 页（Eq. 2 & 3）—— 长时程习惯化扩展（Wang 1995），逐字**：

```
τ dy(t)/dt = αz(t)(y₀ − y(t)) − βy(t)S(t)     (2)
dz(t)/dt   = γz(t)(z(t) − l)S(t)              (3)
```

**【原文】**：
> "where α, y₀ and γ have the same meaning than in (1), β regulates the habituation and z(t) decreases monotonically with each activation of the external stimulation S(t), and models the long-term habituation. Due to this effect of z(t) after a large number of activations, the recovery rate is slower."

**答案是"减法"**：`− S(t)` 就是一个减性驱动项，再叠加一个把它拉回 y₀ 的泄漏项。**不是乘法，也不是单纯的指数衰减。**

**【原文】正文第 3 页（Eq. 4）——频谱图定义，逐字**：

```
Φ(t, f) = | ∫_{-inf}^{inf} x(τ)e^{(t−τ)²/T²} e^{−j2πfτ} dτ |²     (4)
```

**【原文】正文第 3 页（Eq. 5–7）——它自己真正的贡献：二值刺激信号 A，逐字**：

```
v_i = Σ_{j=1}^{l} (m_{i,j} − μ_i)² / l ,   i = 1, …, N      (5)

μ_i = Σ_{j=1}^{l} m_{i,j} / l ,            i = 1, …, N      (6)

A = { 1   if  |v| > T
    { 0   if  |v| ≤ T                                       (7)
```

**【原文】关于 A 的语义逐字**：
> "A value of 1 for the auxiliary signal will mean that there are changes in the input signal, while a value of 0 indicates that the input signal is monotonous."

**【原文】"习惯化"的定性定义逐字（结论第 6 节）**：
> "Habituation is the decrease in the strength of an agent's response when it receives repetitive stimuli."

**⚠️ 关键警告：论文报告的参数值看起来是错的 / 不可直接采信。** 我渲染了 Fig.3b、Fig.4d、Fig.6f 逐图核对：

- **Fig.3 caption 写 `τ = 5, α = 1`，但 α = 1 在 Eq.(1) 里意味着恢复"瞬时完成"**（见 1.4 的泄漏时间常数推导 τ/α = 5 s），habituation level 应该被钉在 y₀ 附近几乎不动。图 3b 确实基本贴着 1，只在受到刺激时向下打尖刺。**【推断】**所以 α = 1 时 Fig.3 测的其实不是"习惯化累积"，而是"刺激信号 S(t) 本身"。
- **Fig.4d 与 Fig.6f 的 caption 都是 `τ = 1, α = 0.002`**。但 α = 0.002 推出恢复时间常数 τ/α = **500 秒**，而两张图的横轴只有 **1.4 秒**，habituation level 在约 0.1–0.15 s 内就从 0 恢复到 1。**两者相差约 3 个数量级，参数与图自相矛盾。**
- **【推断，可直接用于工程标定】**从图上实测：被刺激打到 0 之后，恢复到 ~0.9 需要约 **0.1–0.15 秒**；即实际泄漏时间常数 τ_eff ≈ **0.05–0.1 s**。音频域 22050 Hz / l=5120、帧间重叠 l−1 ⇒ 每个离散仿真步 ≈ 5120/22050 ≈ **0.23 s**。所以实际有效时间常数约 **0.2–0.5 个离散步**。
- **【推断】**视觉域：记帧率 25–30 fps ⇒ 每步 33–40 ms；τ_eff ≈ 0.05–0.1 s ⇒ 约 **1.5–3 步**。

**→ 结论：有明确的时间常数符号 τ，有明确语义（τ 控习惯化速率、α 控恢复速率），但报告的具体数值不可靠，别直接抄。只有形式可抄。**

### 1.3 恢复机制

**【原文】恢复是方程自带的，没有单独的 dishabituation 项。** 逐字：
> "Equation (1) ensures that the synaptic efficacy decreases when the input signal S(t) increases and returns to its maximum y₀ in the absence of an input signal."

即令 S(t) = 0 解 Eq.(1)：

**【推断】**
```
τ dy/dt = α(y₀ − y)   ⇒   y(t) = y₀ − (y₀ − y_start)·e^(−αt/τ)
恢复时间常数 = τ/α
半恢复时间 = (τ/α)·ln 2 ≈ 0.693·τ/α
```

**【原文】论文里唯一提到"dishabituation"一词的地方是参考文献 [2] 的标题**（Castellucci, Pinsker, Kupfermann, Kandel, "Neuronal mechanisms of habituation and dishabituation of the gill-withdrawal reflex in Aplysia", *Science*, 167:1745–1748, 1970），正文并没有建模 dishabituation。**它也完全没有"重新计数 n 的复位"这种概念 —— 恢复是连续泄漏，不是计数复位。**

**【原文】长时程习惯化让恢复变慢（Eq. 2/3）逐字**：
> "Due to this effect of z(t) after a large number of activations, the recovery rate is slower."

**【推断】这是对我们 h(n) 最重要的一条结构启示**：Wang 的 Eq.(2)(3) 说的就是"重复次数越多 → 恢复越慢"，即**习惯化累积会改变恢复速率本身**。这才是长时程习惯化的正确形态。

### 1.4 ⭐ 与我们的 ρ / h(n) 的关系

#### (a) 逐项映射表

| 我们的符号 | Stanley/Déniz 对应 | 关系 |
|---|---|---|
| `h(n) = α^(n−1)`，n = 同一刺激第几轮 | Eq.(1) 的泄漏项 `dy/dt = (α/τ)(y₀ − y)` 的离散化 | **数学同构**：一阶 AR(1) 泄漏积分器 |
| `ρ` 自发回落（目标 μ） | Eq.(1) 的 `α(y₀ − y(t))/τ`，**同一个泄漏项** | **是同一个机制**，见 (c) |
| 触发习惯化的"重复刺激" | `S(t)`，由式 (7) 的 A 二值化给出 | 我们缺这个"是否单调"的判别器 |
| 恢复 / dishabituation | S(t) = 0 时的指数回归，时间常数 τ/α | 我们目前没有 |

#### (b) 形式同构的**逐字证明**【推断，但数学是确定的】

把 Eq.(1) 用前向欧拉、步长 Δt 离散化：

```
τ·(y_t − y_{t−1})/Δt = α(y₀ − y_{t−1}) − S_t
⇒ y_t = y_{t−1} + (αΔt/τ)(y₀ − y_{t−1}) − (Δt/τ)S_t
⇒ y_t = (1 − αΔt/τ)·y_{t−1} + (αΔt/τ)·y₀ − (Δt/τ)S_t
```

令 `λ = αΔt/τ`：

```
y_t = y₀ + λ(y_{t−1} − y₀) − (Δt/τ)·S_t
```

**这就是我们 A2 里的 `ρ(E_{t−1} − μ)` 项，逐字同构。而且它的脉冲响应正是几何衰减：**

```
y_t − y₀ ∝ λ^t
```

**⇒ 我们的 `h(n) = α^(n−1)` 就是 Stanley 泄漏项的脉冲响应，我们的 α 就是 `λ = αΔt/τ`。这不是"类似"，是同一个东西。**

#### (c) ⭐ 对我们的假设"ρ 是自发回落，h(n) 是重复习惯化（两个正交机制）"的裁决

**【原文】支持的部分**：论文明确把两件事分开命名、分开给参数 ——
> "τ is a time constant that governs the rate of habituation and α regulates the rate of recovery."

**⇒ 论文支持"习惯化"与"恢复"是两个可分别调节的量。**

**【原文】反对的部分（我们的假设被修正）**：它们**不是两个机制，也不是正交的**。它们是**同一个一阶 ODE 里的两个参数**，被锁在同一个时间常数上：

**【推断】**
```
习惯化时间常数 = τ/α        （刺激存在时的下沉速度）
恢复时间常数   = τ/α        （刺激消失时的回升速度）
```

**两者共用 τ/α —— 数学上无法独立调节下沉与回升速度**，只能通过调 τ 和 α 的相对比例整体缩放时间轴。

**⭐ 所以对我们是"部分支持"**：
- ✅ 支持：区分"习惯化"与"恢复"两种行为，是文献惯例。
- ❌ 反对：把 `ρ` 和 `h(n)` 当成**两个独立旋钮**去分别调参，在 Stanley 框架下是**过参数化的**。要么承认我们引入了超出文献的二阶结构（那就得说明理由），要么把两者收缩到一个时间常数上校验自洽性。

**【推断】可操作的自洽性检验**：我们的 ρ 给半衰期 9.1 轮 ⇒ ρ = 0.5^(1/9.1) ≈ 0.9269。若 h(n) 的 α 也走同一条泄漏路径，则它应取同一个值 α ≈ 0.927 —— 而我们的工程取值 α ≈ 0.93–0.96 与它高度重叠。**这暗示两处参数其实在描述同一个时间常数，可以考虑合并为单一参数。**

#### (d) 我们模型缺的一块（这篇最有价值的工程启示）

**【原文】**式 (7) 的核心是判定"刺激是否单调"：`A = 1`（有变化）还是 `A = 0`（单调）。第 5 节的实装描述逐字：
> "When the image does not show significant changes or repetitive movements are present for a while the habituation signal grows. When it grows larger than a threshold, an inhibition signal is sent to the attention module of the robot [6], which then changes its focus of attention. The head pan and tilt movements produce changes in the images, though it was observed that they are not periodic, and so habituation does not grow."

**【推断】对照我们的 h(n) = α^(n−1)**：

| | Stanley/Déniz | 我们当前 |
|---|---|---|
| 刺激持续单调时 | S=0 ⇒ 习惯化状态**升到饱和**（不再响应，但没错过新信息） | h 单调递减到 0 |
| 刺激一变化 | S=1 ⇒ 习惯化状态**被打回 0**，重新敏感 | **没有任何复位**：n 继续加，第 20 轮的响应和第 5 轮一样小 |
| 数学形态 | 有界（饱和）的泄漏积分器 | 无界衰减 |

**【推断，最可操作的改造】** 把"轮数 n"换成一个**由新颖性驱动的连续习惯化状态**：

```
h_t = clamp( h_{t−1} + η·(1 − h_{t−1}) , … )     当第 t 轮刺激被判定为"与近期重复"
h_t = h_{t−1} − κ·(h_{t−1} − h_min)              当第 t 轮判定为"新颖"
```

并**保留一个跟 Stanley 一样的"新颖性判别器"**（对话里可直接用我们的 A1/A3 输出：`r` 偏离 μ 的幅度 / precision 变化作 S(t)），判为新颖时把 h 打回低值 —— 这才是"恢复 / 去习惯化"，且能解释"角色对第 50 次同样调侃不再有反应，但换个人换个梗立刻又有反应"。当前的 `α^(n−1)` 做不到这一点。

#### (e) 时间尺度上的硬限制 —— 不能直接搬数值

**【原文】**实验里的 S(t) 每 `l` 个采样出一个值（音频 l=5120 @22050 Hz ≈ **0.23 s/步**；视觉 128 samples @ 25–30 fps ≈ **4–5 s**，但中心矩每帧更新）。

**【推断】我们的 n 是一轮对话（秒~分钟级），他们的时间常数是亚秒级。数量级差 2–4 个数量级，α 的数值不可迁移，只有函数形式和"饱和 vs 无界"的结构可迁移。**

## 三、applsci-15-04960

**【原文】完整出处**：
> Wang, X.; Zhang, L. **Emotional Dynamics in Social Interactions: A Multi-Strategy Synergy Model.** *Appl. Sci.* **2025**, 15, 4960. https://doi.org/10.3390/app15094960
> 中国计量大学（Communication University of Zhejiang）媒体工程学院；浙江影视媒体技术重点实验室。收稿 2025-03-31 / 录用 2025-04-28 / 发表 2025-04-30。

### 主题与方法
**【原文】**（Abstract 逐字）：
> "This paper presents a mathematical model for analyzing emotional dynamics in social interactions, considering strategic induction, group feedback, and natural emotional decay. Stability analysis shows that without control strategies, an emotional system has a unique stable equilibrium."

方法：**非线性常微分方程组 + 局部/全局稳定性证明（Lyapunov）+ Sobol 全局敏感性分析 + 通勤者两周真实案例拟合**。Python 3.9 + SciPy + SALib，`solve_ivp`，四阶 Runge–Kutta。

### ⭐ 可复用公式（逐字，全部从渲染后的 PDF 文本直接抄出）

**核心情绪演化方程（Eq. 5，第 6 页）**：
```
dE/dt = αS(t) + βG(t)(1 − E(t)) − γE(t)          (5)
```
**【原文】各项语义逐字**：
> "where αS(t) indicates how individuals utilize specific strategies to actively shape their emotional states. The term βG(t)(1 − E(t)) shows that the strength of group feedback decreases as the current emotional level increases, thus avoiding emotional saturation. The component **−γE(t) represents the natural tendency of emotions to diminish over time, reflecting the gradual reduction in emotional intensity in the absence of external influences.**"

**策略合成（第 4 页）**：
```
S(t) = w1·S1(t) + w2·S2(t) + w3·S3(t)

S1(t) = μ · (1 − E(t)/E_high)^+                      (1)
S2(t) = ν · ( sin(2πt/T) )^+                         (2)   ← 唯一产生振荡的项
S3(t) = ξ · G(t) · (1 − E(t))                        (3)

G(t) = κ(1 − E(t)) + λ(S(t) − E(t))^+                (4)
```
**【原文】关于 S2 的振荡逐字**：
> "This form can be customized and does not necessarily require the use of periodic functions." / "The strategy S2 initially caused sharp increases, but later exhibited an oscillatory behavior."

**均衡点（Eq. 7/8，第 7 页）**：
```
βκE² − (2βκ + γ)E + βκ = 0                            (6)
E*∓ = [ (2βκ + γ) ± √Δ ] / (2βκ),  Δ = γ² + 4βκγ      (7)
E* = [ (2βκ + γ) − √(γ(γ + 4βκ)) ] / (2βκ) ∈ (0,1)    (8)
```
**【原文】策略全失效时的退化系统（Eq. 9）**：
```
dE/dt = βκ(1 − E)² − γE
G(t) = κ(1 − E)
S(t) = 0
```
**【原文】全局稳定性（Theorem 2 + Eq. 12）**：Lyapunov `V(E) = ½(E − E*)²`，沿轨迹
```
dV/dt = −(E − E*)²[ βκ(2 − E − E*) + γ ]  ≤ 0
```

### 对我们的用处：⭐⭐⭐ 这是四篇里对 ρ 最直接的一篇

**【推断】把他们的 γ 换算成半衰期**（他们的 E 是相对于 0 的绝对值衰减，我们的是向 μ 回落，但衰减时间常数可直接类比）：

```
E(t) ∝ e^(−γt) ⇒ t_half = ln2 / γ

工作日 γ_w = 0.3 /day  ⇒ t_half = 2.31 天 = 55.4 小时
周末   γ_r = 1.0 /day  ⇒ t_half = 0.693 天 = 16.6 小时
基准   γ   = 0.3       ⇒ t_half = 2.31 天
```

**【推断】**若把"一轮对话 ≈ 15 分钟"（陪伴型角色的常见单轮间隔），则 2.31 天 ≈ **222 轮**，远超我们的 9.1 轮。**所以这篇不支持我们的 9.1 轮，反而说明 9.1 轮偏快。** 但注意这是**情绪水平本身**的衰减，而我们的 ρ 是**单次情绪冲动**的回落，两者不是同一对象 —— 这一点必须诚实标注。

**【推断】可借鉴的建模手法（比参数更有价值）**：
1. **`−γE(t)` 是"向 0 衰减"，我们的 `ρ(E−μ)` 是"向 μ 回落"** → 我们的形式更正确（保留了 baseline 不动点），可以把这当作我们设计的辩护。
2. **把 γ 拆成情境相关的分段常数**（工作日 γ_w / 周末 γ_r，差 3.3 倍）→ 直接可迁移：我们的 ρ 可以做成**依情境切换的 ρ_s**（例如"角色在忙 / 独处 / 群聊"），这比单一 ρ 更贴合真实数据。
3. **Sobol 敏感性排序证明 γ 支配一切（SF 0.677 vs 其余 < 0.14）** → 工程含义很硬：**调参精力应该全部压在 ρ 上，其他增益都是二阶的**。这是我们当前资源分配的直接依据。
4. **`βG(t)(1−E(t))` 的 `(1−E)` 饱和因子** → 情绪不会饱和溢出，正好对应我们的"对数封顶 `f(r) = 1−(1+r)^(−k)`"，给我们的封顶设计提供了一个同构的文献参照（同样是"随水平升高增益递减"）。
5. ⚠️ **该模型是确定性 ODE、无随机项**，且其"真实案例"是构造的情境而非拟合实测个体数据（"Time units were measured in days"但数据来源未给出个体级拟合指标）—— **不要把它当成实证校准来源，它本质是理论模型 + 数值仿真。**

### 对我们的用处：⭐⭐ 给 ρ 一个实证数量级

**【推断】把自转移概率读成 ρ**（离散状态的保持概率在形式上就是 AR(1) 的持久性）：

```
ρ ≈ p_ii  ⇒  离散半衰期 = ln 0.5 / ln ρ

State 0: ρ = 0.875  ⇒ t_half = ln0.5/ln0.875 = 5.19 步
State 2: ρ = 0.805  ⇒ t_half = ln0.5/ln0.805 = 3.19 步

```

**【推断】这是本次四篇里唯一一个"实测的、人类情绪状态的保持系数"，给出 ρ ≈ 0.80–0.88（正性态）、0.45（负性态）。** 对我们的意义：

1. **我们的 ρ = 0.9269（半衰期 9.1 轮）比实测的正性态持久性（最大 0.875）更"粘"。** 也就是说我们的设定偏保守/偏粘，不是偏快 —— 这与第三节 applsci 给我的印象（9.1 轮偏快）方向相反。**两篇给出的是不同量纲的对象，所以结论冲突并不奇怪，但它提示 9.1 轮这个数字落在 3.2–5.2 步（HMM）与 222 轮（applsci）之间，两个都不精确支持它。**
2. **负性态 ρ 极低（0.451）** ⇒ 负性情绪天然是短促的，稳态占比只有 6.2%。**【推断】工程含义：我们不该让角色的负面情绪像正面一样持久；`ρ` 应当按效价（valence）分段而不是全局一个值。** 这是本次分析里一个比较明确、可落地的设计改动。
3. **稳态 86.3% 为正性** ⇒ 陪伴型角色的情绪基线应显著偏正（对应我们的 μ），这给 μ 的"方向"分量提供了用户侧依据。

### ⚠️ 严重的方法学限制（引用前必读）
**【原文】逐字**：
> "Despite the cross-sectional design, the HMM framework enabled inference of latent affective states..."
> "Unlike longitudinal research that follows individual trajectories, our approach applies HMMs to single-occasion, cross-sectional responses to infer population-level emotional configurations and their relative stability."
> "Dwell time was calculated as the expected number of steps in which participants' data remained in a given state before transitioning to another."

**【推断】**这是**关键漏洞**：数据是**横截面**（每人一次），不存在真实时间序列。所谓"转移矩阵"和"3.4 步停留时间"是从**群体分布**里估出来的统计量，"一步"**不是真实的时间步**，而是 HMM 状态空间的抽象索引。**所以 ρ ≈ 0.875 不能当作"每轮对话的保持概率"来直接使用。**
**【推断】正确的用法**：只把它当作**一个合理的量级参照**（人类的情绪状态保持概率大致在 0.45–0.88 区间），而**不是**为 ρ 提供校准值。

## 六、⭐ 对我们 A2 动力学的启示

我们的方程：`E_t = μ + ρ(E_{t−1} − μ) + g·h(n)·ΔE`，其中 `ρ` 半衰期 9.1 轮（无依据）、`h(n) = α^(n−1)`（α ≈ 0.93–0.96，来自 VR 风险实验）。

### 6.1 能不能给 ρ 提供依据？—— **能，但只能给量级，不能给精确值**

| 来源 | 给出的量 | 换算到 ρ | 评估 |
|---|---|---|---|
| applsci Eq.(5) `−γE(t)` | γ = 0.3 **/天**（工作日），1.0 /天（周末） | t_half = 2.31 天 / 0.69 天 | ⭐ **形式最对（明确的自然衰减项 + 敏感性证明它支配一切），但对象是"情绪水平"而非"单次冲动"，时间单位是天不是轮** |
| Sci Rep HMM | p_00 = 0.875, p_22 = 0.805, p_11 = 0.451 | ρ = 0.45 / 0.805 / 0.875 | ⭐ **唯一人类实测的保持系数，但来自横截面数据的群体级推断，"一步"无物理含义** |

**【推断】诚实结论**：**没有任何一篇给出可"设 ρ = X"的直接依据。** 我们能做到的是：
1. 把 9.1 轮（ρ = 0.9269）与 HMM 的正性态持久性 τ_half ≈ 3.2–5.2 步对照，说明我们的取值**偏粘**，属于**在实测区间之外但方向不荒谬**的一侧。
2. **把 ρ 从单值改为按效价分段**（Sci Rep 强证据：正性态 ρ≈0.80–0.88、负性态 ρ≈0.45）。这是本次分析里**依据最扎实、最该做**的改动。
3. **把 ρ 从单值改为按情境分段**（applsci 强证据：γ_w = 0.3 vs γ_r = 1，差 3.3 倍）。次扎实。
4. 在代码注释里把 9.1 轮标注为"工程取值，量级由 Sci Rep (2025) 与 Appl. Sci. (2025) 交叉约束，无直接文献依据" ——**保持诚实，这比伪造一个引用好**。

### 6.2 能不能给 α 提供依据？—— **能，而且这篇 Habituation 论文给的是"形式依据"而非"数值依据"**

1. **形式依据（最强）**：`h(n) = α^(n−1)` **不是一个拍脑袋的建模，它是一阶泄漏积分器（Stanley 1976 / Déniz 2004 Eq.1）的脉冲响应。** 这一点可以写进代码注释直接引用：
   > `τ dy/dt = α(y₀ − y) − S(t)` 的离散解给出 `y_t − y₀ ∝ (1 − αΔt/τ)^t`
   即 **我们的 h(n) 就是这个机制在"刺激恒为重复"假设下的特例**。
2. **数值依据（弱）**：Habituation 论文的 τ、α 是**亚秒级**（τ_eff ≈ 0.05–0.1 s），我们的 n 是**轮次级**，**差 2–4 个数量级，数值不可迁移**。而且它报告的值本身自相矛盾（见 1.2 的 ⚠️），**不能抄。**
3. **自洽性交叉验证**：ρ = 0.9269 与 α = 0.93–0.96 几乎重合 ——**【推断】说明这两个旋钮在数值上其实在描述同一个时间常数。** 要么合并成单一参数，要么在文档中明确说明为何需要两个。

### 6.3 ⭐ 最该做的三处结构性改动

**改动 1 —— 给 h(n) 加"新颖性复位"（最重要）**
当前 `α^(n−1)` 无界递减，第 20 轮与第 5 轮响应一样弱。文献机制是"**刺激一变化就把习惯化打回 0**"（Déniz Eq.7 的 S(t) 判别器）。可直接用我们已有的 A1/A3 输出做判别器（偏离 μ 的幅度 / precision 变化），判为新颖时把 h 复位。工程上这是"角色对第 50 次同样的调侃无感，但换个梗立刻有反应"。

**改动 2 —— 按效价/情境分段 ρ**
Sci Rep：正性 ρ ≈ 0.80–0.88、负性 ρ ≈ 0.45。applsci：情境差 3.3 倍。合成一个 `ρ_valence × ρ_context` 或一张查表。

**改动 3 —— 承认 ρ 与 α 同源，做自洽性校验**
在测试里断言 `|1 − ln(0.5)/ln(ρ) 的对应 α 与 h(n) 实际 α|` 在容差内，避免两个参数各自漂移。

### 6.4 调参优先级（applsci Sobol 的直接推论）
**【推断】**γ（≈ 我们的 ρ）一阶效应 **0.677**，其余全部 ≤ 0.139。**⇒ 调参预算应压倒性地投给 ρ，g 和 α 是二阶项。** 我们现在花在 α 上的精力应当部分转移到 ρ 的情境/效价分段上。

### 6.5 不要做的事（避免过度外推）
- ❌ 不要把 `f(r) = 1−(1+r)^(−k)` 的对数封顶说成"有文献依据" —— 最接近的是 applsci 的 `(1 − E(t))` 饱和因子，**只是同构，不是来源**。
