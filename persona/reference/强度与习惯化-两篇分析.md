## 一、两篇各讲什么（各 3 句）

### [P1] 情绪强度 → 调节策略选择 & 主观减效（preprint，未经同行评审）

**【原文】**
1. 用**经验取样（ESM）**研究了"不愉快情绪的强度"是否预测**摆脱型（disengagement）**与**投入型（engagement）**情绪调节策略的选择，以及这些策略对情绪的**主观衰减效果**（第 4 页摘要）。
2. 样本为社区夫妇样本 **183 人 / 28 天 / 每天 3 次提示（共 85 个 prompt 索引）**，2020-04 至 2021-01 采数（第 4、12、13 页）；采用多层 logistic（选策略）与多层线性（衰减量）模型，强度拆成 **within-person**（个体内偏离）与 **between-person**（个体均值）两层（第 18–19 页）。
3. 核心结论：**大部分摆脱型策略的选择并不被强度显著预测**（只有 substance use 被更高的瞬时强度正向预测）；**接受（acceptance）在更低的瞬时强度下更常被选**；而**投入型策略在低强度下减效更好**（交互 b = −0.445，p < .001），摆脱型策略的减效**不随强度变化**——结果"大体上与近期理论相悖，而效应部分与理论相符"（第 4、27、34 页）。

### [P2] 情绪习惯化 → 冒险升级（已发表，经过同行评审）

**【原文】**
1. 用 **VR 高空木板（Richie's Plank Experience）** 把"物理风险"搬进实验室，共三个实验：**主实验 N=160（分析 N=159）、验证实验 N=35、控制实验 N=30**（第 1、2 页）。
2. 每 trial 让被试口头报告 **anxiety / excitement（0–10）**，每 trial 记录走到木板上的**最远距离（0–5.525 m）**作为风险量；主实验 15 个 trial，被试每次都从 0 点重新开始（第 2、4 页）。
3. 核心结论：**重复暴露后风险升级、情绪习惯化**；**习惯化速度（而非基线情绪、也非特质焦虑）预测风险升级速度**——anxiety 习惯化 β = −0.249, p = 0.002；excitement 习惯化 β = −0.177, p = 0.027（第 5 页）。作者明确声明这是**相关**证据，不是因果（第 7 页 Limitations）。

## 二、⭐ 情绪强度的测量与标定

### 2.1 [P1] 强度的操作化（这是最详细、最可直接借用的一份）

**【原文】测量方式**（第 14 页 Measures；第 17 页 Table 2）

- 先问二值题："Have you experienced an unpleasant emotion since the last beep?"（Yes/No）。
- 若 Yes，对 **6 种不愉快情绪**分别打分：**anger, sadness, agitation, anxiety, boredom, helplessness**。
  - 题项模板："How strongly have you experienced the emotion of **anger** since the last beep?"
  - 量表：**连续滑块 0 [“not at all”] – 10 [“very much”]**，"answers were given for every emotion"。
- **强度合成**（第 15 页 Emotional Intensity）：先把 6 个情绪强度在**每个 prompt 内取均值** → 再对全体做 **grand-mean / grand-SD 的 z 标准化** → 拆成：
  - **Between-Person Emotional Intensity** = 该被试整个 ESM 期的平均强度；
  - **Within-Person Emotional Intensity** = **person-mean centered** 的瞬时偏离量。

**【原文】分布参数（第 20 页 + Table 3）**

| 量 | 数值 |
|---|---|
| 合成强度均值（6 情绪平均） | **M = 3.41, SD = 1.93**（0–10 尺度） |
| Anger | M = 4.46, SD = 3.12，范围 0–10 |
| Anxiety | M = 2.30, SD = 2.92，范围 0–10 |
| Depression／文本中对应 sadness | M = 4.07, SD = 3.18，范围 0–10 |
| Unrest／文本中对应 agitation | M = 4.30, SD = 3.10，范围 0–10 |
| Helplessness | M = 3.68, SD = 3.10，范围 0–10 |
| Boredom | M = **1.59**, SD = 2.38，范围 0–10 |
| "出现过不愉快情绪"的 prompt 占比 | **M = 20.89%（SD = 17.46%）** |
| 人均 ESM 完成率 | **M = 84.78%（SD = 14.60%）** |

> ⚠️ 【原文】Table 3 用了 `Depression` / `Unrest`，而正文与 Table 2 用 `sadness` / `agitation`——**同一篇内的标签不一致**，引用时注意。
> ⚠️ 【原文】Table 3 的 `SD` 与 `M` 之间有明显空隙（如 anger 4.46 / 3.12），不能排除抽取时的列错位，**引用前建议回原 PDF 核对**。

**【原文】关键的"没有报告"清单（做标定时必须知道）**
- **没有报告任何信度**：无 Cronbach's α、无 ICC、无 split-half、无 test-retest。
- **没有报告**情感强度测量的**收敛效度**（如与 PANAS、 valence/arousal 的对照）。
- **没有报告**强度的**峰度/偏态**或"高强度的判定阈值"——所有结论都建立在**连续 z 分数**上。

### 2.2 [P2] 强度的操作化（单题、口头报告）

**【原文】**（第 2 页 Methods）
- 每 trial 开始前让被试**口头报告**两项：anxiety `0 (not at all anxious) – 10 (very anxious)`；excitement `0 (not at all excited) – 10 (very excited)`。
- 由实验者实时录入电子表格，房间内**始终另有一名实验者**以保证记录一致性。
- 分析时**在全部被试间做 z 标准化**（"standard z-score normalization across subjects"）。
- 另有基线测量：任务前的 anxiety/excitement、**Trait Anxiety Inventory**、自评**恐高**（0–10）、一般冒险意愿、Curiosity and Exploration Inventory。
- **GSR 采集失败**：Shimmer GSR+ 在测完 **53 名**被试后硬件故障，**GSR 数据被弃用**（第 2 页）。

**【推断】** [P2] 的强度是**单题主观量表**（single-item），既无信度报告也无法估计测量误差；[P1] 至少是 **6 题平均**（理论上有部分随机误差抵消）。因此**"强度的测量精度"上 [P1] 优于 [P2]**，尽管 [P1] 的证据等级更低。

### 2.3 【推断】两篇的"强度"都是标量，而不是几何长度

- [P1] 强度 = 6 个**非负**分量的**算术平均**（一维投影）。
- [P2] 强度 = anxiety 与 excitement 两个**各自独立**的一维刻度（连"一个标量"都不是，是两条平行曲线）。
- 两篇都**没有**把多个情绪分量合成一个**范数/长度**。
- 因此：**没有一个可用的既有标定可以搬给我们的 r。** 能借的只有**分布形状与量级**（见第十节）。

## 三、⭐ 强度 → 行为 的定量关系

### 3.1 [P1] 强度 → 是否选择某策略（多层 logistic，OR 与 CI 均为原文 Table 4）

**【原文】模型**（第 18 页）：
`Strategy Choice ~ 1 + Within-Person EI + Between-Person EI + Weekend + Survey Index + (1 + Within-Person EI | Participant) + (1 | Couple)`
- 方向性假设用**单侧 p**；用 **Benjamini-Hochberg** 控制 FDR（第 19–20 页）。
- **注意**：第 20 页原文写 "For Hypothesis 1.1, **seven** separate models … For Hypothesis 1.2, **four** separate models"（7 个摆脱型 / 4 个投入型）——但表 2 实际是 **4 个摆脱型（distraction, substance use, exercise, expressive suppression）+ 7 个投入型（acceptance, rumination, problem-solving, perspective, benefit finding, self-blame, reappraisal）= 11 个**。位置互换，与 Table 4 的结构不符，属**原文内部不一致**。

**【原文】显著项（BH 校正后仍显著）**

| 策略 | 类别 | 预测变量 | OR (95% CI) | SE | z | p |
|---|---|---|---|---|---|---|
| Substance use | 摆脱 | **Within-Person EI** | **1.75 (1.07–2.87)** | 0.44 | 2.24 | 单侧 **0.012** |
| Acceptance | 投入 | **Within-Person EI** | **0.72 (0.60–0.86)** | 0.07 | −3.63 | 单侧 **<0.001** |

**【原文】其余（BH 后不显著）**

| 策略 | Within-Person EI OR (95% CI), 单侧 p |
|---|---|
| Distraction（摆脱） | 1.06 (0.83–1.35), p = 0.321 |

| Expressive suppression（摆脱） | 1.35 (0.92–1.99), p = 0.065 |
| Rumination（投入） | 2.08 (1.60–2.70), p 单侧 >0.999（**双侧 <0.001**） |
| Problem-solving（投入） | 1.33 (1.06–1.68), p 单侧 0.993（**双侧 0.014**） |
| Benefit finding（投入） | 1.78 (1.34–2.36), 双侧 **<0.001** |

- **Between-Person EI**：所有 11 个策略**全不显著**（原文明说 "No significant effect emerged for the person mean of emotional intensity" 第 22 页；Table 4 中该行 OR 多在 0.7–1.5 且 CI 跨 1）。
  - 例外提示：Table 4 里 acceptance 的 between-person 项 OR = 0.76 (0.57–1.02), 单侧 p = 0.031、**双侧 0.063**；problem-solving OR = 0.70 (0.51–0.97), 单侧 p = 0.016、**双侧 0.032**。**这些是"未过 BH 或方向性假设"的边角项，引用需谨慎**（原文讨论中把它们归为"没有可靠 between 效应"）。

**【原文】探索性分析（双侧 + BH，第 22–23 页）**
- 除 perspective 外，**rumination / problem-solving / benefit-finding / self-blame / reappraisal 都在"高于个人均值"时更可能被选**（与假设 1.2 方向相反）。
- acceptance 仍然在**更低**瞬时强度下更可能被选。

**【原文】强度 → 策略**数量**（线性多层模型，第 23 页）**
- **Within-person：b = 0.190, SE = 0.033, p < .001** —— 强度高于个人均值的当下，会选**更多**个策略。
- **Between-person：b = −0.018, SE = 0.076, p = .814**（不显著）。
- 参照：在有策略的场合，**人均选 M = 1.84 (SD = 1.18)** 个策略；**26.13%** 的"有不愉快情绪"的 prompt **一个策略都没选**（第 21 页）。

### 3.2 [P1] 强度 → 主观衰减（多层线性，Table 5）

**【原文】模型**（第 18–19 页）：
`Attenuation ~ 1 + Within-Person EI * Strategy Category + Between-Person EI * Strategy Category + Weekend + Survey Index + (1 | Survey Index) + (1 + Within-Person EI * Strategy Category | Participant) + (1 | Couple)`
（Strategy Category：**摆脱 = 0，投入 = 1**；Attenuation 与 EI 均已 z 标准化）

**【原文】固定效应**

| 预测项 | b (95% CI) | SE | t | p |
|---|---|---|---|---|
| Intercept | **5.81 (5.52–6.11)** | 0.15 | 38.65 | <0.001 |
| Within-Person EI | −0.12 (−0.34–0.09) | 0.11 | −1.12 | 单侧 0.866 |
| **Strategy Category**（投入 vs 摆脱） | **−0.92 (−1.14 – −0.71)** | 0.11 | −8.37 | **<0.001** |
| Between-Person EI | 0.04 (−0.32–0.41) | 0.19 | 0.24 | 单侧 0.407 |
| Survey Index（时间） | **−0.02 (−0.02 – −0.01)** | 0.00 | −8.44 | **<0.001** |
| **Within-Person EI × Strategy Category** | **−0.32 (−0.60 – −0.04)** | 0.14 | −2.26 | 单侧 **0.013** |
| Between-Person EI × Strategy Category | −0.25 (−0.57–0.06) | 0.16 | −1.58 | 单侧 0.058 |

**【原文】简单斜率（post-hoc，未预注册，第 27 页）**
- **摆脱型**：b = **−0.122**, SE = 0.109, t = −1.118, **p = .269**（强度**不影响**摆脱型的衰减效果）。
- **投入型**：b = **−0.445**, SE = 0.099, t = −4.483, **p < .001**（强度越高，投入型**减效越差**）。

**【推断】可换算的量级**：衰减量表 0–10，b 为**每 1 SD 强度**的变化。投入型斜率 −0.445（相对摆脱型的 −0.122）意味着**强度每上升 1 SD，投入型相对摆脱型的减效优势再多损失约 0.32 分（0–10 尺度）**；而回归截距 5.81 说明被试平均自评"削减了约 5.8/10"。

| 风险升级 ~ 特质焦虑 | — | β = 0.13, t(149)=1.59, p=0.114, **BF₁₀ = 0.55** | 不支持（"anecdotal" 零证据） |

**【原文】控制实验（N=30，地面木板，第 6 页）**
- 地面组自评更低：anxiety M = 1.51 (SD 1.41) vs 主实验 M = 3.08 (SD 1.94)，**t(187) = −4.21, p < 0.001, Cohen's d = −0.84**, CI [−1.24, −0.44]。
- excitement M = 2.96 (SD 1.6) vs M = 5.02 (SD 2.0)，**t(187) = −5.33, p < 0.001, Cohen's d = −1.06**, CI [−1.46, −0.66]。
- 到达木板边缘的 trial 分布：控制组 **29/30 第一次就走到边缘**，主实验只有 **8/159**；**KS D(159,30) = 0.91, p < 0.001**；**Wilcoxon W = 130, p < 0.001**。
- 掉下木板的编码：**约一半**被试至少掉下过一次，平均 **1.8 次**；**23.3%** 在前 1/3 首次掉下，**13.2%** 中 1/3，**9.43%** 后 1/3。剔除所有掉落 trial 后**结论不变**（Supplementary Figs. 1–3）。

**【推断】量级换算（原文未给）**
- 原文的 β 都是"跨被试 z 标准化后"的系数，因此**同时是标准化回归系数 ≈ 相关强度**：anxiety 习惯化与风险升级 **r ≈ −0.25**（**小到中等效应**，解释方差约 6%）；excitement 习惯化 **r ≈ −0.18**（约 3%）。
- **绝不要**把 −0.249 当成"斜率"使用：它对应"习惯化斜率每快 1 SD，风险升级斜率快 **0.25 SD**"。**升级率差异是"跨个体的小幅比例差异"，不是倍数差异。**
- Risk escalation β = 0.25，**risk 也是 across-subjects z 分**。原木板长 5.525 m、15 trial、每 trial 从 0 开始 → 若把 0.25 SD/trial 粗放地当线性增速，**数个 trial 即可走完绝大部分木板的量级**，与"多数人在实验后半段才到边缘"一致。

## 四、情绪调节策略的类型学

**【原文】** [P1] 用了 **16 个策略的清单（被试可多选）**，但**当前分析只用 11 个"个体内（intrapersonal）"策略**（第 14 页）。

**摆脱型 / Disengagement（4 个）**

| 策略 | 原文题干 |
|---|---|
| Distraction | "I found an activity to keep myself busy and distracted." |
| Substance use | "I smoked a cigarette/drank alcohol/used drugs." |
| Exercise | "I exercised." |
| Expressive suppression | "I controlled my emotions by not showing them." |

**投入型 / Engagement（7 个）**

| 策略 | 原文题干 |
|---|---|
| Acceptance | "I accepted the situation and/or my emotions." |
| Rumination | "I thought over and over again about the situation and my feelings." |
| Problem-solving | "I made a plan to make the situation better." |
| Perspective | "I reminded myself that things could be worse." |
| Benefit finding | "I thought about how I could become stronger or learn from the situation." |
| Self-blame | "I thought about how this situation was my fault." |
| Reappraisal | "I thought about the situation in a different way." |

**【原文】分类依据**：按 **Sheppes et al. (2014)**——摆脱型"**不包含**对情绪信息的精细加工"，投入型"**包含**投入与精细化情绪信息"；由作者小组（CLM, TE, JF, VS, BC）讨论定稿（第 15–16 页）。作者自己承认"**不存在明确的投入/摆脱清单**，某些策略可以合理地划到对面（例如 rumination 也可视为情绪回避）"（第 35–36 页 Limitations）。

**【原文】选择频率（第 21 页，占"出现过不愉快情绪"的 prompt 的比例，可多选故加总 >100%）**
- **Acceptance 33.46%**（最常）> **Distraction 24.01%** >（Figure 1 中其余按图形排序，正文未逐个给数）… > **Substance use 1.72%**（最少）。

- **Wylie et al. (2021/2023)**（6 个策略，单选）：reappraisal ↓、rumination ↑、engagement ↑、relaxation ↑、distraction ↓、suppression ↓。
- **Lennarz et al. (2019)**（8 个策略，多选）：acceptance ↓；reappraisal 不显著；problem-solving ↑、social support ↑、rumination ↑、avoidance ↑、distraction ↑、suppression ↑。

## 五、⭐ 习惯化的定量描述

### 5.1 时间尺度：**有，但只有 trial 轴，没有物理时间常数**

**【原文】** [P2] 的习惯化定义为**每个被试**用线性模型 `emotion ~ trial number` 的**斜率**（跨被试 z 标准化）；"Negative values indicate habituation … positive values imply sensitization"，"Steeper negative slopes … represent greater habituation"（第 3 页）。

**【原文】关键参数**
- **主实验共 15 个 trial**；每次暴露时长：升上去后 **等 5 s** 听到 "trial begins"，然后 **20 s 自由活动**，之后自行返回地面；**inter-trial interval = 25 s**（第 2 页）。
  - 【推断】单 trial 周期约 **50 s（5 + 20 + 25）**，含情绪口头报告。**15 个 trial ≈ 12.5 分钟**。
- **群体层面衰减速率：anxiety β = −0.06 / trial，excitement β = −0.06 / trial**（均 p < 0.001，CI 见第三节）。
- **两情绪的衰减轨迹不分化**（emotion × trial 交互 β = 0.002, p = 0.614）。
- **两个习惯化斜率中度相关 r ≈ 0.403**（p < 0.001）→ 作者据此主张"部分共享的**唤醒习惯化**过程"。
- **样本层面**：159 人中有 **8 人第一个 trial 就到最大风险**（无法估斜率，被排除）；**4 人 anxiety 与 excitement 都无变化**（无法估斜率）。

**【推断】把 β 换算成 0–10 尺度上的"降到多少"**
- 原文 β 是"emotion 与 trial 都跨被试 z 化"后的系数。若用主实验 anxiety 的 M ≈ 3.08、SD ≈ 1.94 粗算：跨被试 z 化后 1 个单位 ≈ 1.94 分 → **−0.06 z/trial ≈ −0.12 分/trial（0–10 尺度）**。
  - 15 个 trial 累计 ≈ **−1.7 分**：即从 ~3.1 降到 ~1.4 的量级——与第 6 页控制实验里"地面组 anxiety M = 1.51"的数量级吻合。
  - **但要注意**：原文的 −0.06 是**双向标准化**的系数，且被试内部的 SD 未报告，这个换算只能当**数量级参考**，不能当精确标定。
- **线性 vs 指数**：作者**用线性斜率**描述习惯化，**没有**报告指数衰减常数、半衰期或平台值。若真要拟合指数，需要原始数据（作者已开源，见第九节）。
  - 【推断】线性拟在 15 个 trial 的窗口内是对指数衰减的**一阶近似**；**外推到长程会失真**（会穿负值）。

**【原文】"重复暴露多少次"**
- 原文**没有**给出"多少次暴露后强度降到多少"的显式阈值表格或"X 次达到平台"的结论。可用的间接证据：
  - **只有 8/159（5%）** 的人在 **第 1 个 trial** 就到最大风险；控制实验里 **29/30** 的人第一个 trial 就到边缘 → 说明**达到"无情绪阻力"的状态通常需要多次暴露**，且**跨个体差异巨大**。
  - 掉下木板的时间分布：首 1/3、中 1/3、后 1/3 分别 **23.3% / 13.2% / 9.43%** → 最大风险行为**在前段最密集**，尾部趋缓（与"平台/习惯化"形状一致）。

### 5.2 习惯化的**方向性**定义与"什么不是习惯化"

**【原文】**
- 习惯化 ≠ 基线情绪低：**基线 anxiety / excitement 以及 trait anxiety 都不预测风险升级**（BF₁₀ = 0.04 / 0.12 / 0.55；第 5 页）。
- 习惯化 ≠ 运动学习：控制实验（地面木板）里 29/30 第一次就到边缘，主实验 8/159 → **"逐渐走得更远"不是"越来越会走木板"**（第 6 页）。
- 习惯化 ≠ 走得远导致的（反向解释被排除）：把"每 trial 走的距离"加入模型后，情绪衰减依然显著（第 5 页）。
- **作者明确承认是相关证据**，因果需直接操纵习惯化速率（药理或放松技术），并称"**风险升级导致焦虑/兴奋下降**（而非上升）的可能性较小"（第 7 页 Limitations）。

## 六、习惯化 → 冒险升级 的链条

### 6.1 作者给出的**链条**（【原文】）

**【原文】明说的两条并列机制**（第 1 页 Introduction、第 6 页 Discussion）：
1. **负性通路**：焦虑是**抑制**冒险的线索 → 焦虑习惯化 → "no signals curbing risk-taking behavior" → 冒险增加。
2. **正性通路**：兴奋驱动冒险 → 兴奋习惯化 → 为**重新获得**当初的刺激感而追求更大的风险（"recreate the level of excitement"）。原文强调本任务**没有物质激励**，所以人走木板大概出于"internal rewards"（好奇与刺激寻求）。

**【原文】链条的每一环都有数据**
- 环 A「情绪随重复下降」：anxiety β = −0.06、excitement β = −0.06，p < 0.001。
- 环 B「行为随重复升级」：risk β = 0.25, p < 0.001。
- 环 C「习惯化速度 ↔ 升级速度」：anxiety β = −0.249 (p = 0.002)、excitement β = −0.177 (p = 0.027)；换指标（到最大风险的 trial 数）同向：β = 0.265 / 0.301，p < 0.001。
- 环 D「风险感知本身随 distance 上升」：验证实验 β = 0.17, p = 0.022（保证"走得更远"确实是"更冒险"）。

### 6.2 ⚠️ **有没有中介分析？——没有**

**【原文】** **全文没有做中介分析（mediation）**：没有 a×b 间接效应、没有 bootstrap 间接效应 CI、没有 SEM 路径模型、没有因果中介假设检验的表述。
- 可用的是：**相关/回归 + 控制变量 + Bayes 因子（用于零结果）**（第 2 页 Analysis；第 5 页）。
- 作者**自己声明**："While the results are correlational, it is useful to **speculate** about the potential mechanisms"（第 6 页 Discussion）；Limitations 里再次强调 "correlational nature … a third factor explains the correlation"（第 7 页）。

**【推断】所以"情绪衰减 → 风险感知降低 → 冒险增加"这个三环链条，论文只支持其中两环**
- **支持**：情绪衰减 ↔ 冒险升级（相关）；走得越远 ↔ 主观风险感越高（相关）。
- **不支持/未测**：**"风险感知随时间下降"** 这一环**没有被直接测过**——验证实验（N=35）**只测 perceived risk、不测情绪**（第 4 页明说 "emotional measures (anxiety, excitement) were not collected"），而且验证实验是**独立的一组被试**，无法把"perceived risk 的衰减"和"习惯化"对齐到同一个人身上。
- **对我们最重要的一句话**：【原文】作者并未主张"风险感知降低"是中介；他们主张的机制是"**情绪信号（抑制/驱动）被习惯化**"。**风险感知的变化是一个未被检验的替代解释，不要当成论文结论引用。**

### 6.3 [P2] 与 [P1] 在"行为后果"上的互补

**【推断】** 两篇拼起来正好覆盖我们 A2 的**两个不同时间尺度**：
- [P1] 是**单次事件内 / 事件之间**的"强度 → 立即选择与减效"（时间尺度：小时级 prompt，28 天）。
- [P2] 是**同类刺激重复暴露**的"强度增量 → 衰减 → 行为阈值移动"（时间尺度：分钟级 trial，15 次）。
- 二者**不能互相替代**：[P1] 从未考察暴露次数效应（虽然它确实把 Survey Index 放进模型并发现 **衰减量随 prompt 索引缓慢下降：b = −0.02, p < 0.001**，见 Table 5——这是全文唯一一个"时间趋势"证据，但作者没把它解释为习惯化）。

## 七、个体差异

### 7.1 [P2] 个体差异（这篇的主战场）

**【原文】**
- **升级速率跨个体差异巨大**："The rate of escalation differed dramatically across individuals"（第 1 页摘要）。
- **谁习惯化快？**
  - **习惯化快的两个情绪高度同向**（斜率相关 r ≈ 0.403, p < 0.001）→ 作者解释为**跨情绪的部分共享过程（arousal habituation）**，暗示**"习惯化速率"是一个个体层面的、跨情绪（乃至可能跨领域）的准特质参数**。
  - **与基线情绪无关**：基线 anxiety（BF₁₀ = 0.04）、基线 excitement（BF₁₀ = 0.12）、trait anxiety（BF₁₀ = 0.55）**都不预测升级速率**。
  - **与"情绪总量"无关**：均值层面 anxiety ~ excitement 相关很弱（β = 0.158, p = 0.046）。
- **作者点名的未测/未来个体差异变量**：impulsivity（第 7 页 Limitations，引 Baker et al. 2024）；以及"习惯化是否**领域一般（domain general）**"——若跨领域一般，或可解释"爱做财务冒险的人也更爱做身体冒险"。
- **临床应用推论**：【原文】"个体习惯化速率差异"提示**暴露疗法可以按个体习惯化速率来定制暴露次数**（第 6 页）。

### 7.2 [P1] 个体差异：**between-person 全线落空**

**【原文】**
- between-person（个体平均强度）对 **11 个策略的选择**全部不显著；对**衰减**也不显著（Table 5 的 Between-Person EI 与其交互都不显著）。
- 作者的解释："interindividual variation may be less informative … compared to within-person dynamics"，并归因于**社区样本本身情绪强度不高、变异受限**（第 30 页）。
- **反例指向**：作者指出 **BPD 患者平均情绪强度更高且更依赖摆脱型策略**（Daros & Williams 2019; Kuo & Linehan 2009; Eckland et al. 2022），因此主张未来要在**临床/亚临床群体**里重做 between-person 分析（第 30 页）。

**【推断】这条对我们特别重要**：若我们的陪伴型角色要模拟"高情绪强度人格"，[P1] 的证据**不能**从健康大学生/社区样本外推到高强度的临床人群——恰恰相反，作者暗示**方向可能在临床群里成立**。

## 八、⚠️ 正性/负性是否不对称

### 8.1 [P2]：**明确检验过，结论是"不存在显著不对称"**

**【原文】**
- 假设是**两条通路都成立**（负性：焦虑抑制冒险；正性：兴奋驱动冒险）。
- 结果：**anxiety 与 excitement 都以几乎相同的速率衰减**（β = −0.06 vs −0.06）；**emotion × trial 交互 β = 0.002, t = 0.505, p = 0.614** → "the trajectories of the two emotions did not diverge significantly"（第 5 页）。
- 两条习惯化斜率**中度正相关**（r ≈ 0.403）→ 共同成分（唤醒）多于特异成分。
- 结论句："habituation of **both** positive and negative feelings" 与风险升级相关（第 6 页）；摘要用词 "faster reduction of anxiety **or** excitement"（第 1 页，注意是 **or**，不是 and）。

**【推断】对"负性不易习惯化"这个直觉的反驳**
- 至少在这个 VR 情境里，**负性（焦虑）并没有比正性（兴奋）更"顽固"**；两者幅度相同，且不显著分化。
- 但**必须标注三个限定**：(1) 这里只有一对情绪（anxiety / excitement），不是普适的 valence 对比；(2) 刺激是**中度威胁 + 无真实后果**（"participants are aware that they are not in actual danger in a VR environment, which may **expedite habituation**"，第 7 页 Limitations）；(3) 只有 15 个 trial，**慢习惯化需要更长窗口才能显现**，这里是"窗口内未分化"，不等于"永不分化"。
- 另外，两篇**都没有**做"负性 vs 正性习惯化速率"的**元分析式**对比。

### 8.2 [P1]：**只研究负性**，正性是"提了一句"

**【原文】**
- 文中只分析 6 种**不愉快**情绪的强度与 11 个策略；当被试报告"没有不愉快情绪"时，他们会被问**几乎同样的正性情绪问题**，但"**For the current analyses, only the 11 items on intra-personal ER strategies and unpleasant emotions were considered**"（第 14 页）。
- 因此在 [P1] 里，**正性/负性不对称完全未被检验**（不是"无效应"，是"未测"）。

### 8.3 【推断】写进我们的模型时要留的余地

- 不要因为 [P2] 的 null interaction 就把角色的正负衰减写成同一个参数。合理做法：**共享一个基础衰减速率 + 一个 valence 相关的调制项**（默认调制接近 0，允许在剧情/人设维度上调），这与 [P2] 的"部分共享 + 未显著分化"一致。

## 十、⭐ 对我们 A1 的 r 与 A2 的启示

### 10.0 先回答那个必须先回答的问题：**这两篇的"强度"是不是我们的 r？——不是。**

| 维度 | 我们 A1 的 r | [P1] 的 emotional intensity | [P2] 的 emotional intensity |
|---|---|---|---|
| 数学对象 | **欧氏范数** `r = ‖E − μ‖`，E ∈ R³(PAD) | **一维算术平均**（6 个非负分量求和 / 6） | **两条独立的一维刻度**（anxiety 0–10、excitement 0–10） |
| 分量允许负值？ | 允许（P/A/D 有正负两极） | 不允许（0 = "not at all"） | 不允许 |
| 有没有"方向"？ | **有**（PAD 方向携带情绪种类信息） | **完全丢弃** | **完全丢弃** |
| 有没有"底情绪"？ | **有**（μ 是原点） | **有**（person mean 被显式剔除为 between 成分） | **有**（baseline 单独测量） |
| 量纲 | 球坐标半径，球面 = 1（模型内归一） | 0–10 滑块 | 0–10 滑块 |
| 与 σ | `r²/σ² ~ χ²(3)` | 无 σ 概念；只有经验 z 分数 | 无 σ 概念；只有经验 z 分数 |

**【推断】至少三个不可忽略的差别：**

1. **标量 vs 范数（最根本）**：他们的强度是"**感觉有多强**"（arousal-magnitude 型的一维投影），我们的 r 是"**离底情绪多远**"（几何长度）。
   - 关键后果：**同一个 r 可以对应完全不同的"感觉强度"**。例如高唤醒+高支配的兴奋（r 大）与低唤醒+低支配的疲惫，在某些 μ 下 r 可能相近，但主观"强度"完全不同。反之，**一种强烈但方向与 μ 一致的情绪**（如底情绪本身就是低落的角色遇到更强的低落）在我们这里 r 大，在主观量表上可能只被报为中度。
   - 另一个后果：他们的 6 个分量都是**单极、同向**的负性情绪；把 6 个非负值取平均，**在数学上等价于"把这些情绪看成近似正交的同向轴"**。若我们硬要用它估 r，我们必须假设**这些情绪轴在 PAD 里大致正交**——而这是**未经验证的假设**。

2. **r 是"到 μ 的距离"，他们的强度是"事件内强度"**：他们的量表问的是 "since the last beep"（事件窗口内），**没有减去任何基线**。所以他们的 0–10 更像是 `‖ΔE_t‖`（事件诱发的增量幅度）而不是 `‖E_t − μ‖`。
   - **这一条对我们其实是好消息**：他们的量最自然的映射位置是 **A2 里的 `ΔE_t` 的幅度**，而不是 A1 的 r。也就是说——**两篇论文真正能标定的是 A2 的驱动项，不是 A1 的半径。**

3. **区间尺度 vs 比率尺度**：0–10 滑块只有顺序/区间意义，**"0" 不代表"没有情绪"，"10" 也不代表"球面"**。他们从未定义任何"极致"点；我们的"球面 = 强度的极致"在他们的框架里**没有任何对应物**。

### 10.1 【推断】对 A1（r 的标定）能借的三样东西

虽然不同源，但**分布形状**可以直接拿来当先验：

1. **经验量级（可借）**：[P1] 给出合成强度 **M = 3.41, SD = 1.93（0–10）**；单情绪 SD 约 **2.4–3.2**；[P2] 的 anxiety M ≈ 3.08 (SD 1.94)、excitement M ≈ 5.02 (SD 2.0)。
   - **含义**：真实日常的"情绪强度"分布**大部分质量压在低区**（0–10 里均值 3.4，即 34% 量程），并且**"出现过不愉快情绪"只占 20.89% 的 prompt**。
   - **对我们的直接后果**：如果我们希望角色的日常表现贴近真人，**σ 应该被标定为"大多数时候 r 落在 1 个 σ 以内、只有少数时刻摸到外侧"**，而不是"经常贴球面"。
2. **χ²(3) 形状的自洽性检查（可借）**：在 A1 里 `r²/σ² ~ χ²(3)`，因此 `E[r] = σ·√2·Γ(2)/Γ(1.5) ≈ 1.596·σ`，`E[r²] = 3σ²`。
   - **反解**：若把"日常平均强度"当作 `E[r]` 的代理，并用 [P1] 的 **3.41** 作为这个平均，则 **σ ≈ 3.41 / 1.596 ≈ 2.14（0–10 尺度）**。
   - **球面（r = 1）的落点**：我们模型里球面 = 球坐标半径 1，所以 **r = 1 ↔ 0.47σ**；`P(χ²(3) > (0.47)² = 0.22) ≈ **0.974**` → **"球面"是 97.4 分位**，也就是只有约 **2.6% 的时刻**才会触到。
   - **⚠️ 但这只是"如果 A1 的 r 与他们的标量强度同尺度"的假设性换算**，而第 10.0 节已论证它们**不同尺度**。所以上面的 σ ≈ 2.14 应当只被当作**排序与量级参考**，不能当定标数值。
3. **⚠️ 不要借的东西**：
   - **不要**用他们的 0–10 → 我们的 [0,1] 半径做线性缩放。
   - **不要**用他们的"z 标准化"当 σ 定义（他们的 z 是样本内标准化，**不是**人格特质的标准差）。
   - **不要**把 [P2] 的 risk 量（0–5.525 m 的**走板距离**）当成任何强度量——它是一个**行为比例**，不是情绪强度。
4. **⚠️ 我们更该内测的量（论文没给）**：
   - 我们的情绪词库有 599 个中文情绪词、强度只分 `strong/mild`。**这两篇无法给我们"哪端是 strong"的阈值**。
   - 我建议的替代路径（【推断】，可工程化）：**用自采的 PAD 标注数据，对 r 取经验分位数切分**，例如
     - `mild`：`r < P50`
     - `moderate`：`P50 ≤ r < P85`
     - `strong`：`P85 ≤ r < P97`
     - `extreme`：`r ≥ P97`
     并把这套分位阈值**反过来约束 χ²(3) 下的 σ**（即让 `P(χ²(3) > (t/σ)²)` 与经验分位对得上，解出 σ）。
   - 或者（更省事）**直接把 σ 当自由参数**，用 A4 的 strong/mild 二分做监督信号去拟合，**用这两篇只做"合理性区间"的检查**：若拟合出的 σ 导致"日常 r 大量贴球面"，就与本节的 3.41/1.93 分布矛盾，需要回退。

### 10.2 【推断】对 A2（动力学）的启示——**这是两篇真正能给我们的东西**

我们的 A2：`E_t = μ + ρ(E_{t−1} − μ) + ΔE_t`

**（a）不要把 [P2] 的"习惯化速率"塞进 ρ。** 这是最容易犯的错。

- ρ 描述的是**单次情绪事件的自行回落**（事件内衰减、情绪自回归），尺度是"这一秒到下一秒"。
- [P2] 的"习惯化斜率"描述的是**同类刺激第 k 次出现时 `ΔE` 变小**，尺度是"第 k 次暴露"。
- 两者**可以同时存在且互相独立**：一个角色可以每次事件内回落很快（ρ 小）、但同类刺激重复时反应幅度不变（无习惯化）；也可以相反。
- **正确的插入位置**是**给驱动项加一个暴露状态变量**，例如

  ```
  ΔE_t = g(state_t)      # 事件诱发的驱动增量
  g(state)_k = α^(k−1) · ΔE_0     # 第 k 次同类暴露，0 < α ≤ 1
  ```
  或等价地让 `ΔE` 的幅度按一阶过程衰减：`ΔE^(k) = (1 − h)·ΔE^(k−1)`，其中 **h = 单次暴露的习惯化比例**。

**（b）[P2] 给的 h 有多大？——只能给数量级，且必须标注不确定性**

- 用第三节的比例关系 + 我的换算：**anxiety 线性衰减 β ≈ −0.06 z/trial**，即**在整个 15 trial 窗口内相对自身 SD 衰减约 0.9 个 z 单位**（−0.06 × 15）。
- **【推断】若把它硬当指数**：从第 1 trial 到第 15 trial，幅度按 `α^14` 缩放，且 `(1 − α^14)/(1 − α)` 型的线性化近似 → **α 的粗略量级在 0.93–0.96（即每次暴露衰减 4%–7% 的剩余幅度）**，但**这个数字建立在"线性 ≈ 指数"的近似上，15 个点也太少**。**建议：把 α 当自由参数、默认取 0.93–0.96 区间做敏感性分析，不要写死在模型里。**
- **更稳的一条（可直接引用）**：**习惯化是"跨个体差异巨大"的**（第 1 页摘要原话），所以**α 不应该是一个全局常数，而应该是角色级参数**。

**（c）[P2] 支持"α 与情绪效价关系不大"**

- emotion × trial 交互不显著（p = 0.614）+ 两条斜率相关 r ≈ 0.403 → 【推断】**用一个共享的 α 起步是合理的**；
- 但【推断】这两条也提示 **α 更可能是"唤醒"维度的属性**（作者自己说 "a common feature such as arousal habituation"，第 5 页）。**落到 PAD 上，最自然的做法是让衰减作用于 A（唤醒）维的驱动增量，而不是 P/V**——这与我们的三维结构天然兼容，而且论文提供了直接的原话依据。
- **⚠️ 但别忘了第八节的限定**（无真实后果、15 trial），**这是一个可用的先验，不是一个已验证的定律**。

**（d）[P2] 给了"α 慢 → 行为阈值不动"的行为读出方式**

- 关键可移植的结论不是具体数值，而是**结构**：**行为的变化由"情绪信号"的习惯化驱动，而不是由"基线情绪水平"或"人格特质"驱动**（基线 anxiety、基线 excitement、trait anxiety 的 BF₁₀ 分别是 0.04 / 0.12 / 0.55 → 零证据）。
- 【推断】对我们：**角色的"越界行为"（冒险、越界发言、越界亲密）应该由"该情境下 ΔE 的习惯化状态"驱动，而不是由 A3 的 μ 或 σ 驱动。** 这是一个可以直接落地的设计决策：
  - `μ` 决定"常态气质"（角色平时什么样）；
  - `σ` 决定"多容易激动"（触到球面的频率）；
  - **习惯化状态 `k`（或 `α^k`）决定"同一个刺激第 n 次出现时还剩下多少反应"**，以及**行为阈值是否已经被磨低**。
- 另外 [P2] 指出**正性通路也会推高冒险**（"recreate the level of excitement"）→ 【推断】**不要只在负性 ΔE 上做习惯化**；正性 ΔE 的习惯化同样会让角色为了"找感觉"而升级行为（对应到陪伴角色的语境，就是**重复的甜点互动会变淡，角色会去追更强的刺激**）。

**（e）[P1] 对 A2 的两条次要但可用的启示**

- **衰减量随时间缓慢下降**：Table 5 的 Survey Index 效应 **b = −0.02, p < 0.001**，即**"调节之后剩下的情绪"在 28 天里整体缓慢走低**（【推断】：这可以读成"日常强度的基线在缓慢漂移"，属于 A3/μ 的慢漂移项，而不是习惯化）。
- **强度高 → 同时用更多策略**：within-person **b = 0.190, SE = 0.033, p < .001**（策略数；平均 1.84 个）。
  - 【推断】对我们**行为映射**的直接价值：**"强度 → 行为"不是"选一个动作"，而是"同时/连续触发多个动作"**。角色的高 r 时刻应当输出**策略叠加**（既倾诉又转移注意又求助），而不是单一路径。这是一个可以立刻写进行为层的规则，而且证据是强（p < .001）。

### 10.3 ⚠️ 一句话总结这一节的边界

**【推断】这两篇不能告诉我们"我们的 r 应该多大"，也不能给我们 r→行为的阈值；它们能告诉我们的是：(1) 真实情绪强度的分布形状（低区集中、少量高峰）；(2) "强度 → 行为"的**结构**是"多策略叠加 + 倒 U 型的减效优势"；(3) "重复暴露 → 反应幅度衰减 → 行为阈值移动"这条**跨时间尺度**的机制，而这条机制的正确插入点是 A2 的 `ΔE`，不是 ρ、也不是 A1 的 r。**
