## 二、数学形式化

### 2.1 白化

设该角色的情绪中心为 `μ`（默认 `(0,0,0)`，见 A3），三轴协方差矩阵为 `Σ`（3×3，正定）。

作 Cholesky 分解 `Σ = L Lᵀ`，令

```
y = L⁻¹ (x − μ)
```

则 `y` 的三个分量**去相关且同方差**，`y ~ N(0, σ² I₃)`。

> **实现提示**：不必显式求 `L⁻¹`，用**前代法**解 `L y = x − μ` 即可。

**⭐ 文献依据**：轴的可旋转性是 PAD 文献明确承认的自由度 ——
Russell 1980 p.1171：*"since rotation of the axes leaves the circular configuration of the
variables intact, **rotation is considered arbitrary**."*

### 2.2 球坐标

```
方向  γ = y / ‖y‖           （单位向量，即 μ = λ·γ 里的 γ）
强度  r = ‖y‖               （即 μ = λ·γ 里的 λ）
球面  r = 1                 （强度的极致）
```

**→ 与既有的 `μ = λ·γ` 无缝对接：白化后的方向就是 γ，模长就是 λ。**

### 2.3 正态互补：r 的分布

白化后三轴独立同分布 `N(0, σ²)`，于是

```
r² / σ²  =  (y₁² + y₂² + y₃²) / σ²  ~  χ²(3)        （自由度 3 的卡方）
```

**即：`r = σ · √χ²₃`。**

**⭐ 这就是「三轴均可平面化为单轴正态分布」的严格形式** ——
三轴各自是单轴正态，它们的平方和（即强度的平方）服从卡方。

### 2.4 球面的位置

```
r = 1  ⟺  χ²₃ = 1/σ²
```

**⭐ 取 σ = 0.40 时：**

```
1/σ² = 6.25  ⟺  χ²₃ 的第 90.0 百分位（查表值 6.2514）
√6.2514 = 2.5003 ≈ 2.5
```

**→ σ = 0.40 是**精确解**，不是拟合值。**

**语义：球面 = 前 10% 的极端情绪才越过的线。**

## 四、σ 作为角色参数

**球体半径恒为 1 —— 它是所有角色的共同容器。σ 才是角色参数。**

| σ | 越过球面的概率 | 中位强度 | 平时用量程 | 气质 |
|---:|---:|---:|---:|---|
| 0.25 | 0.11% | 0.385 | 38% | 极冷淡 |
| 0.30 | 1.11% | 0.461 | 46% | **冷淡平稳** |
| 0.35 | 4.28% | 0.538 | 54% | 偏内敛 |
| **0.40** | **10.01%** | **0.615** | **62%** | **典型（基准值）** |
| 0.45 | 17.64% | 0.692 | 69% | 偏外露 |
| 0.50 | 26.15% | 0.769 | 77% | **情绪化** |
| 0.60 | 42.72% | 0.923 | 92% | 极情绪化 |

**⭐ σ 补上了一处文献空白**：Mehrabian 1991 把「人格」定义为
*「情绪状态在代表性情境上的**平均**」* —— **那只给了中心（均值），没有给波动幅度。**
本模型补上 σ，即**情绪起伏的幅度**。

> ⚠️ **这是本项目推出的新参数，不是任何一篇文献的结论。** 引用时须注明。

## 五、与实测数据的吻合

对 38 个心理学谱系实测点（Chen 2018 的 24 个 + R&M 1977 的 8 个 + 田智行 2021 的 6 个）拟合：

```
各轴 SD：P 0.469 · A 0.343 · D 0.347        三轴合并 RMS = 0.3965
|E| 实测：中位 0.585 · 75% 0.819 · max 1.062

由中位反推 σ = 0.381，预测各分位：

  分位     理论(σ√χ²₃)   实测      差
  中位       0.585       0.585    0.000
  75%       0.771       0.819   +0.047
  90%       0.952       0.977   +0.025
  95%       1.064       0.977   −0.087
  99%       1.282       1.040   −0.242
```

**⭐ 中位到 90% 分位几乎完全吻合（差 < 0.05）。**

**⚠️ 两个保留意见：**
1. **尾部比正态薄**（95%/99% 分位实测偏低）—— 可能是样本小，也可能是**真实分布薄尾**（极端情绪比正态更罕见）。
   若为后者，对设定是加分：「极端情绪接近球面」不但是前 10%，还比正态预测的更罕见一档。
2. **本样本是人工挑的代表词，不是随机抽样**，不能当作总体参数的严格估计。

## 六、白化的自洽性验证

```
R&M 1977 的 Happy = (0.81, 0.51, 0.46)     ← 全表最强的正向词
Σ 取 [[1,0,.40],[0,1,0],[.40,0,1]]          ← P–D = .40（文献实测值），A 独立

白化前  ‖E‖ = 1.062   ⚠️ 越界
白化后  y = (0.8100, 0.5100, 0.1484)，r = 0.9686   ✅ 球内
        σ=0.40 时 χ²₃ = 5.864 → 尾部 11.84%，未越过第 90 分位(1.000)
```

**⭐ 白化把 P–D 相关「摊平」后，虚高的模长回落 —— 连全表最强的词都恰好落在球面内侧一点点。模型自洽。**

## 七、⚠️ 三轴相关性的处理（白化的动机）

```
R&M 1977 原文实测：P–A = .03    P–D = .40    A–D = .15
本项目样本（人工挑词）：P–A = −.076   P–D = .344   A–D = .078
```

**P–D 有中等相关（两处一致，≈.34~.40）。**

| 做法 | 后果 |
|---|---|
| 直接用欧氏距离 | 球是球，但 `r²/σ² ~ χ²(3)` **不严格成立** |
| 用马氏距离 `XᵀΣ⁻¹X` | χ²₃ 严格成立，但"球面"变成**椭球** |
| **⭐ 先白化再取球（本裁定）** | **球是真的球 + χ²₃ 严格成立 + 与 μ=λ·γ 无缝** |

**⭐ 三方同时成立 —— 这就是选 (丙) 的理由。**

## 八、与既有裁定的关系

| 既有裁定 | 本规格如何满足 |
|---|---|
| 强度 = 到原点的**径向距离** | `r = ‖y‖`，白化后的模长 |
| **球面 = 强度的极致** | `r = 1`；立方体做不到（"极致"随方向波动 73%），故用球 |
| **强度与方向正交** | 球坐标 `(r, γ)` 天然分离；白化后方向就是 γ |
| **底情绪 = 原点** | 白化后的原点；`μ = (0,0,0)`（与 A3 联动） |
| **没有回到原点这回事** | 本规格只定义**空间**，不定义**演化** → 归 A2 |
| 极端情绪接近球面 | 前 10%（σ=0.40）才越过；是统计稀薄，不是被挡住 |

**⭐ 顺带解决**：本规格让「硬墙 vs 渐近线」这个二选一**消失了** ——
既不是硬墙挡住，也不是力推回来，而是**越往外概率密度越低**。
