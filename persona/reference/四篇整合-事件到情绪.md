## 一、四篇合起来的架构

```
                  ┌── AET (1996) ──── 事件层 + 两级评价
                  │
  事件 → 知觉 → 评价 → 情绪 → 行为
          ↑       ↑
   topdown2025   moors2013
   （知觉层）    （评价层）
          ↑
   barrett2016（统一机制：预测误差最小化 + 精度门控）
```

**⭐ 没有硬冲突 —— 四篇是**分层**的,不是互斥的。**

## 二、⭐ 一条架构决定（来自 moors2013）

> "there is a **variable relation between stimuli and emotions**, but a **stable relation between appraisals and emotions**"

```
刺激 → 情绪：关系【可变】
评价 → 情绪：关系【稳定】
⇒ ⭐ ΔE 不能由【事件】直接算，必须由【评价】算
⇒ #40 的架构 = 在事件与情绪之间插一层【评价层】
```

## 三、⭐⭐⭐ 事件的定义与过滤（来自 AET）

```
p.31  事件定义 = "**change**"
      "**Some, but by no means all, events have affective significance**"
      ⇒ ⭐ 授权做【事件过滤器】—— 大量事件 ΔE = 0
      ⇒ 真实 / 想象 / 回忆中的事件【同等有效】(pp.11, 12, 36)
```

**⭐ "回忆中的事件同等有效" —— 对陪伴型角色重要（角色会"回想"）。**

## 四、⭐⭐⭐⭐ 两级评价架构（AET 的核心，最工程化）

```
【一级评价】goal relevance + goal congruence + importance
      ↓ 输出
   价效 (hedonic tone) + 强度 (intensity)
      ↓
【二级评价】后果 / 归因 / 应对潜力 / 未来预期
      ↓ 输出
   具体离散情绪
```

**⭐ AET 原文（p.31）：**
> "This initial evaluation also contains an **importance evaluation** which influences the **intensity** of the emotional reaction"

**⭐ 强度专项（p.32）：**
> "the **intensity** of the emotion is **directly correlated with the importance or desirability of the goal**"
> 另有两个调制项：**unexpectedness** + **existing arousal levels**
> 以及目标层级位置 / 工具性类型 (pp.32-33)

**⚠️ 与 A1 的表面冲突（已核，兼容）：**
```
AET:  用二维 (Hedonic Tone, Intensity)，强度【独立正交】(p.30)
A1:   r = ‖E − μ‖ —— 强度是三维向量的模长（非独立维）

✅ 兼容：AET 的 importance 是【原因】，A1 的 r 是【结果】
        → ΔE 的模长由 importance 驱动，r 自然跟随
```

## 五、⭐⭐⭐⭐ ΔE 的乘法结构（barrett2016）+ 三旋钮（topdown2025）

**barrett2016 给的乘法结构：**
```
原文 p.9   预测误差 (prediction error) 的定义
原文 p.15  ⭐【精度门控】(precision gating)：
           只有被预期与【资源/生存/奖励/威胁】相关、或价值不确定的误差才【被学】，
           其余当噪声忽略
原文 p.12  贝叶斯式的概念选择（胜出概念）

⇒ ΔE_t = α_t(精度) × ε_t(预测误差) × (胜出概念的 affect 签名)
⭐ 这解释了【为什么同样强度的刺激，有时改变情绪、有时完全不改变】（α ≈ 0）
```

**topdown2025 给的三旋钮（有实验支撑）：**
```
注意 → 漂移率/增益 ↑   （真知觉效应）
期望 → 起点/c 偏移      （**不**提高敏感性）
二者独立、对预测误差作用相反 (p.394)

⇒ ΔE_t 可拆三个正交旋钮：
   起点项（先验 = μ）
   漂移项（显著度 / 注意增益）
   标准项（期望）

⚠️⚠️ 反直觉坑：期望【不增强知觉】，只增强"报告倾向"
     若把「越期待越容易感知到」做成【知觉增益】就错了
```

**⭐ 合起来：**
```
ΔE_t = α_t · ε_t · signature
        ↑     ↑     ↑
      精度  预测误差  概念
        │
        └─ 而 ε_t 本身可拆三旋钮（起点/漂移/标准）
```

## 六、⭐⭐⭐⭐ μ 的升级：从「一个向量」到「方向 + precision」

**topdown2025 的建议：**
```
论文里刻板印象 = "chronic expectations"(p.397) + "strong perceptual priors"(p.398)
且只改 **initial starting bias**、【不改 drift rate】(p.398)

⇒ ⭐ μ 应作用在【知觉层的先验】上，不直接作用在情绪值上
   且 μ 应带【负性偏置】：
     · 情绪刺激与情境关联学得更好
     · 威胁情境有竞争优势且妨碍新建关联 (p.396)
     · 负性概率 >0 后对概率变化钝化 (p.397)
     · 焦虑的威胁过度警觉【不论刺激是否存在】(p.399)

⇒ ⭐ 角色底色 = μ 的【偏移方向】+ μ 的【precision】
```

**⭐⭐ 这直接复现了设定者那条链条：**
```
「自卑 → 受伤 → 怨恨」
   μ 偏向负性 + precision 过高
     → 模糊事件被知觉为"受伤/被否定"（知觉层）
     → 继而产生"怨恨"（情绪层）
   （对应论文的焦虑/抑郁偏差清单 p.389-390, p.399；
     Box 2 p.393 把病理性偏差写成"先验因不确定性更低而支配知觉"）
```

**⚠️ AET 的相反意见（需裁定）：**
```
p.37 AET 否认"高 NA = 慢性负性基调":
     "**When no negative event takes place, individuals high and low in trait NA 
      should have similar levels of mood**"
p.39 特质让人 "respond with greater or lesser intensity"

⇒ AET 主张特质在【ΔE 的 gain】上，不在【μ 的常数偏移】上

⭐⭐ 但不冲突 —— 因为来源不同：
   AET 批的是「从特质推出常数偏移」
   我们的 μ 是【用户显式配置的角色设定】
   ⭐ 两条可以【并存】：μ 管"没事故意待的地方"，g_i 管"对事件多敏感"
```

## 七、⭐⭐⭐ 新参数：g_i 反应增益（AET）

```
AET 支持的写法：
   E_t = μ + ρ(E_{t−1} − μ) + g_i · ΔE_t

   g_i = 角色反应性向量，⭐【正负增益相互独立】
        (Larsen & Ketelaar 1991: 高神经质只对【负性】刺激反应，
         高外向只对【正性】反应，两者对【中性】都不反应)

⭐ 而"高 NA 恢复更慢"(p.38 Marco & Suls: "high NAs take longer to recover from 
   a stressor") → ⭐ ρ 的个体差异
```

**⭐⭐⭐ 工程价值：`g_i` 正好能做「傲娇」—— 对负性事件反应大、对正性反应小。**
**⭐ 而"恢复更慢" = ρ 更大。**

## 八、⭐⭐⭐ 新机制：情绪 ↔ 心境的开关是「原因显著性」

**AET 原文（p.18）：**
> "an emotion turns into a **mood** when one **loses the focus on the precipitating event or object**. 
> Similarly, **making the cause of the mood salient may transform a mood into a weak emotion**."

**实验支撑：让人知道心境的原因 → 心境的【全局效应消失】**
（p.19 Clore 1992；p.60 Schwarz & Clore 1983）

**⭐ 判据是【cause pointer 是否还在】，而非过了多少秒。**

**⭐⭐ 对陪伴型角色的直接用法：**
```
角色「意识到自己为什么心情不好」
  → 弥散心境【收敛】为具体情绪
  → 全局影响被【削弱】

⭐ 这解释了为什么"说出来"会好受 —— 是机制，不是心理安慰
```

## 九、⭐⭐ ΔE 是「脉冲 + 余震序列」，不是单次脉冲（AET）

```
p.43  shocks 产生 aftershocks，即 emotion episode
p.41  episode 中「小事件获得被放大的情感意义」

      ⭐ 等于一个全局增益 g_episode > 1
p.42  episode 的子事件「many caused by the coping mechanisms of the worker himself」
      ⭐ 事件会【生】事件 —— 可实现的规则
```

## 十一、⭐⭐⭐⭐ 知觉的定位（topdown2025 —— 解决「前置物/副产物」悖论）

**设定者的裁定（逐字）：**
> 「受伤的话它更想一种知觉，它更像是**体验情绪的前置物和副产物**」

**topdown2025 的答案：**
```
perception = 最小化预测误差的那个假设
情绪       = 由「预测 vs 实际输入」的匹配/失配产生
   → ⭐ 结构上知觉【确实在情绪之前】     （= 前置物）
情绪又回写先验，形成"visual confirmation bias"(p.397)
   → ⭐ 这就是【副产物】

⭐⭐⭐ 两条判据由【同一个反馈结构】满足 —— 不必二选一
```

**⚠️ 但该篇也说清了：它【没有】给知觉/情绪的形式化分界，**
**正确分界位置是「知觉估计 vs 报告偏向」（操作上用 d′/漂移率 vs c/起点 分解）。**
> "very few tasks can be unequivocally labelled as purely measures of perception" (p.391)

## 十二、⭐⭐⭐ `kind=perception` 那 39 词的重新定位（重要）

**topdown2025 的建议：**
```
Box 1 (p.390): 情绪 "should not be equated or reduced to" 语言/行为/生理指标
p.398:         interoception（身体内部信号的知觉）也算 perception

⇒ 那 39 个「词形被动 + 躯体感受」的词，判据落在【内感受通道/输入】上
⇒ ⭐ 建议把它们【移出情绪强度空间】，改做知觉层的【知觉模板】
     模板承载特征 + 知觉偏向，决定从输入里抽哪些特征 (p.397)

⭐⭐ 于是词库的角色变了：
   ⚠️ 词不是【标签】，是【特征提取器】
   ⚠️ 评价标准应是「模板独特性」，而非「分类正确率」
```

**⭐⭐⭐ 这同时解掉了设定者那个担心：**
> 「如果每次都让大肥鱼先解析然后再对情绪做出反应我感觉有些会不准」

**⭐ 按这个读法，「准」的来源是【模板稳定】，不是【分类正确】。**

**⭐ 而且 barrett2016 的说法一致：词库字段可重读为【概念先验】：**
```
释义（≤20 字） → 语义邻域
主题（19 类）   → 目标维度
方向（12 类）   → 效价
强弱（二分）    → 先验强度 / 精度
未归类词        = 先验接近均匀，等情境裁决   ← 那 41 个跨类词的地位
```

## 十三、⚠️⚠️⚠️ 两篇对我们**分类体系**的警告（必须处理）

### AET 的警告 —— 词义归纳不能外推
> "It may be true that the cognitions pertaining to emotion words can be hierarchically 
> organized **but even Shaver et al. are cautious in their willingness to extrapolate 
> to actual emotion categories**" (pp.20-22)

**反例（p.23）：`disappointment` / `guilt` / `pity` 同属 sadness 家族,但【行为后果完全不同】。**

### barrett2016 的警告 —— 本质主义与平均原型
```
p.21      点名批评「更细粒度的类型学」(finer-grained typologies)
pp.21-22  anger/sadness/fear/disgust/happiness 这些类别
          「连跨文化比较人类都不构成稳健通用框架」
pp.19-20  「能诊断悲伤的模式不是悲伤的脑状态，只是高度可变实例的统计摘要；
            把统计摘要当常模就是【本质主义错误】」
尾注24    「2015年美国家庭平均 3.14 人，但这不代表每个（或任何一个）家庭有 3.14 人」
```

### ⭐⭐⭐ 但两篇都留了出路

**barrett2016：** 反对的是【类别 = 本质】(essentialism),不是【使用类别】(categorization)
```
pp.17-18 明说不否认情绪是幻觉、情绪类别和「钱」一样真实
p.10     承认「每一个都有某个概率（以贝叶斯先验计算）」
⇒ 8 型作为【工程用概念先验】完全可用，只要：
   ① 不做互斥 one-hot
   ② 不做平均原型最近邻
   ③ 不在文档里写成情绪的【本质】
```

**AET：** 给出另一条独立证据线
```
⇒ ⭐ 从【二级评价维度】（后果 / 归因 / 应对潜力 / 未来预期）交叉验证八型/12 类
   这是与词义【独立】的来源
```

### ⭐ 我核过我们的设计，**大体天然避开了**那些做法


## 十五、⭐⭐⭐ 「模棱两可」的机制与实证

**moors2013（p.121）：**
> "**If only a few appraisals yield results, the emotional experience is relatively 
> undifferentiated and global**; if many appraisals are made, it is highly differentiated and specific."

**婴儿实证（p.121）：**
> "the **generalized distress** experienced by infants **differentiates into sadness and anger** 
> when the infant is able to **perceive differences in agency**"
> 「9 个月获得『预期』评价能力 → 才能产生 surprise」(Scherer et al. 2004)

```
⭐⭐ 「模棱两可」= 评价变量做得少，是【未分化态】，不是错误
⭐ 而"交由模型判断" = 补上更多评价变量
```

**⭐ 三层评价机制（p.120）说明这本就是正常的:**
```
rule-based      规则式      —— 常非自动，概念码
associative     关联式      —— 常自动，知觉码（学到的关联）
sensory-motor   感觉-运动式 —— 自动，感觉码（未学习的关联）
⭐ 不总是走规则推理
```

## 十九、⭐⭐⭐⭐ 汇总：对现有模块的改造建议

```
【A1 空间】保持不变
   ⚠️ AET 的二维(强度独立) vs A1 的三维(强度=模长)：
      表面冲突，实际兼容（importance 是原因，r 是结果）

【A2 动力学】建议扩展
   E_t = μ + ρ(E_{t−1} − μ) + g_i · ΔE_t          ← 新增 g_i
   ΔE_t = α_t(精度) × ε_t(预测误差) × signature    ← 乘法结构
   ε_t 可拆三旋钮：起点项(μ) + 漂移项(注意) + 标准项(期望)
   ⭐ 事件过滤：只有部分事件有情感意义 → 大量 ΔE = 0
   ⭐ 脉冲 + 余震：episode 有自我放大 + 事件自生
   ⚠️ 待裁定：是否引入成分间反馈回路

【A3 μ】建议升级
   μ = (偏移方向, precision)    ← 从一维向量变成两参数
   作用位置：知觉层的【先验】，不直接作用在情绪值上
   ⭐ 角色底色 = μ 的方向 + μ 的 precision
   ⚠️ 与 AET 的"特质不该是常数偏移"不冲突（来源不同：用户配置 vs 特质推断）

【A4 词库】建议重读 + 补验证
   ⭐ 词 = 特征提取器 / 知觉模板，不是标签
     评价标准 = 模板独特性，不是分类正确率
   ⭐ 39 个 perception 词 → 移出情绪强度空间，做知觉模板词汇
   ⚠️ 必须补：从【二级评价维度】交叉验证 12 类/八型（AET 警告）
   ⚠️ 不得写成"情绪的本质"（Barrett 警告）

【#40 ΔE 来源】架构基本定了
   事件 → 【评价层】→ ΔE → A2 动力学 → 情绪
   两级评价：一级给(价效, 强度)，二级给离散情绪
   评价变量五核心：goal relevance · goal congruence · certainty · agency · coping potential
```
