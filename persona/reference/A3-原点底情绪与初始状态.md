## 二、⭐ 术语重新指派（把两个"原点"钉死）

**原裁定里的「原点」是**比喻**（指"基准点"），A1 又引入了**几何**原点。两个词撞在一起了。**

| 原裁定表述 | 里头"原点"实际指 | 按 A1/A2/A3 改写成 |
|---|---|---|
| 「底情绪 = 三维模型的**【原点】**，不是象限点，而是**坐标系的原点**」 | **μ** | **底情绪 = μ**（球心，A1/A2 共用） |
| 「角色**从原点出发**」 | **μ** | 角色 **从 μ 出发**（`E₀ = μ`） |
| 「**原点** = 强度 0」 | **μ** | **μ 处** = 强度 0 |
| 「强度 = 【**到原点的距离**】（径向）」 | **μ** | 强度 = **‖E − μ‖** |

**⭐⭐ 而「几何原点 `(0,0,0)` = 中性」在原裁定里**压根没出现过** —— 它是这次从文献引入的新概念。**
**这就是歧义的来源。**

### 术语表（此后一律按此用）

| 术语 | 定义 | 数值 |
|---|---|---|
| **几何原点** | 中性 | `(0,0,0)` |
| **μ** | 底情绪 —— 球心 + 收敛终点 | 由用户配置 / 默认 0 / 学习得到 |
| **σ** | 情绪起伏幅度（角色参数） | 建议 0.40~0.50 |
| **ρ** | 记忆保持率（角色参数） | 0.927（半衰期 9.1 轮） |
| **r** | 强度 = `‖E − μ‖` | `0 ≤ r ≤ 1` |

## 三、初始状态：`E₀ = μ`

```
E₀ = μ
```

| 情形 | μ | 效果 |
|---|---|---|
| **用户配置了底情绪** | 配置值 | "快乐进场"就是进来时已经快乐 |
| **用户不配置（出厂）** | **0** | **理想无情绪** |
| **不配置 + 开始对话** | 由对话学到 | 从 0 起步，逐渐形成偏好 |

**⭐ 于是原裁定与新裁定**不冲突**：**

```
「从原点出发」 = μ 的默认值是 0
「快乐进场」   = 用户把 μ 配成别的值
两者都是 E₀ = μ —— 只是 μ 取不同值
```

**⭐ 原裁定不是被推翻，而是被【参数化】了。**

## 四、μ 的三个来源（优先级从高到低）

| 优先级 | 来源 | 说明 |
|---|---|---|
| **1** | **用户显式配置** | 导入角色时指定（"快乐进场"/"悲伤进场"…）。见 A2 §5.4 的八型候选表 |
| **2** | **出厂默认 `0`** | **陪伴型工作机器人的出厂状态 = 理想无情绪** |
| **3** | **由对话学习用户偏好** | 不配置时的自然路径 —— 见 §六待办 |

**⭐ 设定者明确：「用户不去配置也是可以的。」**

### ⚠️ 一个边界情况（"甲"的适用性）

严格读法要求 `μ ≠ 几何原点`，但出厂默认 `μ = 0`。**这不构成矛盾：**

```
对话开始【之前】：μ = 0 是【未初始化状态】，不是动力学状态
对话开始【之后】：μ 被配置或被学习 → 不再恒为 0
∴ 「没有回到原点这回事」在【长期意义上】成立
```

**规格约定**：`μ = 0` 是**出厂初始值**与**合法的显式配置**，但它是一条**退化路径** ——
一旦发生任何对话，`μ` 就应当离开 0（被配置或被学习）。

## 五、⭐⭐ 架构：记忆是 μ 的唯一载体

> **设定者原话**：
> 「所以我为什么前期一直疯狂装记忆插件……拥有记忆对于学习是非常重要的，因为它**同时满足了
> 衰减理论与多轮对话学习**，分析用户想要的基底情绪以及用户偏好大肥鱼往什么情绪走，
> **记忆在里面是那一根唯一的绳子**，断了只要上下文一压缩，里面忘干净，**这对体验来说是灾难性的**。」

### 5.1 三个时间尺度

| 变量 | 尺度 | 载体 | 丢了会怎样 |
|---|---|---|---|
| **E_t** | **快** —— 每轮波动（半衰期 9.1 轮） | **会话上下文** | **无所谓** —— 下一轮从 μ 重新起步 |
| **μ** | **慢** —— 跨很多轮学习 | **持久记忆（mnemon）** | **灾难** —— 学习的成果没了 |
| **σ, ρ** | **常量** —— 角色配置 | 角色配置 | 重新配置即可 |

### 5.2 ⭐ 衰减机制与记忆的关系（关键的自洽）

**衰减的设计意图不是"忘掉情绪"，而是让记忆的绳子只需承载 μ，不必承载全部历史：**

```
上下文压缩时：
   E 丢了 → 无所谓，下一轮从 μ 重新起步   ← 这正是衰减存在的意义
   μ 丢了 → 灾难，学习成果归零
```

**⭐⭐ 所以：E 可以丢，μ 绝对不能丢。而 μ 的载体就是 mnemon。**

### 5.3 ⭐ 对 Clore 增益/损失的回补

**A2 §八 记了「AR(1) 是线性模型，复现不了 Clore 的 gain/loss」。**
**但在本架构下：纯 AR(1) 只保留一个压缩状态，而 μ 记住了长期偏好 —— 一旦 μ 参与，gain/loss 就回来了一部分。**

**⭐ 即：gain/loss 不是靠 E 的状态实现的，而是靠【μ 的历史】实现的。**（此为助手推断，未裁定。）

### 5.4 μ 的持久化需要存什么（待办，见 §六）

```
每个（角色 × 用户）组合：
  · μ        当前底情绪（白化后坐标）
  · σ, ρ     角色参数
  · μ 的漂移历史（何时、因何漂移）
  · 偏好证据（哪些对话把 μ 推向了哪边）
```

## 八、与既有规格的一致性检查

| 既有裁定 | 本规格如何满足 |
|---|---|
| 强度 = 到原点的**径向距离** | `r = ‖E − μ‖`（**μ 就是原裁定里的"原点"**） |
| **球面 = 强度的极致** | `r = 1`（A1） |
| 强度与方向**正交** | A1 的球坐标 `(r, γ)` |
| **没有回到原点这回事** | 收敛到 μ ≠ 几何原点（严格读法，A2）；`μ = 0` 是退化路径 |
| 情绪由**记忆**引导 | §五 —— **μ 由记忆承载，E 由 μ 引导** |
| 记仇 / 记爱 / 记恨 | ⭐ 不是 E 的事（短期波动），而是 **μ 被长期互动缓慢改变**（底色变了） |

**⭐ 「记仇记爱记恨」的正确归属：它是 μ 的慢漂移，不是 E 的快波动。**
**—— 这解释了为什么它需要记忆：因为 μ 不在上下文里。**
