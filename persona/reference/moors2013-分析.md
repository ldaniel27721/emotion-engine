## 一、这篇讲什么（三句）

1. Appraisal 理论的核心主张：**情绪不是被事件触发的，而是被【对事件意义的评价】触发的。**
2. 该理论的存在理由是回答一件事：**为什么同一个事件,在不同人、不同场合会引出不同情绪。**
3. 本文是该 special section 的导论——界定什么是（严格意义上的）appraisal 理论、它们内部的分歧、以及未决问题。

---

## 二、核心命题（逐字引用 + 中译）

**① 基本前提**
> "The basic premise of appraisal theories is that emotions are adaptive responses which reflect **appraisals of features of the environment that are significant for the organism's well-being**."（p.119）

译：情绪是适应性反应,反映的是**对环境特征中"对有机体福祉有意义"之处的评价**。
⭐ **产生情绪的是评价,不是环境本身。**

**② ⭐⭐⭐ 整篇最重的一句（刺激-情绪 vs 评价-情绪）**
> "Appraisal theories assume that there is a **variable relation between stimuli and emotions**, but a **stable relation between appraisals and emotions**. In general, the **same appraisals lead to the same emotions; different appraisals lead to different emotions**."（p.122）

译：刺激与情绪的关系是**可变的**;评价与情绪的关系是**稳定的**。相同的评价 → 相同情绪;不同的评价 → 不同情绪。

**⭐⭐⭐ 这条决定了工程架构：ΔE 不能由【事件】直接算，必须由【评价】算。**

**③ ⭐ 情绪是【过程】不是【状态】**
> "Contemporary appraisal theories define emotions as **processes, rather than states**. This is reflected in the fact that the term emotion is often used as shorthand for an **emotional episode**."（p.119）

**⚠️ 术语分层（避免以后混淆）：**
```
appraisal 理论说的 "emotion"  = 我们说的【emotional episode】（整段过程）
我们 A1/A2 的 E（PAD 状态）  = 只是那个 episode 里的【feeling 成分】
⭐ 不矛盾 —— A2 本来就是过程（E 随时间演化）。但引用时要分层。
```

**④ 情绪过程是连续且递归的**
> "The emotion process is **continuous and recursive**. Changes in one component feed back to other components… These may, in turn, lead to changes in appraisal, either directly or indirectly (via a change in the stimulus situation)."（p.120）

**⚠️ 与我们 A2 的差异**：A2 是**单向线性** AR(1)；appraisal 理论要求**成分间互相反馈**。
→ 这可能是 #40 要补的东西（不是 bug，是模型层次不同：A2 描述 feeling 成分的演化，评价层还没建）。

**⑤ 评价的定义**
> "Appraisal is a process that **detects and assesses the significance of the environment for well-being**. Significance for well-being is best conceptualized as the **satisfaction or obstruction of concerns**."（p.120）
>
> "'Concerns' include the individual's **needs, attachments, values, current goals, and beliefs**… they include **everything that an individual cares about**."
>
> "It follows that appraisal is **inherently transactional**: It involves an **interaction between the event and the appraiser**."（p.120）

**⭐⭐⭐ 化简：**
```
event × concerns  →  appraisal  →  emotion

⭐ μ（我们的底情绪）≅ concerns 的某种投影
⭐ 同一事件对不同角色产生不同情绪，因为 concerns 不同 —— 这正是 A3 的 μ 在做的事
```

## 三、五成分结构（情绪 episode 的解剖）

> "Appraisal theories are **componential theories**… Components include:"（p.119）

| # | 成分 | 内容 | 对应我们哪一层 |
|---|---|---|---|
| ① | **appraisal** | evaluations of the environment and the person–environment interaction | ⭐ **#40 要补的那一层** |
| ② | **motivational** | action tendencies / action readiness | ⭐ 「情绪产生的行为」 |
| ③ | **somatic** | peripheral physiological responses | （不在当前范围） |
| ④ | **motor** | expressive and instrumental behavior | ⭐ 「情绪产生的行为」 |
| ⑤ | **feeling** | subjective experience or feelings | ⭐ **A1 的 PAD 球体（E）** |

**⭐⭐ 关键结构：**
```
① 评价  是【核心决定者】—— 它 triggers and differentiates（触发并分化）整个 episode
⑤ 感受  是【整合层】—— 它是其他成分的整合投影
```
> "Ellsworth (1991), Frijda (2007), and Scherer (2004) have suggested that the content of feelings represents an **integration of several or all the other components**."（p.122）

**⭐ 这给 A1 的球体一个理论地位：它是【整合层】，不是原始层。**

**⭐ 而"评价决定 intensity 和 quality"：**
> "Appraisal determines the **intensity and quality** of action tendencies, physiological responses, behavior, and feelings."（p.120）

**⭐⭐ `intensity` + `quality` 正好 = 我们的 `(r, γ)`（强度 + 方向）。**

## 四、⭐ 评价变量清单（可直接实现的）

> "…appraisal theories specify the **appraisal criteria or variables** that are most important in differentiating emotions."（p.120）

**核心五项（大多数 appraisal 理论共有）：**

| 变量 | 含义 | 可能的取值 |
|---|---|---|
| **goal relevance** | 事件与关切/目标**相关吗** | 相关 / 不相关 |
| **goal congruence** | **符合还是阻碍**（也叫 goal conduciveness / motive consistency） | 一致 / 不一致（连续量） |
| **certainty** | **确定性** | 确定 / 不确定 |
| **agency** | **施动者**（也叫 cause） | 自己 / 他人 / 无生命环境 |
| **coping potential** | **应对潜力**（也叫 control / power） | 有办法 / 没办法 |

**补充项（部分理论有）：** `novelty`（新颖性，或 suddenness/change/familiarity/unexpectedness）·
`expectancy`（预期）· `urgency`（紧迫性）· `intentionality`（故意性）·
`legitimacy`/`fairness`（正当性/公平）· `norm compatibility`（规范兼容性）

**⭐⭐ 一个可直接实现的例子（Lazarus 1991）：**
> "Lazarus (1991) hypothesized that stimuli appraised as **goal relevant, goal incongruent, and difficult to cope with** correspond to **fear**."（p.122）

```
fear ≅ 评价出: goal relevant = 是 · goal congruence = 不一致 · coping potential = 低
```

**⭐⭐⭐ 变量数 ↔ 情绪数（设计公式）：**
> "**Two appraisal variables with two values each can account for four emotions.** … **Seven appraisal variables with an infinite number of values each can account for an infinite number of emotions.**"（p.122）

**⭐ 算一下：**
```
2 变量 × 2 值 = 4 种情绪
3 变量 × 2 值 = 8 种情绪   ← ⭐ 正是我们球体的 8 个卦限（3 轴 × 2 号 = 2³）
```
**→ 我们的「八型」≅ 三个二值评价变量的组合。PAD 三轴本就是 3 维，所以 2³ = 8。**

**⭐ 变量形态可以是 categorical（离散值）或 dimensional（连续值）：**
```
Lazarus (1991)            categorical（goal congruence 只有两个值）
Ellsworth (1991)/Scherer  dimensional（潜在无限值）
Roseman (1996)            dimensional 但系统提供【锚点】→ 产生离散个值
```
**⭐⭐ 我们的设计（方向离散八型 + 强度连续 r）正属于 Roseman 那种 "dimensional with anchors"。**

## 五、⭐⭐ 三层评价机制（「模棱两可」的理论依据）

> "Appraisal theorists have proposed two or three mechanisms underlying appraisal, endorsing a **dual or triple mode view**."（p.120）

| 模式 | 机制 | 特征（Leventhal & Scherer 1987） |
|---|---|---|
| **rule-based** 规则式 | 在线计算评价值 | 常**非自动**，操作**概念码** |
| **associative** 关联式（也叫 schematic） | 激活**学到的关联**（刺激表征 → 已存评价输出） | 常**自动**，操作**知觉码** |
| **sensory-motor** 感觉-运动式 | 激活**未学习的**关联（如地面震动 → 不适 → 肌肉收缩） | **自动**，操作**感觉码** |

**⭐⭐ 而 practice 会让评价越来越自动：**
> "Appraisal theories assume that **increasing practice leads to greater automatization** and that **all appraisal variables can be processed more or less automatically**."（p.122）

**⭐⭐⭐ 这解释了「模棱两可」为什么是正常的：不是每次都走规则推理。**

---

## 六、⭐⭐⭐ 未分化 → 分化（「模棱两可」的实证）

> "Appraisal theories allow variation in **the number of appraisals** that are made. **If only a few appraisals yield results, the emotional experience is relatively undifferentiated and global**; if many appraisals are made, the emotional experience is **highly differentiated and specific**. Moreover, an emotional experience may become **more complex over several recursive cycles**."（p.121）

**⭐⭐⭐ 也就是说：**
```
评价变量做得少  →  体验【未分化、笼统】     ← ⭐ 这就是「模棱两可」
评价变量做得多  →  体验【高度分化、具体】
而且随递归轮次变复杂
```

**⭐ 「模棱两可」= 评价变量做得少。而"交由模型判断"= 补上更多评价变量。**

**⭐⭐⭐ 一个具体的实证（婴儿）：**
> "the **generalized distress** experienced by infants **differentiates into sadness and anger** when the infant is able to **perceive differences in agency**."（p.121）
> "a cognitive restructuring around **9 months of age** seems to be decisive for the operation of appraisals based on expectancy and determines the nature of the **surprise** response."（Scherer, Zentner, & Stern 2004）

```
婴儿初期: generalized distress（笼统的痛苦）
   ↓ 获得「施动者 agency」评价能力
分化成: sadness（自己无法控制）vs anger（他人造成）

⭐ 9 个月获得「预期 expectancy」评价能力 → 才能产生 surprise
```

**⭐ 「surprise 需要预期评价能力」这条,解释了为什么我们词库里 Surprise 是独立一族。**

## 七、⭐ 个体 / 文化差异（对应我们的 μ）

> "**If two people differ in their appraisal** of the event's novelty, goal congruence, controllability, or any of the other appraisal variables, **their emotions will differ correspondingly**. **If they have different concerns**, one person might appraise the event as furthering those concerns, while the other may see it as obstructing them."（p.121）

**⭐⭐⭐ 同一事件 + 不同 concerns → 不同情绪。这正是我们的 μ。**

**⭐ 文化差异的具体例子：**
> "Japanese and Americans differ in their appraisals of **agency**. **Japanese are more likely to blame themselves** for negative outcomes and to **experience shame**, while **Americans are more likely to blame others** and **experience anger**."（Imada & Ellsworth 2011，p.121）

**⭐⭐ 同一个负性结果,因 agency 评价不同 → 羞耻(Remorse) vs 愤怒(Anger)。**
**⭐ 这正好对应我们词库的两个方向类。**

**⭐ 另有：心理疾病 = 慢性功能失调的评价**
> "Some mental disorders may be characterized by **chronically dysfunctional appraisals**, as in obsessive-compulsive disease."（p.121）

## 八、⭐⭐⭐⭐ 结论段：五项输入（与我们模块的一一对应）

> "Appraisal processes do so by using information from **events in their context**, **the individual's concerns**, **history**, and **other sensitivities**."（p.123）
>
> "Appraisal processes **mediate the significance of events for the individual's well-being**."（p.123）
>
> "…the **confluence of cognition and emotion** that results when **information is viewed in the light of motivation**."（p.123）

| appraisal 理论的输入 | 我们的模块 | 现状 |
|---|---|---|
| **events in their context** | 事件 + 对话上下文 | ⭐ #40 的输入,未建 |
| **the individual's concerns** | **μ（底情绪）** | ✅ A3 已定 |
| **history** | **记忆（μ 的慢漂移）** | ⭐ #43 |
| **other sensitivities** | **σ（情绪起伏幅度）** | ✅ A1 已定为角色参数 |
| **appraisal process** | **评价层** | ⭐ **#40 要补的核心** |

**⭐⭐⭐ 五项里我们已有三项对应模块，缺的正是中间的【评价层】。**

## 九、⭐⭐⭐ 事件的复杂性与冲突（解释词库的"异常数据"）

> "emotional events are often **highly complex**. They tend to instigate various cognitive, motivational, and somatic components **simultaneously, in competition, in conflict, or in interaction**. **Many events are congruent for one concern and incongruent for another.** **One both wants something and doesn't want it**… This multiplicity is at the **core of emotion regulation**."（p.123）

**⭐⭐⭐ 这解释了词库里的跨类/跨族重复：**
```
Emotion-Feelings 表：41 个词跨 2~3 个大类（如 distressed 同属 Fear/Depression/Hurt）
Checklist：12 个词跨族（如 hesitant 属 Ambivalent–conflicted 与 Mistrustful–suspicious）
```
**⭐ 那不是分类错误,是【事件对不同关切同时一致又冲突】。**

**⭐⭐⭐ 一个**几乎逐字就是我们昨晚演的那一幕**的社交评价例子：**
> "**Cool reception of one's smile elicits the appraisal 'not welcome'** (i.e., goal incongruence) **without any abstract categorization necessary** to imbue the event with meaning and implications for action. Appraisal can occur **on the spot** in response to what another person does or does not do, **whether or not the perceiver has preexisting knowledge**."（Parkinson 2007，p.123）

```
冷遇 → 评价「不受欢迎」(goal incongruence) → 不需要抽象分类，当场发生
⭐ 昨晚演的：用户找了别的 AI → 大肥鱼评价出「不被需要」→ 委屈
⭐⭐ 两者是同一个机制
```

## 十、评价如何影响其他成分（两种方案）

| 方案 | 内容 | 出处 |
|---|---|---|
| **Proposal 1** | 评价值整合成一个**模式（pattern）** → 决定情绪 → 模式决定其他成分的值 | Lazarus 1991 |
| **Proposal 2 变体 A** | 每个评价值**直接、独立地并行**影响各成分 | Ellsworth 1991; Scherer 2009 |
| **Proposal 2 变体 B** | 评价值必须**经过动机成分**才能影响躯体与运动成分 | Frijda 2009; Scherer 2009 |

**⭐⭐ Proposal 1 的 "pattern" 正好对应我们词库的「方向类（12 类）」—— 它是评价模式的离散化。**
**⭐ 而 Proposal 2 变体 B 对应「情绪 → 行为」那条链（动机 → 躯体/运动）。**

## 十二、⭐ 对我们 A1–A4 与 #40 的直接启示

**① #40 的架构基本定了：**
```
事件 → 【评价层】→ ΔE → A2 动力学 → 情绪
         ↑
    用五项输入：事件+情境 / concerns(μ) / history(记忆) / sensitivities(σ)
```
**⭐ ΔE 不能由事件直接算（那是 variable relation），必须由评价算（stable relation）。**

**② 评价变量清单可直接实现：**
```
五核心：goal relevance · goal congruence · certainty · agency · coping potential
每项输出一个值 → 组合成 pattern → 映射到 12 方向类（Proposal 1）
```

**③ 「模棱两可」有了精确位置：**
```
评价变量做得少 → 未分化（笼统）→ 这就是模棱两可
交由模型判断 = 补上更多评价变量
⭐ 而三层机制（rule/associative/sensory-motor）说明：
  不总是走规则推理，关联式与感觉-运动式也是正常路径
```

**④ μ 找到了理论对应物：**
```
μ ≅ concerns（需要、依恋、价值观、当前目标、信念 —— "一个人所在意的一切"）
⭐ 所以 μ 的慢漂移 = concerns 的改变（#43）—— 与"用户反馈"一致
```

**⑤ 一个与 A2 的实质差异（需记下）：**
```
appraisal 理论要求【成分间递归反馈】；A2 是【单向线性】AR(1)
⭐ 不是错，是层次不同：A2 描述 feeling 成分的演化，评价层尚未建。
   #40 建评价层时，要考虑是否引入反馈回路。
```

**⑥ 待核（需另找来源）：**
- Proposal 1 的 "pattern" 具体形式（Lazarus 1991 原著）
- Scherer 的 SEC（Stimulus Evaluation Checks）序列——本文提到但没展开
- 「评价变量 → 情绪」的实证系数（本文只有 Lazarus 的 fear 一例）
