## 二、⭐ 情绪识别的方法与效果（含纯文本的性能）

### 2.1 第 1 篇（ELMO）——它就是纯文本

**【原文】输入模态**：纯文本（或语音转文本后的文本）。原文（PDF-p2，48816）：
> "we have focused on learning a model for the recognition of selected emotions present in short text fragments (available directly as text sentences or the speech of a human after transformation to text using a 'speech-to-text' application)."

**【原文】情绪类别 = 6 类**（改自 Ekman）：
> "we replaced disgust and happiness with joy and love. Our final set of recognized emotions was joy, sadness, love, fear, surprise, and anger."（PDF-p5，48819）

原文还把它们映射到极性（PDF-p5，48819）：joy/love = positive，fear/anger/sadness = negative，surprise = unexpected（*"Surprise can be both positive and negative"*，PDF-p5，Fig.1）。

**【原文】模型 = 8 层统一骨架，只换中间 2 层**（PDF-p8，48822，Fig.3）：
- 固定 6 层：Embedding（128 维）→ Dropout(0.5) → 可替换层 → 可替换层 → Global pooling → Dense(128, ReLU) → Dropout(0.5) → Dense(6, softmax)
- 7 种被替换方案（PDF-p9，48822）：
  - CNN：两个 1D 卷积（kernel 7, stride 3, 128 filters）+ ReLU
  - LSTM：两个 128 单元 LSTM，返回完整序列
  - BiLSTM：双向版两个 LSTM 层
  - GRU：两个 128 单元 GRU，返回完整序列
  - BiGRU：双向版两个 GRU 层
  - Transformer：两个 transformer block，每块 6 个子层（multi-head attention **2 heads**、Dense 128 + ReLU、2 个 layer-norm、2 个 dropout）
  - Capsule：1 个 primary capsule 层（两个 2D 卷积，第一个后接 ReLU）+ 1 个 capsule 层（1D 卷积 + **3 次 dynamic routing**）

**【原文】训练协议**（PDF-p9，48822）：
> "compiled for using categorical cross-entropy as a loss function and Adam optimizer with learning rate 0.001"、"fitted to training data for maximum 100 epochs (but early stopping based on validation data was employed) with batch size equal to 128"

**【原文】平均 20 次重复训练后取均值±样本标准差**（PDF-p9，48823）。

### 2.2 第 2 篇（ToM）——不是情绪识别论文

**【原文】它的"识别"不是分类，而是状态估计**：情绪只是 5 个被跟踪的隐变量中的 2 个（PDF-p10 / 158475）：
> "NAO evaluated and tracked the mental states, i.e., **one value for the belief** (related to the difficulty level of the puzzle), **two values for the goals** (related to quitting the interaction and to skipping the puzzle), and **two values for the emotions** (related to the frustration and the boredom) per participant."

**【原文】测量手段 = 被试自我报告，不是文本/语音/表情**（PDF-p5 / 158470）：
> "(ii) asking users to directly report their beliefs, goals, and emotions."
> 而被排除的方案是生理传感：*"measuring physiological signals, such as heart rate, to infer the anxiety levels of a user, or using visual recognition to quantify user engagement"*（PDF-p5，158470）

**【原文】测量稀疏度（PDF-p3 / 158469）**：
> "these self-report occasions were limited to, on average, **10 reports per 35 minutes** (roughly one measurement every 3.5 minutes)."
> 以及（PDF-p4 / 158470）：*"On average, **41 data points were collected per participant per session**."*

**【原文】引用 MMM 的准确率（PDF-p2 / 158468）**：
> "as demonstrated in [24], MMM achieved an **average mental state estimation accuracy of 81.55%**"
> 这句是转引 [24]（Patrício & Jamshidnejad 2023），不是本文测的。

**【推断】** 第 2 篇对我们"纯文本情绪识别"的直接贡献 = 0（它压根不从文本读情绪）。它的价值在"评价层/对方状态推理"那一侧。

### 2.3 第 3 篇（fnbot）——完全没有识别

**【原文】** 无任何模态、特征、分类器、准确率。全文唯一带"数字"的是被引文献的实验，例如（PDF-p14，第 14 页）：
> "Results of experiments showed that the accuracy in the detection of group emotion on the level of 90.84% and 89.78% in the cafeteria and the museum scenarios." —— **这是引文献 [13] 的，不是本文结果。**

**【推断】** 第 3 篇在本节得分为 0。**任何"从这篇提取情绪识别指标"的尝试都是错的。**

## 三、⭐ 可复用的形式化（公式逐字）

### 3.1 第 1 篇（ELMO）：**几乎没有形式化**

**【原文】** 全文唯一可称为"公式"的是输出层定义与训练目标：*"the second dense layer containing 6 units (reflecting six emotion classes) followed by softmax activation"*（PDF-p8，48822）；损失 *"categorical cross-entropy"* + *"Adam optimizer with learning rate 0.001"*（PDF-p9，48822）。

**【推断】** 它给的是**架构配方**（层数/单元数/kernel/heads/routing 次数），不是数学式。架构配方可原样抄去当 baseline，见第八节。

### 3.2 第 2 篇（ToM）：**有，且完整可用。以下全部逐字抄录。**

**【原文】过程方程与测量方程（PDF-p6 / 158472，(6a)(6b)）**：
```
x(k) = f(x(k−1), u(k−1)) + w(k−1)      (6a)
xm(k) = h(x(k)) + ν(k)                  (6b)
```
> "x(k) is the vector of all mental states at time step k, and xm(k) is the vector of all measured (e.g., self-reported) mental states at time step k. The vector u(k) includes the inputs at time step k, i.e., the real-world data that affects the cognition of the user. The vectors w(k) and ν(k) are, respectively, the process and measurement noise, and are assumed to follow a Gaussian distribution with zero mean and Q and R covariance matrices, respectively."

**【原文】MMM 的第 i 个状态转移分量（PDF-p6 / 158472，(7)）** —— 这是本篇最可复用的一条：
```
fi(x(k−1), u(k−1)) = wi·xi(k−1) + Σ_{i≠j} wji(k)·xj(k−1) + f_input(u(k−1))      (7)
```
> "where wi is a scalar weight that regulates the influence of xi(k) on its next realization. The terms wji(k) are weights that represent the influence of other mental state variables xj(k−1), with j≠i, on the evolved value xi(k) of mental state i. These weights are defined as **piecewise constant, depending on the region of the state space** ... **wji(k) = w+ji when xj(k) > 0, and wji(k) = w−ji when xj(k) ≤ 0**. This structure results in a **globally nonlinear function composed of multiple locally affine components**."

**【原文】测量函数（PDF-p6 / 158472，(8)）**：
```
h(x(k)) = x(k)      (8)
```
> "in our application, the measurements directly correspond to the mental states, as they are measured through self-reports from users."

**【原文】Q 的构造（PDF-p5 / 158471，(1)(2)）**：
```
Q = diag(σQ_1, ..., σQ_n)                                              (1)
σQ_i = (1/|D|) · Σ_{k∈{1,...,|D|}} ( x̂MMM_i(k) − xm_i(k) )²             (2)
```
> "we estimate each element Qi,i by calculating the **mean squared error between the prediction made by the identified MMM for the value of mental state xi(k) and the corresponding value from the collected data**."

**【原文】R 的构造（PDF-p6 / 158472，(3)(4)(5)）**：
```
σR_i,ℓ = (1/|Sℓ|) · Σ_{xm_i(k)∈Sℓ} ( xm_i(k) − x̄i,ℓ )²                  (3)
σR_i = (1/n_seq) · Σ_{ℓ∈{1,...,n_seq}} σR_i,ℓ                          (4)
R = diag(σR_1, ..., σR_n)                                              (5)
```
> 稳态段定义：*"by isolating sequences of **at least three consecutive data points** with similar values for the inputs"*、*"Sequences with fewer than three data points were excluded"*。

**【原文】EKF 预测相（PDF-p7 / 158473，(9a)(9b)）**：
```
x̂MMM(k) = f( x̂(k−1), u(k−1) )                       (9a)
P⁻(k) = F(k−1)·P(k−1)·Fᵀ(k−1) + Q                    (9b)
```
**【原文】EKF 校正相（PDF-p7 / 158473，(10a)(10b)(10c)）**：
```
K(k) = P⁻(k)·Hᵀ(k) · ( R + H(k)·P⁻(k)·Hᵀ(k) )⁻¹       (10a)
x̂(k) = x̂MMM(k) + K(k)·( xm(k) − h(x̂MMM(k)) )          (10b)
P(k) = ( I − K(k)·H(k) ) · P⁻(k)                      (10c)
```

**【原文】⭐ forward-fill-evolving 的 R 递推（PDF-p7 / 158473，(11)）** —— 这条对我们"多轮稀疏反馈"极其好用：
```
R(k) = { R0,            if mental states are measured at time step k
       { α·R(k−1),      otherwise                            (11)
```
> "where **α > 1** is a scalar parameter and R0 is the measurement noise covariance matrix calculated offline. ... the longer the gap between capturing two measurements, the less the KF relies on the measurements and the more it relies on the model estimation. ... **α effectively models the rate of decay of the confidence in reused measurements.**"
> 实验中 **α = 2**（PDF-p10 / 158475）：*"The parameter α of the forward-fill-evolving EKF (see (11)) was set to 2."*

**【原文】forward-fill 的定义（PDF-p7 / 158473）**：
> "at each time step k, the value of measurement xm(k) is set to **the most recent available measurement**. Consequently, if no new measurement is available for q consecutive time steps, the measurement xm(k) corresponding to time step k is re-used for xm(k+1), ..., xm(k+q)."

**【原文】三个假设（PDF-p9 / 158475）**：
> "Hypothesis 1: Intermittent EKF will perform similarly to the estimator in [20]. / Hypothesis 2: Forward-fill EKF will outperform the estimator in [20]. / Hypothesis 3: Forward-fill-evolving EKF will outperform forward-fill EKF, as it better balances the predictions generated by the MMM with the varying reliability of measurements over time."

**【推断】** 第 2 篇的 (7) 与 (11) 是本批**唯一两条可直接嵌进我们引擎的形式化**：(7) 对应 A2 的动力学（"其他情绪变量对自己的影响 + 分段常权重"），(11) 对应"越久没反馈 → 越信模型、越不信观测"。

### 3.3 第 3 篇（fnbot）：**没有任何公式**

**【原文】** 全文无编号公式。它"最像公式"的两句是措辞而非数学式（PDF-p14，第 14 页）：
> "the monitoring of the prediction error dynamics over time is a self-regulation mechanism behind IM ... **a positive emotional experience is linked to a continuous decrease in prediction error, conversely, a negative emotional experience to a continuous increase in prediction error over time**"（PDF-p7，第 7 页）
> "**When a faster than expected error reduction rate occurs, produces positive emotions, motivating the agent to continue with the task.** ... **A rate of minimization of the actual error which is slower than the expected one can triggers a disengagement from the task. This difference will have a negative valence**"（PDF-p15，第 15 页）

**【推断】** 可以写成 `valence ∝ sign( ė_expected − ė_actual )`，但**这是我们的推断，不是原文给的公式**——原文没写成式子。详见第八节怎么用。

## 四、ToM 心智状态估计（那篇单独一节）

### 4.1 心智状态怎么表示

**【原文】** 状态向量是 3 类变量的堆叠（PDF-p6 / 158472）：
> "The state transition function captures the dynamic evolution of **three groups of mental state variables — beliefs, goals, and emotions — where each category can include multiple variables**."
> 且 n 的定义（PDF-p5 / 158471）：*"n is the number of mental states (i.e., the cumulative number of possible beliefs, goals, and emotions)"*

**【原文】** 本实验的具体实例化（PDF-p10 / 158475）：**1 个 belief + 2 个 goal + 2 个 emotion = 5 维**：
> "one value for the belief (related to the difficulty level of the puzzle), two values for the goals (related to quitting the interaction and to skipping the puzzle), and two values for the emotions (related to the frustration and the boredom)"

**【原文】** 标量取值范围与控制目标（PDF-p10 / 158475）：
> "The objective for NAO was to select actions that **minimized the values of goals and emotions**, and brought the **belief value as close to zero as possible** — indicating that the perceived difficulty of the game was suitably balanced, neither too easy nor too hard."

**【推断】** 这是一个**连续值的心智状态向量**，不是符号化的信念逻辑。与我们"评价层"的对应关系：`belief ≈ 对局面的预测/判断`、`goal ≈ 关切(concern)`、`emotion ≈ 我们的 PAD 点`。它们被同一个线性+分段权重动力学一起推演——这正是我们 A2 想做的事的"人类侧镜像"。

### 4.2 信念/意图怎么被"估计"（而不是被分类）

**【原文】** 用的是 **EKF**，理由（PDF-p4 / 158470）：
> "while the MMM is a nonlinear model, the **degree of nonlinearity is not severe enough** to justify the use of more advanced filters"、"EKFs capture the necessary dynamics with sufficient accuracy, without incurring the computational complexity of unscented KF or particle filtering — an essential requirement in HSRIs."
> 以及拒绝黑箱：*"while model-free estimators, such as deep neural networks, can be used for state estimation, our goal is to leverage a validated and interpretable model of human mental state dynamics. Additionally, training such model-free approaches typically requires large datasets, which are generally unavailable in HSRIs."*

**【原文】** 核心机制：**预测相每步都跑；校正相只在有测量时跑**（PDF-p7 / 158473）：
> "while the prediction phase ... can be carried out in each discrete time step ... **the correction phase can only be performed when a measurement of the mental states becomes available.**"

**【原文】** 三个变体的差别就是"没测量时怎么办"（PDF-p7–p8 / 158473–158474）：
| 变体 | 无测量时 | 结果 |
|---|---|---|
| intermittent EKF | 只跑预测相，跳过校正 | 与无估计器基线一样，无改进 |
| forward-fill EKF | 用最近一次测量重复跑两相 | **最好** |
| forward-fill-evolving EKF | 同上，且每次 R(k) ← α·R(k−1) | 与 forward-fill 相当，收敛略差 |

**【原文】** 收敛性无法证明的自陈（PDF-p9 / 158474）：
> "the specific formulation of MMM is customized per participant and HSRI scenario, making a **general formal convergence proof for the proposed EKFs infeasible**."
> "Although f(·) is nonlinear, it is **piecewise affine** with respect to the state x(k) within local regions of the state space. In these regions, the EKF behaves as a standard KF, for which **local convergence** can be established under classical conditions"
> "During interaction, dynamic cognitive state variables ... may transition across these affine regions of the state space. As a result, **convergence guarantees within those regions do not generalize globally.**"

### 4.3 效果（数字）

**【原文】摘要（PDF-p1 / 158467）**：
> "the mental state estimators reduced the average error in estimation and prediction of mental states across all participants by **3% (i.e., from 12% to 9%)**, with improvements of **up to 13% for individual participants**."

**【原文】逐人结果（PDF-p12 / 158478）**：
> "forward-fill EKF yielded a lower prediction error than the baseline error for **all participants except for participant P8**."
> "For participants P1, P2, and P4, forward-fill EKF led to significant improvements ... with decreases in prediction error of **4.0%, 13.1%, and 7.6%**, respectively."
> "the maximum, median, and mean prediction errors decrease by **2.8%, 4.0%, and 2.9%**"（相对 forward-fill EKF vs 基线）
> "for participants whose baseline prediction error was already below 10% (i.e., participants P3, P7, P9, and P10), the gains were understandably minor"

**【原文】假设 3 被证伪（PDF-p11 / 158477）**：
> "In hypothesis 3, we theorized that increasing the values of the measurement noise covariance matrix R(k) ... would enhance the state estimator performance. However, **the initial results did not support this hypothesis.**"

**【原文】计算开销（PDF-p12 / 158478）**：
> "The average running times for one iteration of each state estimator were approximately **1.6 ms, 1.7 ms, and 1.9 ms**, for the intermittent EKF, forward-fill EKF, and forward-fill-evolving EKF, respectively. Additionally, the maximum time for one iteration was **3.2 ms, 4.1 ms, and 5.1 ms**."

**【原文】收敛性实证（PDF-p13 / 158479）**：
> intermittent EKF 的协方差迹"does not seem to converge for most participants, as its trace fluctuates over time"（锯齿状）；
> forward-fill EKF 的迹"shows convergence for all participants ... within the first 10 time steps and remains stable"；
> forward-fill-evolving EKF 介于两者之间，"presents a trade-off between adaptivity and convergence"。

**【推断】** 3% 的绝对改善听起来小，但注意基线误差只有 12%，**相对下降约 25%**，且对"本来误差就 >10% 的人"改善最大（P2 达 13.1 个百分点）。这对我们的意义是：**当模型本身还不错时，观测融合的收益上限本来就不高；收益集中在"模型偏了的人/时段"。**

## 五、情绪 → 回应/行为 的映射

### 5.1 第 1 篇：**有映射，但是查表式，无定量**

**【原文】** 三种输出通道（PDF-p11 / 48825）：
> "1) Visualization of emotion through his face (different type of eye animation) 2) Textual information, which is presented on computer as response 3) Speech based on the textual response"

**【原文】** 映射的具体内容 = 每种情绪一组**预先写死的英文句子**（PDF-p11–p12 / 48825–48826）逐字示例：
- joy: "i feel great today" / "i plan to visit some museum on Sunday since i like exploring artefacts from our past" / "not only yesterday's game was fabulous but i also win it"
- love: "i feel in heaven while kissing your sweet lips" / "i feel such a longing to be near him when we don't" / "i actually fell very compassionate towards her"
- surprise: "i feel funny things happening to my face and all over my body" / "i kept trying to feel shocked or depressed or somehow affected but i could not" / "i had one sip and already i feel dazed"
- sadness: "i was in cinema yesterday but the movie was rather boring" / "at the end of the day i often feel very exhausted" / "i feel a bit shamed for my behavior yesterday" / "I failed in everything"
- anger: "i don't like any unpleasant surprise" / "my tooth causes me almost unbearable pain" / "i was accused of being incompetent in my field" / "I am very angry to you"
- fear: "i often feel insecure in an unknown situation" / "i feel threatened because she attacked me with unfair accusation" / "i feel frightened to leave my wife alone"

**【原文】** 双模型架构（PDF-p7 / 48821，Fig.2）：Dataset1 训 chatbot（**从候选答案列表里选**），Dataset2 训情绪检测，"the selection of final answer need to be guided by an emotional detection model"。
**【推断】** 这是**离散情绪类别 → 预设回应池**的硬映射，没有"强度→回应强度"的定量函数。眼睛里只有 6 种固定形状（Fig.5/Fig.6，PDF-p11）。对我们的表达层（`E_outer = μ + s(E_inner − μ)`）而言，**这篇只能提供"离散标签 → 模板"的朴素对照，不提供连续映射**。

**【原文】唯一"定量"的部分是对话里的置信度**（PDF-p5 / 48819，Dialog 1）：
> "Emotion: joy (72,19%) - TRUE"、"Emotion: fear (48,04%) - TRUE"、"Emotion: joy (44,03%) - FALSE"、"Emotion: surprise (60,95%) - FALSE"
> 注释明确：*"the recognition percentage refers to the SoftMax Layer of LSTM model"*
**【推断】** 有趣的是：**软最大置信度低并不等于错，置信度高也不等于对**（44.03% 标 TRUE，60.95% 标 FALSE）。**别把 softmax 概率当"识别可靠度"用**——这是原文数据能支持的推断。

### 5.2 第 2 篇：**有定量，且是控制意义上的**

**【原文】** 行为输出的选择规则（PDF-p10 / 158475）：
> "NAO dynamically selected the **difficulty level of the puzzles** and decided whether to **display entertaining behaviors**"
> "The objective for NAO was to select actions that **minimized the values of goals and emotions**, and brought the belief value **as close to zero as possible**"

**【原文】** 这是**模型预测控制**式的最优化，不是规则表：*"MMM was embedded within a predictive model-based controller that steered the behavior of a NAO robot during interactions"*（PDF-p3 / 158469）。
**【推断】** 对我们的价值：它把"回应"变成**对隐状态的目标函数优化**（最小化负面情绪、把"难度信念"拉向 0），而不是"情绪标签→模板"。我们的表达层如果要做"傲娇式抑制"，可以借鉴这个"目标是隐变量而非表面标签"的取向。

### 5.3 第 3 篇：**只有定性方向，无定量**

**【原文】**（PDF-p15，第 15 页）：
> "When a faster than expected error reduction rate occurs, produces positive emotions, motivating the agent to continue with the task. ... **A well-done feeling, also updates the expected error reduction rate for that particular task in that particular context.**"
> "A rate of minimization of the actual error which is slower than the expected one can triggers a disengagement from the task."

**【原文】** 时间窗（PDF-p16，第 16 页）：
> "the size of this time window should **change dynamically** according to 'how well or bad things are going' ... when the error rate constantly decreases ... **the need for error monitoring diminishes**. On the contrary, if prediction errors are increasing, a more careful evaluation has to be done. In computational implementations, **less monitoring implies the liberation of resources.**"
> "in a familiar environmental context ... **the time window ... is decreased**. On the contrary, in novel or unfamiliar environmental contexts ... **the time window ... is increased**"

**【推断】** 这给的是"**自适应观测窗**"的定性规则，与我们 A2 里 `g·h(n)` 的意图同构，但没给函数形式。

## 八、⭐ 对我们引擎的可用之处

> 我们的现状：A1 `r = ‖E − μ‖`, `r²/σ² ~ χ²(3)`, 对数封顶；A2 `E_t = μ + ρ(E_{t−1}−μ) + g·h(n)·ΔE`；A3 `μ = (方向, precision)`；A4 599 词概念先验；评价层 `ΔE = α(精度) × ε(预测误差) × signature`；表达层 `E_outer = μ + s(E_inner − μ)`。

### 8.1 第 1 篇 —— 有用，但用途是"**买教训**"，不是"抄模型"

| 用在哪 | 怎么用 | 依据 |
|---|---|---|
| **A4 词库的上限证明** | 它的词表只覆盖训练集（17,094 tokens），**表外词一律 OOV→0**，作者实测自由句"unsatisfactory"。我们的 A4 只有 **599 个中文情绪词**，比它的小 28 倍。**结论：599 词绝不能单独承担"理解任意输入"的职责**；必须让 LLM 做语义层，A4 只做概念锚点。 | PDF-p12 / 48826 |
| **是否需要微调情绪分类头** | 它给了一个"够用就好"的成本基准：GRU **2.38M 参数、3.7MB（32 维 embedding）**，单句 **8–21ms**。如果我们想要一个**廉价的本地情绪粗分类器**做交叉验证/降级兜底，这个量级是可接受的。 | PDF-p11 / 48825、PDF-p13 / 48827 |
| **类别混淆的先验** | joy↔love、sadness↔anger 是双向混淆高发对（GRU: Joy→Love 29.9、Love→Joy 23.75；Fear→Surprise 14.0、Surprise→Fear 9.05）。**对我们的意义**：当 LLM 给出"喜悦/爱"或"难过/愤怒"二选一时，**不要当作独立证据产生两个方向的 ΔE**，应视为同一激活族。 | 表 4，PDF-p10 / 48824 |
| **不要把 softmax 当置信度** | 它的 Dialog 1 里 44.03% 判对、60.95% 判错。我们 A1 里 `precision` 是**先验精度参数**，不应该从分类器 softmax 直接取。 | PDF-p5 / 48819 |
| **embedding 维度可以砍** | 128→32 维，指标无变化（表 6）。**如果我们做任何本地文本向量缓存，32–64 维足够**。 | PDF-p11 / 48825 |
| **不平衡不要过度矫正** | class weights 让 Precision 从 0.884 掉到 0.867、F1 基本不变，只改变了 TP/FP 分布。**我们的 599 词分布也不均，别用重加权去"修"。** | PDF-p13 / 48827 |

**⚠️ 诚实说：它没有可直接搬进 A1/A2/A3/A4/评价层/表达层的公式或结构。** 它是一个"小模型能跑多好"的工程基准，不是一个情绪动力学模型。我们不要为了用它而用它。

### 8.2 第 2 篇 —— **有用，而且是最实质的一条：给"评价层"提供观测融合的形式**

这道题我们的痛点很明确：**LLM 给对方的意图/关切估计（= 我们的 ε 与 precision）是稀疏的、有噪声的、而且越久不用越不可信**。第 2 篇正好是这个问题的一个已发表解法。

**（a）A2 动力学的"多变量互相影响"版本 —— (7) 可直接借用**
```
fi(x(k−1), u(k−1)) = wi·xi(k−1) + Σ_{j≠i} wji(k)·xj(k−1) + f_input(u(k−1))
wji(k) = w+ji if xj(k) > 0, else w−ji
```
我们的 A2 目前只有 `ρ(E_{t−1}−μ)`（自我回归）与 `g·h(n)·ΔE`（外部驱动），**没有"其他情绪维度对自己的影响"项**。第 2 篇的 `Σ_{j≠i} wji(k)·xj(k−1)` 提示：**可以在 PAD 三维之间加一个分段常数的耦合矩阵**，并且**符号翻转用正负两套权重**（`w+`/`w−`）——这恰好能用很小的参数量表达"同类情绪的叠加 vs 反向情绪的抑制"，而且保持了"局部线性"，便于我们做 A1 的 χ² 封顶分析。

**（b）⭐ 观测稀疏时的"信模型 vs 信观测"——(11) 是我们最该抄的一条**
```
R(k) = R0 if measured at step k, else α·R(k−1),  α > 1
K(k) = P⁻Hᵀ(R + HP⁻Hᵀ)⁻¹
```
映射到我们的评价层，**不需要真的实现 EKF**，只需借它的**直觉**：
- 我们已有的 `precision`（A3 的第二个分量）就是"对 μ 的置信"。R(k) 的递推给出了**"多久没拿到新反馈就衰减多少信任"**的一个**现成、可调、单参数（α）**的机制。
- **具体建议**：给评价层的 α（精度）加一个**距上次有效评价的步数**衰减：`α_t = f(Δt)`，其中 `f` 的形式直接照 α=2 的对数线性化——原文实验用 **α = 2**（PDF-p10 / 158475）。
- **代价与收益有实测**：误差基线 12% → 9%（**绝对 3%，相对约 25%**），单步 **1.7ms**（forward-fill），**收敛在 10 步内**稳定。（PDF-p1/p12/p13）
- **⚠️ 别抄的部分**：它的 (11) 变体（forward-fill-evolving）**没能跑赢更简单的 forward-fill**（假设 3 被证伪，PDF-p11 / 158477），且协方差迹有小幅波动。**结论：先实现"forward-fill（用最近一次反馈）"，不要一上来就做 R 的在线自适应。**

**（c）"心智状态 = 连续向量 + 目标函数"的取向，用于表达层**
它的控制目标是"最小化 goals/emotions 的值、把 belief 拉向 0"（PDF-p10 / 158475）。**对我们的表达层**：`s`（抑制强度）不应是常数，而可以定义为**对某个隐目标的最优化结果**（例如"维持角色一致性 vs 表达真实内心"的权衡）。这条是设计取向，不是公式。

**（d）明确不能抄的**
- 它的"测量"是**人自己报告**（每 3.5 分钟一次），我们**没有自我报告渠道**，我们只有 LLM 对对方意图的推断。所以 (2)(3)(4) 那套 Q/R 构造**方法学上不可直接迁移**（原文自己说这些方法依赖大量数据、不适合 HSRI，PDF-p4 / 158470）。
- 5 维状态（1 belief + 2 goal + 2 emotion）**是国际象棋拼图任务专用的**，不是通用情绪空间。

### 8.3 第 3 篇 —— ⚠️ 必须诚实

**（a）对"情绪引擎"本身：直接可用性很有限。** 没有公式、没有数据、没有实现。如果目标是"抄一条形式化进去"，**这篇给不了**。

**（b）但它给了一个我们引擎**结构上确实缺的东西：**"预期改善率"作为评价的第二个自变量**。

我们现在的评价层是：
```
ΔE = α(精度) × ε(预测误差) × signature
```
**问题**：单一 ε（预测误差的大小/方向）无法区分两种情况——
- 局面在变好，但只是比"我预期的变好速度"慢 → 应该是**温和的负面**；
- 局面在变坏 → 应该是**强烈的负面**。

第 3 篇的核心主张正好补这一刀（【原文】PDF-p15，第 15 页）：
> "When a **faster than expected error reduction rate** occurs, produces positive emotions ... A rate of minimization of the actual error which is **slower than the expected one** can triggers a **disengagement** from the task."

【推断】可以形式化为（**注意：这是我们的推断，原文没有写出这个式子**）：
```
ε_appraise = ε_current − ε_expected_reduction(Δt)
```
即在 ε 之外引入一个**参考轨迹** `ε_expected(Δt)`（"在这个时间尺度上，误差本该降到多少"），评价的是**残差/斜率差**，而不是误差本身。这与我们的 `g·h(n)` 同族（都是"随重复而变化的增益/期望"），但**h(n) 是"重复次数"的函数，而 ε_expected 是"时间窗内改善速率"的函数**——两者可以正交叠加。

**（c）它同时给了一个"自适应时间窗"的规则**（PDF-p16，第 16 页）：误差持续下降 → 缩短/降低监控；误差上升 → 加长/加强评估；**熟悉情境 → 缩短窗（预期改善快），陌生情境 → 加长窗（预期改善慢）**。
【推断】映射到 A3：**`precision` 高（熟悉/有概念先验）→ 评价窗短、要求即时改善；`precision` 低（陌生）→ 评价窗长、容忍慢改善。** 这给的是一种"不要对陌生局面过早失望"的机制，和 A4 的概念先验天然对齐。

**（d）【原文】它自陈的定位（PDF-p2，第 2 页）**：
> "it is suggested that, although there are innumerable elements related to the agent, the environment, and the task, the particularity of a context is constituted by means of the specific **physiological needs, motivations and associated emotions** that are experienced"

**（e）⚠️ 最该说的实话**：这篇**不是情绪识别文献，也不是情绪计算模型文献**，它是"情境(context)分类学 + 预测误差假说"。**把它列进"人机情绪三篇"这个清单，本身就是一次错配。** 如果我们只能从它拿一条东西，就拿"**评价应该参考预期改善率，而非仅预测误差**"这一条，并且明确它是**灰色文献级别的定性主张**（无实验支持），不要在我们的文档里给它过度权重。
