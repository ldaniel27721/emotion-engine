## 二、数学形式化

```
E_t = μ + ρ·(E_{t−1} − μ) + ΔE_t
```

| 符号 | 含义 | 性质 |
|---|---|---|
| `E_t` | t 时刻的情绪状态（**白化后**坐标，见 A1） | 3 维 |
| `μ` | **底情绪** —— 球心 + 收敛终点 | **角色配置项**，由用户指定 |
| `ρ` | **记忆保持率** | 角色参数，`0 < ρ < 1` |
| `ΔE_t` | 本步**事件**引起的情绪变化 | **来源机制另立待办**（见 §八） |

**强度**（与 A1 衔接）：
```
r = ‖E − μ‖            距球心的距离，不是距几何原点
r²/σ² ~ χ²(3)          稳态分布（A1 保证）
σ² = s² / (1 − ρ²)     其中 s = 单次冲击的敏感度（导出量）
```

**半径 1**：`r = 1` 即球面（强度的极致）。

## 三、⭐ 为什么是方案 B —— 它是被 A1 唯一确定的

**推导链（不是偏好）：**

```
① A1 已定：白化后 r²/σ² ~ χ²(3)
② 要产生这个稳态，径向漂移【必须】是线性的 ——
   Fokker–Planck 反解：若 p(r) ∝ r²·exp(−r²/2σ²)，则

       a(r) = 2D/r − D·r/σ²
              ↑          ↑
        三维扩散的     线性回复项
        自然外向压

③ 那个线性回复项正是 AR(1) 的连续极限
④ AR(1) 无新事件时几何收敛到【固定点】
⑤ 裁定②（严格读法）→ 固定点不能是几何原点
⑥ ∴ 固定点只能是 μ
```

**⭐ 推论：A1 的 μ（白化中心）与 A2 的收敛点 μ 是**同一个东西** —— 两个规格共用同一个参数，模型闭合。**

## 四、⭐ 球心 = μ，几何原点落在球内（重要澄清）

**球心在 μ、半径 1 时：**

```
几何原点 (0,0,0) 距球心 ‖μ‖ —— 它落在【球内】，不再是球心
「中性」从此是球内一个【具体位置】
```

**⭐⭐ 这恰好解释了设定者那句「人怎么可能没有情绪，就算心中毫无波澜也不可能是原点」：**

| 概念 | 是什么 |
|---|---|
| **几何原点 `(0,0,0)`** | **中性**（Russell/Wen/Zhang/Gao 四处文献一致确认）—— 参考系上的零点 |
| **μ（球心）** | **底情绪** —— 角色没事时待的地方，**通常不等于中性** |

**⚠️ 因此在实现中，`r` 必须按 `‖E − μ‖` 计算，不能按 `‖E‖`。**

**✅ 而 A1 的全部结论保持** —— 因为 r 仍满足 `r²/σ² ~ χ²(3)`（球心平移不改变分布形状）。

## 五、底情绪 μ 的约束

### 5.1 硬约束

```
‖μ‖ < 1        底情绪本身必须在球内
```
若 `‖μ‖ ≥ 1`，角色的**日常待机位置**就已经是极端情绪 —— 自相矛盾。

### 5.2 软约束（"不激进"）

| 档位 | 公式 | σ=0.40 | σ=0.50 | 语义 |
|---|---|---|---|---|
| 严格 | ≤ σ·√χ²₃(50%) | 0.615 | 0.769 | 只能是最常见的强度 |
| **建议** | **固定 0.40 ~ 0.50** | — | — | **底情绪是"人设"，不该随 σ 变** |
| 宽松 | ≤ σ·√χ²₃(75%) | 0.811 | 1.013 ⚠️ | 已接近上缘，对高 σ 会越球 |

**⭐ 建议取固定档 `r_μ ∈ [0.40, 0.50]`：**
底情绪描述的是**角色的性格底色**，不该因为角色"更情绪化"（σ 大）就跟着变强。
**"快乐进场"就是快乐进场，不管这个角色多情绪化。**

### 5.3 底情绪 = 方向 × 强度

```
μ = r_μ · γ_μ
    γ_μ = 底情绪的方向（取八型方向，或指定情绪词的方向）
    r_μ = 底情绪的强度（建议 0.40 ~ 0.50，硬约束 < 1）
```

**⭐ 关键设计：只取代表词的**方向**，不用它的**原始强度**。**
（R&M 1977 的 `Happy` 原始 r = 1.062 已越界，直接当底情绪显然不合适。）

### 5.4 底情绪候选表

| 八型 | 代表词 | 方向 γ | μ（取 r_μ = 0.45） |
|---|---|---|---|
| Exuberant | Happy | ( 0.76, 0.48, 0.43) | ( 0.34, 0.22, 0.19) |
| Dependent | Loved | ( 0.84, 0.52, −0.17) | ( 0.38, 0.23, −0.08) |
| Relaxed | Relaxed | ( 0.83, −0.56, 0.07) | ( 0.37, −0.25, 0.03) |
| Docile | Sheltered | ( 0.24, −0.61, −0.75) | ( 0.11, −0.28, −0.34) |
| Hostile | Angry | (−0.62, 0.72, 0.31) | (−0.28, 0.32, 0.14) |
| Anxious | Fearful | (−0.66, 0.61, −0.44) | (−0.29, 0.28, −0.20) |
| Disdainful | Disdainful | (−0.91, −0.31, 0.26) | (−0.41, −0.14, 0.12) |
| Bored | Bored | (−0.68, −0.65, −0.34) | (−0.31, −0.29, −0.16) |

**⭐ 指定原点（`μ = 0`）也允许**（设定者明确说了），但那意味着"毫无情绪" —— 设定者认为不现实。

### 6.1 半衰期 ↔ ρ

| ρ | 0.70 | 0.80 | 0.85 | 0.90 | **0.927** | 0.95 | 0.97 |

### 6.2 σ × ρ → 导出的 s

| σ \ ρ | 0.90 | **0.927** | 0.95 | 越界率 | ‖μ‖ 上限（球内） |
|---|---:|---:|---:|---:|---:|
| 0.40 | 0.174 | **0.150** | 0.125 | 10.0% | 0.811 |
| 0.45 | 0.196 | 0.169 | 0.141 | 17.6% | 0.912 |
| 0.50 | 0.218 | 0.188 | 0.156 | 26.1% | 1.000 |
| 0.55 | 0.240 | 0.206 | 0.172 | 34.7% | 1.000 |

**实测参照**（Gao 2008 Table 4.1 的 |ΔE|）：轻微 0.09 · 典型 0.15 · 明显 0.22 · 强烈 0.27 · 最强 0.38
**⭐ 所有候选导出的 s 都落在 0.15~0.22（典型~明显）—— 都在实测范围内。**

### 6.3 角色参数一览

| 参数 | 含义 | 建议值 |
|---|---|---|
| **σ** | 情绪起伏幅度（"情绪化程度"） | 0.40 典型 / **0.50 情绪化** / 0.30 冷淡 |
| **ρ** | 记忆保持率（"情绪多难消退"） | **0.927**（半衰期 9.1 轮） |
| **μ** | 底情绪（方向 + 强度） | 方向取八型；强度 **0.40~0.50** |
| **s** | 单次冲击敏感度 | **导出量**，`s = σ√(1−ρ²)` |

**⭐ 大肥鱼是「非常情绪化」→ σ 建议取 0.50（越界率 26.1%，中位强度 0.769，"常在球面附近"）。**
**⚠️ 但 σ 的最终取值待设定者确认（问题见 §九）。**

## 八、被排除的方案（记录理由）

| 方案 | 内容 | 结论 |
|---|---|---|
| **C · 加权平均** | `E_t = N_t/W_t`，无事件时**冻结** | ❌ **数学上不可能** —— 要求 `σ < s`，但实测 s ≤ 0.384 而 σ = 0.40 |
| **D · 切向累积 + 径向压缩** | `E_t = E_{t−1} + ΔE_t·(1−r²)^α` | ❌ **分布不符** —— 50000 步模拟显示状态被压在 r≈1（中位 0.99），与 A1 的 χ²(3) 严重不符（90% 分位差 −0.437） |

**⭐ 排除 C 的判据是硬的**：`σ² = s²(1−ρ)/(1+ρ)` 要求 `k = σ²/s² < 1`，
而实测典型 s = 0.203 时 k = 3.90 —— 远大于 1。
