
## 零点五、理论基座 · PAD 情绪状态模型（原文摘录）

**来源**：`E:\dsh\character-style\ap2024143_341134453.pdf`
**文献**：熊瑛《维度情感模型研究现状综述》，心理学进展 Advances in Psychology，2024, 14(3), 270–278，DOI: 10.12677/ap.2024.143158
**摘录时间**：2026-10-10 00:39 (+08:00)
**性质**：**原文摘录，不含助手的推导**。下面每条都可在 PDF 第 3–6 页逐字复核。

### 来源链条

```
Osgood (1966)：个体判断各种刺激时，都关注其在【价值、活力、力量】三个因素上的语义差别
        ↓
Mehrabian & Russell (1974)：在此基础上提出情绪状态的三维度模型 PAD
```

### 三个维度（论文逐字）

| 维度 | 又名 | 定义 | 两端 |
|---|---|---|---|
| **愉悦维 P** | **效价维** | 情绪状态的积极或消极 | 苦恼 ←→ 狂喜；积极如兴奋、爱、平静，消极如羞愧、无趣、厌烦 |
| **唤醒维 A** | **激活维** | 生理活动和心理警觉水平 | 睡眠、厌倦（低）←→ 清醒、紧张（高） |
| **支配维 D** | **注意维 / 能量维** | 影响周围环境及他人、或反过来受其影响的感受 | 愤怒、勇敢（高）←→ 焦虑、害怕（低）；**高 D = 有力、主宰感**；**低 D = 退缩、软弱感** |

### 八种情绪类型

```
高兴 · 无聊 · 依赖 · 蔑视 · 放松 · 焦虑 · 温顺 · 敌意
```
> Mehrabian & Russell (1974) 用这三个维度**成功解释了其他 42 种情绪量表中的大部分变体**。

### PAD 的看家本领（论文原话）

> 以往的情绪研究多集中在愉悦度与激活度上，**但这两方面都无法有效区分愤怒与恐惧等情绪**。PAD 三维情感模型之所以能够分辨出这几种情绪，是因为**这两种情绪都是愉悦度较低和激活度较高，但从优势度来看则恰恰相反**。

### 论文明确写出的 PAD 局限

> PAD 模型有能力描述无数的情感，**但它仍未能完全涵盖所有人所能体验到的情感**。例如「**惊讶**」这一概念就在该情感空间外部并未被完整表示出来（D'mello & Kory, 2015）。
> → 因此一些研究者把**期望维**（衡量个体情感突发事件的指标，即个体的预测和准备能力的缺失程度）与**强度维**（衡量个体偏离冷静状态的程度）**作为 PAD 的第四和第五个维度**（Gunes & Schuller, 2013）。

### PAD 情感量表（§(三)）

```
提出者    Mehrabian (1995)
原版      34 个项目，分别测量 P、A、D 三个维度
简化版    12 个项目
中国化    中科院心理所修订 → 9 点语义差异量表
          每项目 = 一对表示不同情感状态的形容词
          最终得分 = 该维度 4 个项目得分的【平均数】
信度      α = 0.85 (P) / 0.58 (A) / 0.72 (D)
常模      北京地区 1000 名大学本科生（李晓明等，2008）
```

**中美差异（论文实测）**：
```
愉悦度 P ：无显著差异
优势度 D ：无显著差异
激活度 A ：中国人【显著低于】西方人        ← 情感计算领域须留意
```

**一条经验规律（论文原话）**：
> 愉悦度越高或越低，情感激活度就越高；而趋近中性的情感激活度则更低。
> **因此，愉悦度和激活度的散点图呈【抛物线状】**，这可能反映了正、负和中性情感的固有特征。

### 6.1 三轴（设定者给法 · 逐字）

```
x+ 高愉悦   x− 低愉悦        x 轴代表【个体感觉】
y+ 高主观   y− 低主观        y 轴代表【个体行为】
z+ 高唤醒   z− 低唤醒        z 轴代表【个体思维】
```

| 轴 | 正端 | 负端 | 该轴代表 | 对应 PAD |
|---|---|---|---|---|
| **x** | 高愉悦 | 低愉悦 | **个体感觉** | P 愉悦度 |
| **y** | 高主观 | 低主观 | **个体行为** | D 支配度（设定者标签为「主观」） |
| **z** | 高唤醒 | 低唤醒 | **个体思维** | A 唤醒度 |

> **⚠️ 与零点五并存的一处差异（不裁决）**：PDF 摘录写 D「又名**注意维 / 能量维**」，设定者写 D = **主客观 / 优势度**。两说并存，**标待核**。

### 6.2 三轴的语义分工

```
x 轴 · 个体感觉 —— 内部感受的正负（好不好受）
y 轴 · 个体行为 —— 外部可观察的行为姿态（硬不硬）
z 轴 · 个体思维 —— 认知与警觉水平（想不想得动）
```

**⭐ 三条轴恰好落在角色的三层结构上**（此对应为 **助手观察，未经裁定**）：

```
x 感觉  ↔  ① 内心状态（情绪底色，可撒谎）
y 行为  ↔  ② 表面姿态（外壳）    ← 正是"内容越硬外壳越薄"所描述的那条轴
z 思维  ↔  ③ 认知层              ← 正式规格里尚未单独列层的维度
```

**这解释了文件里 P-3 / P-4 两条接口为什么成立**：
- **P-3**（D 支配度 ↔ ② 表面姿态的硬度）成立，因为 **y 轴的定义就是「个体行为」**，而外壳正是行为层。
- **P-4**（低 D = 退缩、软弱感 ↔ 被戳中 → 软弱退化）成立，因为 **低主观 = 行为上的退缩**，而「退化」是退缩的极端形态——**两者在同一根轴上，只是取值不同。**

## 一、四个要素（本文件的骨架）

```
要素①  底情绪清单   —— 有哪些可以当"底"（自变量）
要素②  强度轴       —— 每个底情绪能升到多强
要素③  退化路径     —— 强到某点会往哪走
要素④  外壳映射     —— 每个强度/路径上，姿态（②层）怎么变
```

**规格已给的一条总原则，是本要素④的唯一已知依据：**

> **「内容越硬外壳越薄，但永不归零」**

**其主语的分配（在分层整合里已确立）：**

```
内容（情绪） = 自变量
外壳（嘴硬） = 因变量
```

## 二、要素① · 底情绪清单

**来源：分层整合的 ① 层（内心状态）剩余成员。**

```
雀跃 · 兴奋 · 期待 · 被戳中
```

**⚠️ 待裁定：**

- [ ] **`被戳中` 算不算"底情绪"？** 分层整合里已标出疑问——它的描述是"触发后通往软弱退化"，**听起来是【触发事件】而不是【状态】**。若是，则要素①只剩 `雀跃 · 兴奋 · 期待`，而 `被戳中` 归入要素③（退化路径的入口）。
- [ ] **④ 层的 `不安 · 失落 · 酸` 算不算"底情绪"？** 它们已被单拎为强负面/彩蛋，**可能是"底情绪升到高强度后的形态"，而不是独立的底**——这直接决定要素②的写法。
- [ ] 底情绪是否还有未列出的成员（原规格里没穷举）。

## 三、要素② · 强度轴

**已知输入：**

- **`B · 间隔分档` 已裁定**（来自 A–D 框架）：
  > 单位秒/分/小时/天/月作情绪旋钮、小数点后 7 位四舍五入、一次一单位、频率 3–5 轮
- **即：强度是可量化的，且量化单位是【时间间隔】。**

**⚠️ 待裁定：**

- [ ] **强度轴是所有底情绪共用一条，还是各自一条？**
- [ ] **档位怎么分？**（A–D 框架里的 A 是"时段粒度"、B 是"间隔分档"，**C「每档输出什么」仍在展开中**，正是本要素的落点。）
- [ ] **强度的上下限**：`内容越硬外壳越薄` 说明强度无上限（外壳趋近于零但不归零）——**但"归零"的判定标准是什么？**

## 四、要素③ · 退化路径

**唯一已知的一条：**

```
被戳中  →  软弱退化
```

**设定者原话（2026-10-10 00:11）**：「被戳中后可以去往软弱退化」

**⚠️ 待裁定：**

- [ ] **【软弱退化】是什么？** 它是 ④ 类（强负面/彩蛋）的一个**状态**，还是一条**路径的终点**，还是一个**过程**？
- [ ] **哪些底情绪能通往它？** 只有 `被戳中`，还是负向情绪都能？
- [ ] **退化是单向的吗？** 退化之后能回来吗？回来走什么路？
- [ ] 除「被戳中 → 软弱退化」外，**是否还有其它路径**（例如 `期待 → 失落`、`兴奋 → 不安`）？

## 五、要素④ · 外壳映射

**已知输入：**

- **分层整合 ② 层**（表面姿态，6 个）：`嘴硬 · 防御 · 逞强 · 软化 · 退让 · 松弛`
- **姿态的判据**：这一类**可以和底下的情绪相反 = 会撒谎的通道**
- **总原则**：内容越硬外壳越薄，但永不归零
- **④ 类 `不安` 的特殊用途**（设定者 2026-10-10 00:06 原话）：
  > 「不安在我的设定上有其他用途，你可以先理解为**一种完全演出，把娇展现得淋漓尽致让人心疼**」

**⚠️ 待裁定：**

- [ ] **强度 → 姿态的映射表**：强度每升一档，姿态怎么变？（本要素的核心，且**属于"演出规则"，在设定者裁定前不得填写**）
- [ ] **尾巴通道的取值**（规格：尾巴是不说谎的通道，一条回复最多出现一次）——它在动力学里对应哪个要素？**是"真实情绪"的直读口，还是"强度"的刻度？**
- [ ] `不安` 的「完全演出」在动力学里怎么定位——**是某个强度档上的必然表现，还是一条独立的特殊路径？**
