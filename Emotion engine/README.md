### `0.1.6-beta`（2026-10-13）—— P2：B2 情境分段 · B7 标注 · B8 漂移标定

#### 🔴 B8 标定查出一个**真问题**

```
现行默认 drift(rate=0.02/次) ⇒ 只需 17.5 轮就顶到 maxDrift(0.35)
若每天 20 轮 ⇒ 【0.88 天】
⚠️ 而文献（nihms）说：人类 PA/NA 在 60 天内都不显著漂移（p=0.10 / p=0.84）
⇒ 差【两个数量级】
```

**反解：** `rate ≤ δ / (60 × N)`，取 N=20、δ=0.05 ⇒ 上界 `4.167e-5`
⚠️ 圆整必须**向下**（曾误取 `4.2e-5` —— 向上圆整会突破上界，被测试当场抓出）

| 项 | 值 |
|---|---|
| 新增常量 | `DRIFT_RATE_CALIBRATED = 4.0e-5`（比默认小 **500 倍**）|
| 60 天位移（最坏情形） | **0.048** ≤ δ(0.05) ✓ |
| 到上限 0.35 需要 | 8750 轮 = 437 天 = **1.20 年** |
| 平凡情形（无事发生） | 位移 **0.000000** ⇒ μ 完全不动 |

**⭐ 语义澄清（与 A3「记忆是 μ 唯一载体」相容）：** `drift` 的输入是**记忆积累量**，不是时间本身 ——
"60 天看不出"只约束**平凡情形**；发生重大事件时 delta 变大，μ 自然可以更快移动。
⚠️ `drift()` 的默认 `0.02` **保留仅为向后兼容**，不改既有调用者行为。

### `0.1.5-beta`（2026-10-13）—— B4 裁定：ρ 与 h(n) 是**两根轴**

**⭐ 设定者裁定"甲"：两轴分开，各为独立参数**（不是过参数化）。

**文献侧的主张（同源）：**
```
Déniz et al. (2004) 底层是 Stanley (1976) 一阶 ODE：
    y_t = y₀ + λ(y_{t−1} − y₀) − (Δt/τ)·S_t
⇒ 习惯化时间常数 = 恢复时间常数 = τ/α  ⇒ ρ 与 h(n) 共用同一时间常数
⇒ 把两者当独立旋钮 = 过参数化
```

**本项目的反论（不同轴）：**
```
⚠️ 该 ODE 里【时间步 t 与刺激步 S_t 是同步的】—— 只有一根轴
本项目有两根：
    ρ  的轴 = 对话轮次（每轮必然过一次）
   h(n) 的轴 = 同类事件的发生次数（只在该类事件出现时推进）
⭐ 第 2 轮"什么都没发生"时：ρ 该推进，h 不该推进
   ⇒ 两轴语义上必须分开
```

**⭐ 数值验证（`demo/test-b4-axes.js`，9 项全绿）—— 两轴不可互换：**

| 判据 | 实测 |
|---|---|
| 等值线随情境改变 | 固定 ρ=0.900，密集/稀疏要达成同一 r，所需 α 相差 **0.5893** |
| 存在"密集可达、稀疏不可达"的目标 | r=0.70：密集 6/6 有解、稀疏 **1/6**；r=0.80：密集 6/6、稀疏 **0/6** |
| α 的影响面不对称 | 密集 Δ=1.1945 vs 稀疏 Δ=0.1172 ⇒ **10.20 倍** |
| 强行令 α ≡ ρ 的偏差 | 最大 **0.4152** |
| 语义可分离 | `eventKey=null` ⇒ h=1 但 ρ 照常推进；只开事件轴 ⇒ h = 1.000→0.500→0.250 |

**结论：** 文献的限制条件是【时间步 ≡ 刺激步】；本模型放宽为【一轮内事件数可变（0/1/N）】。
因这个放宽，原本共用 τ/α 的两个速度被**解耦** —— ⭐ 不是过参数化，是**模型的自由度确实更高**。

⚠️ **残余风险（诚实标注）**：数值上不排除二者"应当相等"（可能是同一个神经时间常数被采样到不同轴）。
本引擎**没有真实数据，无法实证**；将来若有数据可做【锁定检验】：把 `α_habit` 锁到 ρ，看拟合损失多少。

**落点**：`docs/06` 的 B4 · `docs/08` 第八节 · `demo/test-b4-axes.js`（新增，9 项）

刺激（= change）
  │
  ├─ 事件过滤器 ────────── 只有部分事件有情感意义 → 大量 ΔE = 0
  │
  ├─ 评价层（两级）──────── ⭐ 本节是 #40 的核心
  │    一级：goal relevance · goal congruence · importance
  │          → 输出（价效, 强度）
  │    二级：agency · coping · certainty · expectancy · intentionality
  │          → 输出 12 方向类 → 八型
  │
  ├─ ΔE（乘法结构）──────── ΔE = α(精度) × ε(预测误差) × signature
  │
  ├─ A2 动力学 ─────────── E_t = μ + ρ(E_{t−1} − μ) + g(策略)·h(n)·ΔE
  │                        再经对数封顶 f(r) = 1 − (1+r)^(−k), k = 1/σ
  │
  ├─ E_inner ───────────── 里层真实情绪
  │
  ├─ 表达层（傲娇）──────── E_outer = μ + s·(E_inner − μ)
  │                        s = 抑制强度（18 亚型 + 情境触发）
  │
  └─ 行为 ───────────────  强度↑ → 尝试更多策略；但削弱"投入型策略"的效果
```

## 四、核心公式

```
【A1 空间】
  白化       y = L⁻¹(x − μ)          （Cholesky）
  方向       γ = y / ‖y‖
  强度       r = ‖y‖
  量程       r² / σ² ~ χ²(3)          （σ = 角色参数）
  ⭐ 封顶     f(r) = 1 − (1+r)^(−k)     k = 1/σ
             lim(r→∞) f(r) = 1（永不到达）—— "球面"从阈值变成渐近极限

【评价层】
  一级:  价效 = congruence × relevance
         强度 = importance × relevance × (1 + 0.5(1 − expectancy)) × (1 + 0.3·arousal)
  二级:  (agency, coping, certainty, expectancy, intentionality) → 12 方向类 → 八型
  门控:  α = max( relevance × importance, (1 − certainty) × relevance )

【ΔE】
  ΔE = α × ε × signature
       ε = |valence − expectedValence| × 0.5 + 0.5(1 − certainty)

【A2 动力学】
  E_t = μ + ρ(E_{t−1} − μ) + g(策略) · h(n) · ΔE
        h(n) = α_habit^(n−1)           α_habit ≈ 0.93–0.96
  再经封顶
  ⚠️ 稳态（线性时）r_∞ = |ΔE| / (1 − ρ) —— ρ=0.927 时放大 13.7 倍，
     故封顶是必需的

【A3 底情绪】
  μ = (方向, precision)
  贝叶斯读数 后验 = (μ/var_prior + 事件/var_lik) / (1/var_prior + 1/var_lik)
  慢漂移：μ ← μ + rate · unit(Δ)，上限 0.35

【表达层】
  E_outer = μ + s · (E_inner − μ)
  s = clamp( s₀ + 状态偏移 + 事件累积 + 疲劳 )
  状态类：audience −0.40 · alone +0.55   （幂等，不叠加）
  事件类：calledOut +0.45 · flustered −0.25 · impulse +0.30 · intimacy +0.10
```

## 六、已知限制

```
· ρ、σ、α_habit 的取值均为工程标定，非文献值
· 习惯化的时间尺度只有 trial 轴数值，无物理时间常数
