## 1. 为什么需要这一层

此前三条事实并存（交接文档 docs/15 §「当前真相」）：

```
① 引擎是真的 —— 它算的数就是它算的
② 喂料是模型填的 —— appraisal 由模型逐轮直填，引擎不读文本
③ 驱动是假的 —— 说话时不读 E，脾气是按人设规格演的 【没接上】
```

把「③」补上的最小条件：

```
消息 → 算 appraisal → 跑引擎 → 把 E 和 s 注进上下文 → 照着说 → 回写状态
```

而「让模型自己去 git 读文件」这条路**在方法上就不成立**：读不读取决于模型这一轮想不想得起来，
而「想不想得起来」本身由人设提示词决定 ⇒ 输出里分不清哪句是引擎给的、哪句是演的，变量没隔离。
**结论：必须是每轮自动注入（插件），或每轮显式调用（skill + 自觉）。**

（同构先例：`dsh-time-context` 的 README 逐字写着「skill 只在模型记得调用时生效，而 LLM 自己没有钟」。）

## 2. 两条路

| | 插件版 | 轻量 skill 版 |
|---|---|---|
| 落地 | `plugin/dsh-emotion-engine/` | `skill/emotion-engine/` |
| 注入 | **自动**（`systemPrompt.context()`，order 135） | 手跑 `node scripts/ee.mjs state` 贴进上下文 |
| 回写 | `emotion_appraise` 工具（工具返回即含新状态） | 写 json → `node scripts/ee.mjs step --file x.json` |
| 记忆 | 每轮自动写 mnemon（非阻塞） | `step --mnemon` 按需写 |
| 代价 | 要改 DSH profile（热加载风险） | 零配置，但**靠自觉** |
| 状态 | **共用同一个账本** `~/.dsh/emotion-engine/ledger.jsonl` | 同左 |

两条路可以互换、并存：账本一样，谁跑谁就在推进同一个角色。

## 3. 核心设计：账本 + 重放（不序列化状态）

docs/15 §4 的裁定是「v1 公式下递推写法失效 ⇒ 必须保留事件账本」。这条裁定反过来给了一个便宜：

**引擎是确定性的** ⇒ 状态不必序列化，**重放账本就能恢复**。

```
ledger.jsonl   每行一轮：{turn, at, session, senderId, text, summary, emotion, intensity,
                          eventKey, triggers, strategyScale, scene, appraisal{九项}}
     │  load()
     ▼
Character（A1–A4 + 表达层）  +  EmotionMemory（情绪残余）
     │
     ▼
当前 E_inner / E_outer / s / 八型 / 残余记忆  →  注入 + 工具返回
```

好处：进程被杀、DSH 重启、换会话都只是「再放一遍」；账本本身是人类可读的审计记录。

⚠️ **实测踩到的坑（已固化为回归测试）**：账本里没给的 `strategyScale` 存成 `null`，
而 engine 里判断写的是 `ctx.strategyScale === undefined ? 1 : …` ⇒ `null` 会让 `g = null` ⇒
`ΔE` 被乘成 0 ⇒ **E 永远不动**。重放时必须把 `null` 归一成 `undefined`。

## 5. 记忆：为什么走 mnemon，怎么走

- **情绪只有一条 E（不分对象）**，**记忆按 `senderId` 分桶** —— 两者作用域刻意不同（docs/15 §3）。
- 写入 mnemon 走 CLI 的 **`import` + 草稿 JSON**，不走 `remember "正文"`：
  正文里带引号/分号时，命令行参数会被 shell 解释；草稿文件只有一个路径参数，零引号风险。
  并且 `import` 与 `remember` 走同一条写路径（去重 / 冲突检测 / 图边 / 嵌入 / 生命周期打分）。
- 调用方式：`spawn(process.execPath, [cli, 'import', file, '--no-diff'])`，`shell:false`。
- 草稿格式（已用 `mnemon import --dry-run` 验过）：`{schema_version:"1", insights:[{content,category,importance,tags,entities,source}]}`。
- 默认**不挡回复**（`mnemon.blocking:false`）：写失败只记 `mnemon.log`，本地账本仍是真相。
