## 二、⭐ 五条独立汇合的结论

### ① ΔE 必须由【评价】算，不能由事件直接算

```
moors2013:  "variable relation between stimuli and emotions,
             but a stable relation between appraisals and emotions"
AET:        两级评价（一级 → 价效+强度；二级 → 离散情绪）
Mageed:     ℱ 的六元分解把 S(刺激) 与 C(评价) 拆开
topdown2025: 知觉层在情绪之前，情绪由"预测 vs 实际"的匹配/失配产生
⇒ ⭐ 四方独立一致
```

### ② μ 应升级为「方向 + precision」

```
topdown2025: μ 是【知觉层的先验】，只改 starting bias、不改 drift rate (pp.397-398)
SMC2019:     习惯化速率 ∝ SpI/Sl（SpI = 初始不确定性 = precision 的倒数）
barrett2016: 精度门控决定哪个预测误差被学 (p.15)
⇒ ⭐ 三方独立一致
```

### ③ ρ 不该承担全部「变小」——**三批独立**

```
衰减习惯化两篇: ρ 是"唯一不被任何个体差异预测"的指标 (p=0.415)
强度习惯化两篇: 习惯化速度也不由基线/特质预测
                （基线 anxiety BF₁₀=0.04 / excitement 0.12 / trait anxiety 0.55）
SMC2019:        习惯化速率由 SpI/Sl 决定，不是常数
⇒ ⭐⭐⭐ 应拆成三件：
   ρ        自发回落（纯净，不被特质影响）
   h(n)     重复习惯化（α ≈ 0.93–0.96，角色级参数）
   g(策略)  换策略导致的冲击缩放（效价轴 ≈0.35，唤睡轴 ≈0.9）
```

### ④ 分类体系需要从【评价维度】交叉验证

```
AET (pp.20-22): 批评 Shaver 的语义聚类
                "even Shaver et al. are cautious in their willingness to 
                 extrapolate to actual emotion categories"
                ⭐ 反例 (p.23): disappointment / guilt / pity 同属 sadness 家族，
                   但【行为后果完全不同】
Barrett (p.21): 点名批评「更细粒度的类型学」
                pp.19-20「把统计摘要当常模就是本质主义错误」+「平均 3.14 人」
⇒ ⚠️ 我们的 12 类 + 19 主题【确实来自词义】→ 需要独立证据线
✅ 出路（Barrett 自己留的）: 反对的是「类别 = 本质」，不是「使用类别」
   pp.17-18 明说情绪类别和「钱」一样真实；p.10 承认每个类别都有贝叶斯先验概率
✅ 出路（AET 给的）: 从二级评价维度（后果/归因/应对/预期）交叉验证
```

### ⑤ 习惯化是**独立机制**，且有数值

```
强度习惯化（15 trial）: anxiety/excitement 都是 β = −0.06/trial（p<0.001）
   单 trial ≈ 50 s → 全实验 ≈ 12.5 min
⭐ 粗估 α ≈ 0.93–0.96（每次暴露衰减 4%–7% 剩余幅度）
⭐ 是【角色级参数】("The rate of escalation differed dramatically across individuals")
⭐ 作者称共享成分是 arousal → 宜作用于 PAD 的【A 维】驱动增量
```

## 三、对 A1–A4 的具体改造建议

### A1 空间 —— **保持不变**

```
⚠️ AET 的二维(强度独立正交) vs A1 的三维(强度=向量模长)
   表面冲突，实际兼容：AET 的 importance 是【原因】，A1 的 r 是【结果】
⚠️ 强度习惯化那篇的"强度"是【6 个非负分量的算术平均】(标量、丢方向)
   我们的 r 是【欧氏范数】(带方向、带 μ)
   ⇒ 标量 ≠ 范数；正确落点是 ΔE 的幅度，不是 A1 的 r
✅ 唯一可借: 分布形状 → 反解 σ ≈ 2.14（0–10 量程）—— 仅量级参考
```

### A2 动力学 —— **建议扩展为三层**

```
现:  E_t = μ + ρ(E_{t−1} − μ) + ΔE_t
建:  E_t = μ + ρ(E_{t−1} − μ) + g(策略)·h(n)·ΔE_raw

  ρ     自发回落（保持自定值 0.927，但【不再】承担策略衰减与习惯化）
  h(n)  重复习惯化，h(n) = α^(n−1)，α ≈ 0.93–0.96（角色级）
  g     策略导致的冲击缩放（brainsci: 间接回复使效价轴冲击 ×≈0.35）

ΔE_raw 的生成（乘法结构，barrett2016 + SMC2019）:
  ΔE_raw = α_learn(学习率) × ε(预测误差) × signature(胜出概念)
  其中 ε 可拆三旋钮（topdown2025）:
     起点项（= μ）· 漂移项（显著度/注意增益）· 标准项（期望）
  ⚠️ 反直觉坑：期望【不增强知觉】，只增强"报告倾向"
  事件过滤：只有部分事件有情感意义 → 大量 ΔE = 0（AET p.31）
  脉冲 + 余震：episode 有自我放大（g_episode > 1）+ 事件自生（AET pp.41-43）
```

### A3 μ —— **建议升级**

```
现:  μ = 一个 PAD 向量（用户配置的底情绪）
建:  μ = (方向, precision)

  方向      = 底情绪落在哪个方向（用户配置）
  precision = 先验的确定性（topdown2025 / SMC2019 的 SpI 的倒数）
  ⭐ 角色底色 = μ 的【方向】+ μ 的【precision】
  ⭐ 这直接复现「自卑 → 受伤 → 怨恨」:
     μ 偏负 + precision 过高 → 模糊事件被知觉为"受伤" → 继而"怨恨"

⚠️ 与 AET 的"特质不该是常数偏移"不冲突:
   AET 批的是「从特质推出常数偏移」；我们的 μ 是【用户显式配置的角色设定】
⭐ AET 额外送了 g_i（反应增益，正负独立）—— 这是「傲娇」的机制
⭐ 个体差异【只在效价维】(brainsci) → μ 若要个体化，只个体化 pleasure 维
⚠️ 韧性类参数【不该进 μ】（s00406: 影响收敛过程而非收敛终点）
⭐ μ 应为【慢变】而非常数（barrett2016: "neurons do not lie dormant until stimulated"）
   —— 这正是 #43 的设计
```

### A4 词库 —— **建议重读 + 补验证**

```
⭐ 词 = 【特征提取器 / 知觉模板】，不是标签
   评价标准 = 模板独特性，不是分类正确率
   （topdown2025 p.397: 模板承载特征 + 知觉偏向，决定从输入里抽哪些特征）

⭐ 词库字段重读为【概念先验】(barrett2016):
   释义（≤20 字） → 语义邻域
   主题（19 类）   → 目标维度
   方向（12 类）   → 效价
   强弱（二分）    → 先验强度 / 精度
   未归类词        = 先验接近均匀，等情境证据裁决（那 41 个跨类词）

⭐ 39 个 perception 词 → 移出情绪强度空间，改做知觉模板词汇
   （topdown2025 p.398: interoception 也算 perception；
     barrett2016 p.22: 疼痛与情绪是"同一枚硬币的两面"）

⚠️ 必须补: 从【二级评价维度】交叉验证 12 类/八型（AET 警告）
⚠️ 不得写成"情绪的本质"（Barrett 警告）
```

## 四、#40 的架构草案

```
事件（= change, AET p.31）
  ↓ 事件过滤器（只有部分事件有情感意义 → 大量 ΔE = 0）
  ↓
知觉层（topdown2025）
  · μ 作为先验（方向 + precision）
  · 输出：知觉估计（d′/漂移率）vs 报告偏向（c/起点）
  · ⭐ 39 个 perception 词在这里当模板
  ↓
评价层（moors2013 + AET）—— ⭐ #40 的核心
  一级评价: goal relevance · goal congruence · importance
            → 输出（价效, 强度）
  二级评价: 后果 · 归因(agency) · 应对潜力 · 未来预期
            → 输出离散情绪（→ 12 方向类）
  ⭐ 变量数公式: 3 变量 × 2 值 = 8 → 对应八型
  ⭐ 三层机制: rule-based / associative / sensory-motor
  ↓
ΔE（乘法结构）
  ΔE = α_learn × ε × signature × g(策略) × h(n)
  ↓
A2 动力学
  E_t = μ + ρ(E_{t−1} − μ) + ΔE
  ↓
情绪（E 的 PAD 值 + 八型标签）
  ↓
行为（AET: motivational / motor 成分）
  ⭐ 强度→行为的定量约束（强度那篇）:
     强度↑ → 尝试【更多】策略（b=0.19）
     但强度↑ 会【削弱投入型策略效果】（b=−0.445），对摆脱型无影响
  ↓
原因显著性机制（AET p.18）:
  情绪 → 心境：失去对触发事件的聚焦
  心境 → 情绪：使心境的原因变得显著
  ⭐ 对角色: "意识到自己为什么心情不好" → 弥散心境收敛 + 全局影响削弱
  ↓
用户反馈 → μ 的慢漂移（#43）
```

### ⚠️ 必须正面回应的反面意见 —— ELMO (Machova et al. 2026, IEEE Access)

> ⚠️ 这一条**不是**"不可用"，而是**针对我们所用维度模型的反对意见**。
> 按 `docs/06` 的 B12，**必须在本文里正面回应**，不能只放在心里。

**【原文】**（p.5，逐字）

> 三维维度模型 **"not usable ... recognition of dimensions is difficult with only short texts available"**

**【它在批评什么】**
```
它以【分类器式的维度识别】为对象：
   短文本 → 回归出 P/A/D 三个连续值
⇒ 在这个设定下，短文本信息量不足,三维确实"不可用" —— 这个批评成立。
```

**【我们为什么不受它约束】**
```
① 我们【不做】文本 → 三维回归。
   本引擎没有"从一句话预测 PAD"的模块,也没有这类分类器。

② 我们走的是【评价层】：
      刺激 → 一级评价(goal relevance/congruence/importance)
           → 二级评价(agency/coping/certainty/expectancy/intentionality)
           → ΔE = α×ε×signature
   ⭐ 评价变量由【LLM 直接填】（设定者裁定：评价由 AI 自己理解），
      不是由短文本的表层特征回归出来的。

③ 599 词概念先验的作用是【给评价一个语义锚】,
   ⭐ 而不是【提高分类器对短文本的分辨率】。
```

**【它的批评对我们唯一有效的地方】**
```
⚠️ 若上游把一个极短输入（"嗯" / "哦" / "。"）交给评价层,
   评价层确实可能填不出可靠的 certainty / relevance。
⇒ 处置：这不是分类器问题,而是【输入门控】问题 ——
   对应 docs/06 的 B11（中性类吸收态警告）：
   给"无情感意义"加计数与审计输出,长对话里占比过高就报警。
```

**【诚实标注】**
```
✅ ELMO 的批评【有效】,但作用域是"分类器式维度识别"
❌ 不能用它来否定"评价层 + 概念先验"的结构
⚠️ 凡引用本条,必须带上作用域限定,不得写成"文献表明 PAD 不可用"
```
