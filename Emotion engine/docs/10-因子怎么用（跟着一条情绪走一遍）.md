# 10 · 因子怎么用：跟着一条情绪走一遍

> **为什么写这份**：`docs/09` 把因子**按"是什么"归类**，但看不出"**用在哪一步**"。
> 本文改成**按数据流走**：一条情绪从进门到出门，每一步用哪些因子、每个因子干什么。
>
> ⭐ 每个因子的写法统一为：**它是什么 → 什么时候起作用 → 变了会怎样（含"= 0 会怎样"）**

---

## 0. 全程地图

```
 事件进门
   │
   ├─① 评价层 ──────────── 8 个变量（LLM 填）
   │     ↓
   ├─② ΔE 合成 ─────────── α · ε · signature  ← 三个因子
   │     ↓
   ├─③ 动力学 A2 ───────── h(n) · g · ρ · 封顶  ← 四个因子
   │     ↓
   ├─④ 底情绪 A3 ───────── μ 的慢漂移
   │     ↓
   └─⑤ 表达层 ──────────── s = s₀ + 触发 + 对象偏移
         ↓
       行为 / 语气
```

**⭐ 一句话记住分工：**
| 步骤 | 干什么 | 一句话 |
|---|---|---|
| ① 评价 | 把"发生了什么事"翻译成"该有什么情绪" | **判性质** |
| ② ΔE | 算出"这一下冲击多大、朝哪" | **定冲击** |
| ③ A2 | 冲击叠加上去 + 旧情绪怎么退 | **定留多久** |
| ④ A3 | 长期的底色悄悄移动 | **定变不变** |
| ⑤ 表达 | 里层情绪被压多少再吐出来 | **定说不说** |

# 举例：用户说「你今天有点可爱」

**输入：**
```js
{
  eventKey: '被夸奖',
  appraisal: {
    relevance: 0.9,  congruence: 0.8,  importance: 0.6,     // 一级评价
    agency: 'other', coping: 0.8, certainty: 0.7,
    expectancy: 0.4, intentionality: 1.0                    // 二级评价
  },
  context: { triggers: ['alone'], strategyScale: 0.35 }
}
```

## ① 评价层：8 个变量从哪来

**⭐ 全部由 LLM 填**（`APPRAISAL_SCHEMA`，设定者裁定"评价由 AI 自己理解"）。
本鱼**不参与判断**，只规定"必须填这 8 个"——这样每轮抽的特征固定，可比。

### 一级评价（3 个）—— 定"性质"

| 变量 | 本例 | 是什么 | = 0 会怎样 |
|---|---|---|---|
| `relevance` | 0.9 | 这事**与我关切有关**吗 | **与你无关 → 整条链归零**（它进了 valence / intensity / α / priorStrength 四处）|
| `congruence` | 0.8 | 与我的期望**方向一致**吗（正=顺心） | **无所谓顺不顺 → valence = 0 → 中性** |
| `importance` | 0.6 | 这事**多重要** | **不重要 → intensity = 0 → 不产生情绪**（但 α 可能仍非零，见下）|

### 二级评价（5 个）—— 定"哪一种"

| 变量 | 本例 | 是什么 | 变了会怎样 |
|---|---|---|---|
| `agency` | `'other'` | **谁造成的**（self / other / none） | ⭐ **决定去哪个方向**：self→自责 · other→愤怒/轻蔑/受伤 · none→沮丧/困惑 |
| `coping` | 0.8 | 我**能应对**吗 | ⭐ **改变方向**：other+能应对→轻蔑 · other+不能→受伤 · none+<0.35→沮丧 |
| `certainty` | 0.7 | 我**看得清**吗 | 三处用：α、ε、先验拉力。**= 1 → 不产生"不确定"的误差** |
| `expectancy` | 0.4 | 我**预料到了**吗 | 两处用：intensity 的意外加成、ε 的期望落空 |
| `intentionality` | 1.0 | **故意的**吗 | ⭐ **只改方向不改大小**：other+故意>0.6→愤怒 · 不故意→受伤 |

## ② ΔE 合成：这一步一共 5 个因子

### 因子 1 · `valence`（一级效价）

```
valence = congruence × relevance
```
```
· congruence = 0   →  无所谓顺心    →  valence = 0  →  中性
· relevance  = 0   →  与你无关      →  valence = 0  →  中性
```

### 因子 2 · `intensity`（一级强度）

```
intensity = min(1, importance × relevance × (1 + 0.5·(1−expectancy)) × (1 + 0.3·arousal))
            └── 基本量 ──┘   └─ 意外加成 ─┘        └─ 已有唤醒加成 ─┘
```
```
· importance = 0  →  这事不重要      →  intensity = 0  →  不产生情绪
· expectancy = 1  →  完全预料到      →  意外加成 = 1  →  不加成
· arousal 高      →  本来就在激动    →  加成最多 ×1.3
```

### 因子 3 · `α`（精度门控）—— 该不该被影响

```
α = max( relevance × importance ,  (1 − certainty) × relevance )
    └── "与生存/资源/奖励/威胁相关" ──┘   └──── "价值不确定" ────┘
                ↑ 原文的 "or" 用 max 表达        ↑ 再乘 relevance 是【本鱼加的】
```
```
· relevance = 0   →  与你无关          →  α = 0  →  不动
· importance = 0 且 certainty = 1  →  不重要又看得清  →  α = 0  →  不动
· certainty = 0   →  完全看不清        →  α = relevance  →  反而更容易被影响
```
**⭐⭐ 一句话：`α` 回答"**这误差值不值得学**"。**
**（barrett2016 p.15 原话："likely to impact survival, offering reward or threat, or are of uncertain value"）**

### 因子 4 · `ε`（预测误差）—— 与预期差多少

```
expectedValence = (expectancy − 0.5) × 2          ← 把 0–1 映射到 −1~1
ε = |valence − expectedValence| × 0.5  +  0.5 × (1 − certainty)
    └──── 期望落空多少 ────┘              └─ 本身多不确定 ─┘
```
```
· ε = 0  →  完全符合预期  →  不产生冲击
· expectancy 高而 valence 低  →  落空大  →  ε 大
```

**⚠️ 补充（2026-10-13 实测）：`ε = 0` 是【渐近】的，不是精确可达的。**

```
ε = |valence − expectedValence| × 0.5 + 0.5 × (1 − certainty)
要让 ε 精确为 0，需要同时满足：
  ① certainty = 1
  ② congruence × relevance  恰等于  (expectancy − 0.5) × 2

实测：certainty=1, expectancy=0.9
   valence = 0.8×0.9 = 0.7200
   expectedValence = (0.9−0.5)×2 = 0.8000
   ⇒ ε = |0.72−0.80|×0.5 = 0.0400  （不是 0）

⭐ 所以「完全符合预期 ⇒ 不产生情绪」在数值上是【渐近】的——
   只能趋近 0，很难精确取到。这是 ε 这个式子的性质，不是 bug。
```

### 因子 5 · `signature`（八型方向）

```
agency / coping / certainty / expectancy / intentionality
      ↓  （12 个方向类的判别）
   Happiness / Anger / Hurt / Caring / …
      ↓  （映射）
   Exuberant / Hostile / Anxious / Dependent / …  ← 8 个卦限
      ↓  （取单位向量）
   signature ∈ {±1, ±1, ±1}
```
```
本例：other + coping 高 + intentionality 高
   → Happiness → Exuberant（+P +A +D）
```

### ⭐ 合成

```
ΔE = signature × (α × ε × intensity × attention)   ← 主项
   + unit(μ) × (0.15 × (1−certainty) × precision/3) × intensity   ← 先验拉力
```

**⭐⭐ 主项为什么是乘法：**
```
进乘法主项的四个量，任一为 0 则 ΔE = 0：
  · α = 0          →  不确定到不该学  →  不动
  · ε = 0          →  完全符合预期    →  不动
  · intensity = 0  →  这事不重要      →  不动
  · signature= 0   →  没有方向        →  不动（结构上恒非 0）
⇒ 这解释了「同样强度的刺激，有时改变情绪、有时完全不改变」
```

**⚠️ 但要注意两个容易说错的地方（2026-10-13 实测）：**

```
① congruence = 0 【不】使 ΔE 归零
   valence = congruence × relevance = 0
   但 ε 里还有第二项 0.5×(1−certainty) ⇒ ε 仍 = 0.25
   实测：congruence=0 ⇒ α=0.5400 · ε=0.2500 · |ΔE|=0.0968（不是 0）
   ⭐ 语义是对的：一件"无所谓顺不顺但你也没底"的事，仍会扰动情绪。

② relevance = 0 或 importance = 0 确实归零，但走的是【另一条路】
   实测：relevance=0 ⇒ α=0 · ε=0 · intensity=0 · |ΔE|=0.000000
   ⚠️ 而这条路是 classifyDirection() 的【早退】（relevance < 0.15 判为"无情感意义"），
      不是在乘法里自然归零的。
```

**⭐⭐ 先验拉力为什么单独加：**
```
precision 越高 ⇒ 这一项越大 ⇒ 模糊事件被读得越像"符合 μ"
· certainty = 1  →  看得清  →  拉力 = 0（不需要先验兜底）
· precision = 0  →  先验极弱 →  拉力 = 0（兜不住）
```

## ③ 动力学 A2：四个因子决定"留多久"

### 因子 6 · `h(n)`（习惯化）—— 用 `eventKey`

```
n  = 这个类别的事件第几次发生
h  = α_habit^(n−1)
```
```
· 第 1 次被夸    →  h = 1.00  →  全额冲击
· 第 5 次被夸    →  h = 0.81  →  打八折
· 换个新花样夸   →  noveltyReset 触发  →  h 回 1.00  →  重新敏感
```
**⭐ `α_habit = 1` 会怎样：永不习惯化 —— 第 50 次和第 1 次一样激动。**

### 因子 7 · `g`（策略缩放 × 反应增益）—— 用情境和 ΔE 方向

```
g = gGain(ΔE 的符号) × gStrategy(情境给的 strategyScale)
```
```
· 直接说"我很开心"   →  gStrategy = 1.0    →  全额落到里层
· 嘴上说"谁要你夸"   →  gStrategy ≈ 0.35   →  只有 35% 落到里层
```
**⭐⭐ 这就是傲娇在数学上成立的地方：嘴上越硬，心里被削得越少。**

### 因子 8 · `ρ`（自发回落）—— 用当前偏离

```
E ← μ + ρ × (E − μ)
```
```
· 没有新事件   →  每轮 ×ρ
· ρ = 0.927   →  9.1 轮减半（默认）
· 开启 rhoByValence 且当前是负性  →  ρ = 0.451  →  0.87 轮就减半
· 开启 rhoByContext 且是工作日    →  半衰期 ×3.333
```
```
· ρ = 1  →  情绪永不消退，越积越多
· ρ = 0  →  每轮清零，没有情绪历史
```

### 因子 9 · 封顶 —— 用偏离强度 r 和 σ

```
r0 = 2σ          ← 低区上界
r ≤ r0  →  不压（恒等）
r > r0  →  对数压缩，但永远到不了 1
```
```
· σ = 0.40  →  r0 = 0.80  →  r 超过 0.80 才开始压
· σ = 0.50  →  r0 = 0.85  →  几乎要到球面才压（⚠️ 等于封顶很弱）
· 去掉封顶  →  反复刺激会让 r 无限涨（ρ=0.927 时稳态放大 13.7 倍）
```

### 结果

```
E_new = μ + ρ(E − μ) + g·h(n)·ΔE   ，再封顶
```

## ④ 底情绪 A3：慢变量

### 因子 10 · `μ` 的漂移

```
drift(delta, rate)
· rate = 0        →  μ 完全不动（无事发生）
· rate = 4.0e-5    →  60 天位移 0.048（标定值，"看不出漂移"）
· rate = 0.02      →  ⚠️ 0.88 天就顶到上限（历史默认，已过时）
· maxDrift = 0.35  →  μ 最多偏离基准 0.35
```
**⭐ 语义：`delta` 是"这次事件值得记多少" —— 所以漂移是**记忆驱动**的，不是时间驱动的。**

### 因子 11 · `precision` 的衰减

```
· 有反馈  →  precision 刷新回基准
· 无反馈  →  precision ← precision / 2（每轮）
```
```
· precision 高  →  先验硬 →  模糊事件被拉向 μ
· precision 低  →  先验松 →  模糊事件按它自己读
```

## ⑤ 表达层：决定"说不说"

### 因子 12 · `s`（抑制强度）

```
s = s₀ + Σ 状态偏移 + 事件累积 + 对象偏移 + 疲劳
```

**先看触发（`context.triggers`）：**

| 触发 | 值 | 类型 | 什么时候给 |
|---|---|---|---|
| `calledOut` 被戳中 | **+0.45** | 事件（累积） | 用户说中了心里话 |
| `alone` 只有两人 | **+0.55** | 状态（每轮重算）| 对象在场且无旁人 |
| `unobserved` 无人 | **+0.25** | 状态 | 谁都不在 |
| `audience` 有观众 | **−0.40** | 状态 | 有第三者在场 |
| `flustered` 羞耻 | −0.25 | 事件 | 慌 |
| `impulse` 冲动 | +0.30 | 事件 | 情绪压过抑制 |
| `intimacy` 关系深化 | +0.10 | 事件 | 长期累积 |

**⚠️ 情境名怎么传（2026-10-13 修正）：**
```js
context: { triggers: ['alone'], scene: 'workday' }
//                            ^^^^^ B2 的情境名放这里
```
⚠️ 原先 `Character.step()` **没有把情境名透传**给 `Dynamics`，
   导致 `rhoByContext` 走 `Character` 完全用不上（只能直接调 `Dynamics`）。已修。
⚠️ 用 `scene` 而不是 `context` 作字段名 —— 避免与 `ev.context` 这个对象本身重名。

**再看对象偏移：**
```
s −= 0.35 × 在意程度(attachment)
· attachment = 0  →  对谁都一样
· attachment = 1  →  在这个人面前最松
```

**最后：**
```
E_outer = μ + s × (E_inner − μ)
```
```
· s = 1   →  完全泄露（不傲娇）
· s = 0   →  压成 μ（面瘫）
· s = 0.3 →  只泄露 30%
```
**⭐⭐ `μ` 在这里同时是【收敛终点】和【伪装目标】——**
**装出来的样子，就是底情绪的样子。冷淡的人装冷淡，热情的人装热情。**

## ⭐ 所以看因子只需记住两句话

```
① 想让角色【情绪化】→ 调 σ（同时影响波动幅度、封顶陡度）
② 想让角色【情绪留得久】→ 调 ρ（或开 rhoByValence 让负性散得更快）
其余因子要么是 LLM 每轮填的，要么是情境给的，要么是设定者已裁定的。
```
