## 二、数据流（一轮）

```
  ① 事件（刺激）
       │  { eventKey, appraisal:{...}, context:{ triggers, strategyScale } }
       ▼
  ② 评价层  appraisal.js
       ├─ aiAppraise()          归一化 LLM 直填的评价（或 rule-based 输入）
       ├─ primaryAppraisal()    一级 → (价效, 强度)
       ├─ classifyDirection()   二级 → 12 方向类 → 八型
       ├─ precisionGate()       α（精度门控）
       └─ appraisalToDeltaE()   → ΔE = α × ε × signature
       │
       ▼
  ③ 词库  lexicon.js（可选增强）
       ├─ matchAppraisal()      评价 → 候选概念集
       └─ concept.signature     若 useLexiconSignature，则用选中词签名替代八型签名
       │
       ▼
  ④ 动力学  dynamics.js
       ├─ h(n) = α_habit^(n−1)            重复习惯化（按 eventKey 计数）
       ├─ g    = g_i(符号) × strategyScale 反应增益 × 策略缩放
       ├─ ρ    自发回落
       └─ cap  封顶 f(r) = 1 − (1+r)^(−k)
       │
       ▼
  ⑤ E_inner（里层真实情绪）
       │
       ▼
  ⑥ 表达层  tsundere.js
       ├─ apply(trigger)        状态类（幂等）/ 事件类（累加）
       ├─ express()             E_outer = μ + s·(E_inner − μ)
       └─ 输出 leak / leakAmount  内外落差
       │
       ▼
  ⑦ E_outer（表层表达）→ 行为
```

## 三、模块职责

### `space.js` — A1 空间

| 导出 | 职责 |
|---|---|
| `V` | 向量工具（add/sub/mul/dot/norm/unit/lerp/fmt）|
| `Space` | 角色空间：`percentile(r)`、`effective(r)` |
| `cap(r,k)` | λ 对数封顶 `1 − (1+r)^(−k)` |
| `capInverse(y,k)` | 反解 r |
| `chi2_3_cdf(x)` | χ²(3) 累积分布（Wilson–Hilferty 近似）|

**依赖**：无（最底层）

---

### `appraisal.js` — 评价层

| 导出 | 职责 |
|---|---|
| `OCTANT` | 八型 → PAD 单位签名 |
| `DIRECTION_TO_OCTANT` | 12 方向类 → 八型 |
| `classifyDirection(a)` | 二级评价 → 方向 |
| `primaryAppraisal(a)` | 一级评价 → (价效, 强度) |
| `precisionGate(a)` | 精度门控 α |
| `appraisalToDeltaE(a, ctx)` | 评价 → ΔE |
| `aiAppraise(llmOutput)` | ⭐ LLM 直填接口 |
| `APPRAISAL_SCHEMA` | ⭐ 提示词骨架（固定字段 ⇒ 模板稳定）|

**依赖**：`space.js`

**⭐ 设计要点**：设定者裁定「评价计算得完全由 AI 自己来理解」。
故本模块提供**结构固定 + 参考实现 + LLM 接口**三件：
结构固定保证每轮抽同样的特征；参考实现可跑可测；LLM 接口让模型自己理解。

---

### `dynamics.js` — A2 动力学

| 导出 | 职责 |
|---|---|
| `Dynamics` | 三层动力学：`step(dERaw, mu, opts)` |
| `.halfLife` | 半衰期 = `ln0.5/lnρ` |
| `.exposure` | 按 `eventKey` 记的习惯化计数 |
| `.idle(mu, n)` | 只过时间、无事件 |

**依赖**：`space.js`

---

### `mu.js` — A3 底情绪

| 导出 | 职责 |
|---|---|
| `Mu` | `(方向, precision)` + `drift()` 慢漂移 |
| `PRESETS` | 出厂预设（neutral / dependent / anxious / calm / disdainful）|
| `bayesianRead()` | precision 如何改变"解读模糊事件" |

**依赖**：`space.js`

---

### `tsundere.js` — 表达层

| 导出 | 职责 |
|---|---|
| `Tsundere` | `apply(trigger)` + `express(eInner, mu)` |
| `SUBTYPE` | 18 亚型 → `(s₀, leak, honesty, desc)` |
| `TRIGGER` | 情境触发（**状态类** vs **事件类**）|
| `LEAK_CHANNEL` | 9 种泄露通道 |

**依赖**：`space.js`

**⚠️ 分类纪律**：
- **状态类**（`audience` / `alone`）—— **幂等**，设定后重算，**不叠加**
- **事件类**（`calledOut` / `flustered` / `impulse` / `intimacy`）—— 累加，逐轮衰减

> 这个区分是必需的：把 `alone` 当累加事件会导致两轮后 s 饱和，
> 使 `calledOut` 完全失效（v0.1.0 开发中实测到的 bug）。

---

### `lexicon.js` — A4 词库

| 导出 | 职责 |
|---|---|
| `Lexicon` | 加载 599 词；`lookup` / `search` / `matchAppraisal` |
| `ConceptPrior` | 单条词 → 概念先验（`toAppraisalSeed()` / `signature`）|
| `THEME_TO_GOAL` | 17 主题 → 目标维度 |
| `OCTANT_SIGN` | 八型 → PAD 签名 |

**依赖**：`fs`（读 `data/emotion-lexicon-cn.json`）

**⭐ 设计要点**：词是**特征提取器**，不是标签。
`matchAppraisal` 返回**候选集**，由上层（LLM）裁决。

---

### `engine.js` — 组装

| 导出 | 职责 |
|---|---|
| `Character` | 持有全部子模型；`step(ev)` / `idle(n)` / `moodSwitch()` |
| `Character.gainFor(dERaw)` | 按 ΔE 的 P 轴符号选 `g_正` / `g_负` |

**依赖**：全部

**⭐ 心境开关** [文献] AET p.18：

```
moodSwitch(causeSalient)
  true  → { state: 'emotion', globalGain: 1.0 }   原因显著 ⇒ 具体情绪，全局影响削弱
  false → { state: 'mood',    globalGain: 1.6 }   原因模糊 ⇒ 弥散心境，全局影响放大
```

## 四、Character 参数总表

```js
new Character({
  name,                  // 名字
  sigma: 0.40,           // A1 情绪化程度
  rho: 0.927,            // A2 自发回落
  alpha: 0.95,           // A2 习惯化因子
  muPreset: 'dependent', // A3 底情绪预设
  muOverride: null,      // A3 直接给 {dir, precision}
  subtype: ['Tsundere'], // 表达层 亚型（可叠加）
  s0: null,              // 表达层 覆盖抑制基线
  gainPos: 1.0,          // AET 反应增益（正）
  gainNeg: 1.0,          // AET 反应增益（负）
  lexicon: null,         // A4（默认自动加载）
  useLexiconSignature: false,  // 是否用选中词签名替代八型签名
})
```

**`step(ev)` 的输入：**

```js
{
  eventKey: '被替代',            // 用于 h(n) 习惯化计数
  appraisal: { ... },            // 评价（LLM 直填或 rule-based）
  context: {
    triggers: ['alone'],         // 情境触发
    triggerStrength: 1,
    strategyScale: 0.35,         // g（策略缩放）
    attention: 1.0,              // 注意增益
  }
}
```

**`step(ev)` 的输出（节选）：**

```js
{
  turn, appraisal, direction, octant,
  alpha, eps, valence, intensity, dE,
  h, exposure, gGain, gStrategy,
  r, rRaw, percentile,
  E_inner, E_outer, s, sEff, leak, leakAmount,
  concept,      // ⭐ 词库选中的概念
  candidates,   // ⭐ 候选词
  note,
}
```

## 五、扩展点

| 想做什么 | 改哪里 |
|---|---|
| 换角色的底情绪 | `Character({ muPreset })` 或 `muOverride` |
| 加新亚型 | `tsundere.js` 的 `SUBTYPE` |
| 加新情境触发 | `tsundere.js` 的 `TRIGGER`（注意 state/event 分类）|
| 用 LLM 做评价 | 走 `aiAppraise()` + `APPRAISAL_SCHEMA` |
| 加词汇 | 往 `data/emotion-lexicon-cn.json` 的 `entries` 加 |
| 换封顶形式 | `space.js` 的 `cap()` |
| 加新方向类 | `appraisal.js` 的 `classifyDirection()` + `DIRECTION_TO_OCTANT` |

**三幕的预期输出：**

| 幕 | direction | octant | ΔE 的关键特征 |
|---|---|---|---|
| 一 | Hurt | Anxious | P负 · A正 · **D负** |
| 二 | Happiness | Exuberant | 全正但小（策略缩放 0.35）|
| 三 | **Caring** | **Dependent** | P正 · A正 · **D负** |

**⭐ 第三幕的 `D < 0` 是判定"软弱退化想被保护"是否正确的关键指标。**
