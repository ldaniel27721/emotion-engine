# 11 · 多事件混合：模型到底"记住"了什么

> 起因：设定者问 ——
> 「ρ 的取值按现在的设计就是单调下降咯？多事件混合的情况下，
> 你能不能分别输入事件模拟，看模型是否会**记住**多次事件所产生的情绪，
> 以及各个事件**导致整体情绪的漂移**？」
>
> 复现脚本：`demo/exp-multi-event.js` · `exp-multi-event2.js` · `exp-superposition.js` · `exp-nonlinearity.js`

---

## 0. 先纠正两个数

```
⚠️ ρ = 0.927 的半衰期是 9.14 轮，不是 22.8 轮。
   22.8 轮是 ρ = 0.97 那一档。

   ρ         0.900   0.927   0.950   0.970
   半衰期      6.6     9.1    13.5    22.8   （轮）
```

**⭐ 默认档是 0.927（9.14 轮）。**

---

## 1. ρ 是"单调下降"吗 —— 分三种情形

| 情形 | r 的轨迹 | 判定 |
|---|---|---|
| **(a) 无事件** | `0.600 → 0.556 → 0.516 → 0.478 → 0.443 → 0.411 …` | ✅ **严格单调下降**（每轮 ×ρ）|
| **(b) 周期性同向事件** | `0.000 → 0.000 → 0.274 → 0.254 → 0.235 → 0.478 …` | ⚠️ **上升到稳态后停住** |
| **(c) 混合 20 轮** | `0.274 → 0.409 → 0.351 → 0.717 → 0.737 → 0.800 → 0.688 → 0.812 → 0.698 → 0.871` | ⚠️ **锯齿形，整体上台阶** |

**⭐ 结论：**
```
"单调下降"只在【无事件 + 单一 ρ】时成立。
有事件时是"衰减 + 脉冲"的叠加：
  · 没有事件的那些轮 → 单调下降
  · 有事件的轮       → 跳上去
⇒ 净效果取决于【事件来得快 还是 衰减得快】
```

## 2. ⭐ 模型的"记忆"结构：两处非线性

### 2.1 基础：低强度区是**严格线性**的

```
E_t = μ + ρ(E_{t−1} − μ) + g·h(n)·ΔE_raw
⇒ 展开：E_T − μ = Σ_i  ρ^(T−i) · g_i · h(n_i) · ΔE_raw_i
```

**⭐ 实测验证（关掉封顶后）：**
```
预测 Σ ρ^(age)·g·h·ΔE_raw = [0.203964, 0.790729, -0.357353]
仿真 E − μ                = [0.203964, 0.790729, -0.357353]
差 = 0.000000000   ✅ 逐位吻合
```

**⇒ 各事件的贡献【可加】：同向叠加、反向抵消。**

### 2.2 ⚠️ 但有两处非线性会打破它

```
① h(n) 习惯化 —— 按 eventKey 计数，同类事件递减
② 封顶        —— 强度超过 r0 = 2σ 后压缩
```

**⭐ 实测分离（连续 N 次同向「夸奖」）：**

| 次数 | 解析线性 `Σρ^k` | 两个都关 | 只习惯化 | 只封顶 | 都有 |
|---|---|---|---|---|---|
| 1 | 1.0000 | **1.0000** | 1.0000 | 1.0000 | 1.0000 |
| 2 | 1.9270 | **1.9270** | 1.8770 | 1.9270 | 1.8770 |
| 3 | 2.7859 | **2.7859** | 2.6420 | 2.7860 | 2.6420 |
| 4 | 3.5826 | **3.5826** | 3.3065 | 3.3885 | 3.2626 |

```
⚠️ 注意：解析线性基准是 Σρ^k（因为先发生的事件已经衰减了），
   【不是】 N× —— 本鱼第一版就是拿 N× 当基准，误判成"非线性"。

⭐ 读法：
   · "两个都关" 与解析值【逐位吻合】⇒ 基础确实是线性的
   · "只习惯化" 的差额 ⇒ h(n) 的贡献（4 次时损失 7.7%）
   · "只封顶"   的差额 ⇒ 封顶的贡献（4 次时损失 5.4%）
   · "都有"      ⇒ 两者叠加（4 次时总损失 8.9%）
```

### 2.3 两处非线性**互相补位**

```
α_habit = 0.95（有习惯化）：
   长期重复同一事件 ⇒ h(n) → 0
   实测 200 轮后：h = 0.000037、r = 0.00041
   ⇒ 自己就压住了，封顶几乎没机会介入

α = 1（无习惯化）：
   r_∞ = |ΔE_eff| / (1 − ρ) = 1.3434
   ⚠️ 而球面半径是 1 ⇒ 必须靠封顶压住
   ⇒ ⭐ 这正是当初要加封顶的原因（docs/08 第一节）

⇒ ⭐⭐ 分工：
     习惯化管"同类事件多久钝"（事件轴）
     封顶管 "任何来源的总强度上限"（强度轴）
```

## 3. ⭐ 核心问题：模型"记住"多次事件了吗

**分两层回答 —— 这是本引擎最关键的结构：**

### 3.1 E 层（快变量）—— **会留痕，但按 ρ^age 指数消失**

```
ρ = 0.927 ⇒ 半衰期 9.14 轮

经过轮数   权重 ρ^age    剩多少
   0       1.000000     100.00%  ##############################
   3       0.796598      79.66%  ########################
   5       0.684540      68.45%  #####################
9.14       0.500160      50.02%  ###############
  15       0.320772      32.08%  ##########
  20       0.219581      21.96%  #######
  30       0.102894      10.29%  ###
  50       0.022594       2.26%  #
 100       0.000510       0.05%
```

**⭐ 20 轮后，第 1 个事件的权重只剩 0.237。**
**⭐ 100 轮后剩 0.05% —— 理论上"永不归零"，但实际几十轮后就低于可察觉水平。**

**各事件的残余贡献（第 20 轮时）：**

| 事件 | 发生时轮 | 年龄 | 权重 ρ^age | 残余贡献 \|·\| |
|---|---|---|---|---|
| 夸奖 | 1 | 19 | 0.23687 | 0.0648 |
| 忽视 | 3 | 17 | 0.27565 | 0.1096 |
| 戳中 | 6 | 14 | 0.34603 | 0.1809 |
| 责备 | 8 | 12 | 0.40268 | 0.1789 |
| 夸奖 | 11 | 9 | 0.50550 | 0.1383 |
| 忽视 | 14 | 6 | 0.63457 | 0.2523 |
| 戳中 | 18 | 2 | **0.85933** | **0.4492** |

**⭐ 早期事件虽在，但权重被压得很小 —— 最近的事件主导当下。**

### 3.2 μ 层（慢变量）—— **不自动记**

```
20 轮、7 个事件之后：
   μ 起始 = [0.36365, 0.22728, -0.13637]
   μ 现在 = [0.36365, 0.22728, -0.13637]
   变化量 = 0.000000000
⇒ ⚠️ μ 【完全没动】—— 它只在显式调用 drift() 时才变
```

**⭐⭐ 所以答案是：**

```
┌ E 层（快变量）：会叠加、会留痕，但按 ρ^age 指数消失 ⇒ 半衰期 9.14 轮
└ μ 层（慢变量）：【不会自动记住】—— 必须显式接 drift()

⇒ 现状 = 【短期会记，长期会忘】
   真正的"长期记忆"要靠 μ 漂移接上（issue #43）
```

## 4. 各事件如何让"整体情绪"漂移

### 4.1 同向加强 / 反向抵消（线性区内）

| 序列 | r | E − μ |
|---|---|---|
| 三次夸奖（同向） | 0.6412 | `[0.4063, 0.3818, 0.3166]` |
| 三次责备（同向） | 0.9441 | `[-0.5264, 0.5663, 0.5417]` |
| 夸奖·责备·夸奖（对冲） | 0.6451 | `[0.0860, 0.4786, 0.4239]` |
| 夸奖·忽视·戳中（混合） | 0.7734 | `[0.2648, 0.6090, -0.3964]` |

**⭐ 同向叠加、反向抵消 —— 线性系统的必然。**

### 4.2 ⭐ 时序记忆：顺序不同，结果不同

```
只夸奖     E−μ = [ 0.1733,  0.1629,  0.1351]
只责备     E−μ = [-0.2477,  0.2665,  0.2549]
夸奖→责备  E−μ = [-0.0870,  0.4175,  0.3802]
责备→夸奖  E−μ = [-0.0563,  0.4099,  0.3714]
```

**⭐ 逐位验证（先发生的那个已衰减 ρ 倍）：**
```
夸奖→责备 = ρ·A + B = 0.927·[0.1733,0.1629,0.1351] + [-0.2477,0.2665,0.2549]
                    = [-0.0871, 0.4175, 0.3801]   ✅ 与实测吻合
责备→夸奖 = A + ρ·B = [0.1733,0.1629,0.1351] + 0.927·[-0.2477,0.2665,0.2549]
                    = [-0.0563, 0.4099, 0.3714]   ✅ 与实测吻合
⇒ ⭐⭐ 这就是"情绪有时序记忆"的数学表达
```

### 4.3 ⚠️ 一个观察：事件来得比衰减快时，r 会持续攀升

```
20 轮 7 个事件（混合）：
   轮  1  夸奖    r = 0.2736
   轮  6  戳中    r = 0.7734
   轮 11  夸奖    r = 0.8002
   轮 14  忽视    r = 0.8760   ⭐ 已被封顶压了 0.45%
   轮 18  戳中    r = 0.9425   ⭐ 已被封顶压了 8.90%
   
⇒ r 在【爬向球面】，而封顶开始越来越多地介入
⇒ ⭐ 这就是"情绪饱和"的数学含义：边际效果递减
```

## 5. 如果开启 `rhoByValence`：负性"记得更短"

```
（轮 1-8，轮 1 = 忽视，轮 4 = 夸奖）

默认 ρ=0.927          0.3976 → 0.3686 → 0.3417 → 0.3636 → 0.3371 → 0.3125 → 0.2897 → 0.2685
rhoByValence 开启     0.3976 → 0.1793 → 0.0809 → 0.2669 → 0.2335 → 0.2043 → 0.1788 → 0.1564
```

**⭐ 负性那段（轮 1–3）在开启后散得快得多（0.451 vs 0.927）——**
**而正性那段（轮 4–8）差别不大（0.805/0.875 vs 0.927）。**
**⇒ ⭐ 这正是 `docs/06` 的 B1 想修的那个问题："负性情绪在该散的时候没散"。**

## 6. 结论：四句话

```
① ρ 只有【无事件】时才单调下降；有事件时是"衰减 + 脉冲"的叠加。
   默认 0.927 ⇒ 半衰期 9.14 轮（不是 22.8）。

② 低强度区严格线性 —— 各事件的贡献可加（Σρ^age·g·h·ΔE）。
   实测：关掉封顶后与解析预测【逐位吻合，差 = 0】。

③ 两处非线性会打破它，且【互相补位】：
     h(n) 习惯化 —— 管"同类事件多久钝"（事件轴）
     封顶        —— 管"总强度上限"（强度轴）
   4 次同向事件时，两者合计把强度压掉 8.9%。

④ "记住"要分两层：
     E 层：会留痕，但按 ρ^age 消失（9.14 轮半衰）
     μ 层：不自动记 —— 必须显式调 drift()
   ⇒ 现状是【短期会记，长期会忘】；长期记忆要靠 μ 漂移（issue #43）。
```

## 7. ⚠️ 这次排查暴露的一处文档风险

```
本鱼第一版实验拿 "N×" 当线性基准，于是把 Σρ^k 的正确行为误判成"非线性"。
⇒ ⭐ 教训：谈"叠加/线性"时，必须先写清【基准是什么】。
   有 ρ 衰减的系统里，"两次事件"的正确基准是 (1+ρ)=1.927，不是 2。
```
