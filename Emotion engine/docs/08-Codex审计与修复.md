## 三、① 的根因与修复（最严重的一条）

### 根因：全域施加了封顶，而低区斜率不是 1

```
原实现   f(r) = 1 − (1+r)^(−k),   k = 1/σ
         f′(0) = k  ← ⚠️ 不是 1

⇒ 低区不是"近似恒等"，而是【斜率 k 的线性放大】
⇒ 空闲每轮：dev ×= ρ(0.927) 再 ×≈k(2) ⇒ 净 1.854 > 1 ⇒ 一定放大
⇒ r 一直涨到 cap 的压缩刚好抵消 ρ 为止 ⇒ 停在解析值 ≈ 0.53
⇒ ⚠️⚠️ 这推翻了 A3 的核心裁定「μ 是收敛终点」
```

### ⭐ 而设定者原话本来就说的是「高增幅阶段」才限制

> 「引入对数函数做为限制，使其增长最大值无限趋于1但不为，**高增幅阶段**则由模型情绪化程度决定」

**⇒ 低区应当恒等。原实现理解错了，不是理论错。**

### 修复：分段形式（r0 处 C¹ 连续）

```
f(r) = r                                                    r ≤ r0
     = r0 + (1−r0)·[1 − (1 + (r−r0)/((1−r0)·k))^(−k)]        r > r0

性质：f(0)=0 · f′(0)=1（低区恒等）· f′(r0⁻)=f′(r0⁺)=1
      lim(r→∞) f(r) = 1（渐近，永不到达）· f(r) ≤ r（全域不放大）
⭐ r0 = 低区上界 = 2σ（约在角色日常波动的上沿）
   ⇒ 即「高增幅阶段由情绪化程度决定」
```

## 七、教训

```
1. ⚠️【非线性饱和函数的低区斜率必须为 1】——
      否则"压缩"会变成"放大"，且放大倍数就是 k。
```

## 八、附录：ρ 与 h(n) 为何是【两根轴】（2026-10-13 裁定采纳）

> ⚠️ 本节原为论证草稿，2026-10-13 由设定者裁定采纳（裁定"甲"：两轴分开，各为独立参数），
> 并补上了数值验证。完整证据见 `docs/06` 的 B4 与 `demo/test-b4-axes.js`。

### 文献侧的主张（同源）

```
Déniz et al. (2004) 用的底层是 Stanley (1976) 一阶 ODE：
    y_t = y₀ + λ(y_{t−1} − y₀) − (Δt/τ)·S_t
原文："τ is a time constant that governs the rate of habituation
      and α regulates the rate of recovery."

⇒ 习惯化时间常数 = τ/α ｜ 恢复时间常数 = τ/α   ← 同一个
⇒ 数学上无法独立调节"下沉"与"回升"速度
⇒ 因此把 ρ 与 h(n) 当两个独立旋钮 = 【过参数化】
```

**而 A2 的那一项与它逐字同构：**
```
A2      :  E_t = μ + ρ(E_{t−1} − μ) + g·h(n)·ΔE
                       └──── ρ 就是 λ ────┘
而 h(n) = α_habit^(n−1) 正是 Stanley 泄漏项的【脉冲响应】形式
```

### 本项目的反论（不同轴）

**关键在于：Stanley 的 ODE 里，时间步 `t` 与刺激步 `S_t` 是【同步的】—— 每步一个刺激。**
```
只有【一根轴】⇒ 习惯化与恢复被迫共用 τ/α
```

**而本项目的模型里有两根轴：**

| | 轴 | 推进条件 |
|---|---|---|
| **ρ** | 对话轮次（时间轴） | 每轮**必然**过一次 |
| **h(n)** | 同类事件的次数（事件轴） | 只在该类事件**出现时**才推进 |

**一个具体例子：**
```
轮次:      1        2         3         4
事件:    「调侃」    —      「调侃」  「调侃」
ρ       衰减一次  衰减一次   衰减一次   衰减一次     ← 每轮都过
h(n)     n=1        —       n≈2      n≈3          ← 只在该类事件出现时推进
```

**第 2 轮是关键：什么都没发生。**
```
ρ 该推进（时间在走，情绪该消退）
但 h 不该推进 —— "没被调侃"这一轮，不该让"对调侃的习惯"加深
⇒ 若两轴相同，这两件事被迫同步；而它们语义上必须分开
```

### 结论与残余风险

```
文献的限制条件 = 【时间步 ≡ 刺激步】
本模型放宽为   = 【一轮内事件数可变（0 / 1 / N）】
⇒ 因这个放宽，原本共用 τ/α 的两个速度【被解耦】
⇒ ⭐ 这不是过参数化，是【模型的自由度确实更高】
```

**⭐ 数值验证（`demo/test-b4-axes.js`，9 项全绿）：**
```
固定 ρ=0.900 时，密集 / 稀疏两情境要达成同一个 r，所需 α 相差 0.5893
存在目标（r=0.80）密集情境 6/6 个 ρ 可达、稀疏情境 0/6 可达
α 对密集情境的影响是稀疏情境的 10.20 倍
强行令 α ≡ ρ（同源假设）最大偏差 0.4152
```

⚠️ **残余风险（诚实标注）**：数值上不排除二者"应当相等"——
背后可能是同一个神经时间常数，只是被采样到了不同的轴上。
**本引擎没有真实数据，无法实证**；将来若有数据，可做【锁定检验】：
把 `α_habit` 锁到 ρ，看拟合损失多少（损失小 ⇒ 该合并；损失大 ⇒ 证明独立）。
