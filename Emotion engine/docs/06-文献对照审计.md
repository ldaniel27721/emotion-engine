## B. 文献指出、引擎**还没有**的部分（❌ 缺口 / ⚠️ 部分）

```

   ⭐ 分段依据：当前偏离在 P 轴上的符号（负 / 中 / 高正），"高正"用 `|r| > 1.5σ` 判
   ⭐ 实测（`demo/test-b1-b3.js`）：

   ⇒ ⭐ 印证了本文的判断：**默认的 0.927 比文献三个值都"粘"**
⚠️ 注意【非单调】：不是"越正越持久"（0.875 > 0.805）
⚠️ 该文正文写错了自己的表（把 0.093 说成 State 1 的自转移），引用一律以 Table 3 为准
```

### B2 ρ 按情境分段

```
文献：Appl. Sci. (2025) 15:4960 案例 —— 工作日 γ=0.3 vs 周末 γ=1（3.3×）
引擎：无情境维度（`step()` 只吃 eventKey / g / h）
补法：给 step 增加 context 覆盖（工作日/周末、独处/有观众）
```

### B3 h(n) 的**自动**新颖性复位

```
引擎：dynamics.js 的 step() 有 resetExposure，但是【手动开关】—— 谁来判"刺激变了"没实现
文献：Déniz et al. (2004) = Stanley (1976) 一阶 ODE + "刺激单调性"判别器（其 Eq.7）
判定：✅ **已于 v0.1.3 实现**（Dynamics 的 `noveltyReset` + `noveltyThreshold`，**默认关闭**）
   ⭐ 判别信号：同一 `eventKey` 的 `ΔE_raw` 相对上次的**相对阶跃** > 阈值 ⇒ `exposure=0`
   ⭐ 实测（`demo/test-b1-b3.js`）：A→B 换梗时触发复位（h 回到 1、exposure 归 1）；
     同梗重复【不误触发】
```

### B4 ρ 与 h(n) 可能**同源**（过参数化风险）

```
文献：Stanley 的 λ = αΔt/τ 同时决定回落速度与脉冲响应形状 ⇒ ρ 与 h(n) 共用同一时间常数
引擎：dynamics.js 头注释把它们写成"三批文献独立汇合"，未提同源可能
        ⚠️ v0.1.2 的 docs/08 里给了【不同轴】的反论（ρ 的轴 = 对话轮次，h(n) 的轴 = 同类事件次数）
           ⇒ 此处两说并陈，标【待设定者裁】
补法【文档级】：在该注释与 docs/01 里补一句"框架上可能同源，分开调参属工程简化"
```

### B5 precision 的时间动力学（信度衰减）

```
引擎：mu.js 的 precision 是【常数】，只有先验方差 1/precision
文献：ToM (IEEE Access 2025) —— R(k)=R0（有测量）否则 α·R(k−1)，α>1（实验 α=2）
      "α models the rate of decay of the confidence in reused measurements"
判定：✅ **已于 v0.1.4 实现**（`Mu.setPrecision()` / `decayPrecision(α)` / `tickPrecision(measured)`，**默认不调用**）
   ⭐ 机制：`R(k)=α·R(k−1)`（R 是方差）⇒ `precision ← precision/α`，有测量则刷新回基准
   ⭐ 按本文要求【不做在线自适应】—— 只有"刷新 / 衰减"两个动作，无插值、无拟合
   ⭐ 实测（`demo/test-b5.js`）：衰减 4 轮 3.0→0.1875，先验拉力 0.105000 → 0.006562
     ⇒ 语义：**久无反馈 ⇒ 先验变"松" ⇒ 模糊事件更多按事件本身读**
```

### B6 ρ 的**方向化**（标量 → 转移矩阵）

```
引擎：一个标量 ρ 对所有方向一视同仁
文献：EmoChat (BIGCOM 2019) 用一阶马尔可夫转移矩阵 A（N×N，从 20 人标注的真实对话按行归一化）
      消融证明有效：+5.17 pt（极性）/ +5.86 pt（类别）
补法：ρ 升级为 3×3（P/A/D）或 8×8（八型）转移矩阵；起步可用八型
```

### B7 正/负增益方向 —— **我们目前与文献相反**

```
引擎：g_正 = 1，g_负 = 1.3（负性更重）
文献：nihms (Mote et al.) —— PA 预测动机（b=0.20~0.43, p<.001），NA 不预测
      ⇒ 结论是"放大利正 > 压制负向"，并建议 reappraise / savor
判定：⚠️ 这是【**设定者裁定层**】的决定（傲娇被戳更疼），权威**高于**本条文献意见 —— 见 `docs/07-证据分级与裁定权.md`
补法【诚实标注】：在 tsundere/engine 里注明"g_负>g_正 属设定者裁定，文献在此只作对照"；
      或补一个 savor（回味）通道走正性
```

### B8 μ 漂移速率的上界标定

```
引擎：mu.js 的 drift() 里 maxDrift=0.35（幅度上限），速率默认 0.02/次 —— 无"每轮/每天"标定
文献：nihms 的 EMA —— 人类 PA/NA 在 60 天内都不显著漂移（p=0.10 / p=0.84）
补法：把 rate 换算成"60 天量级看不出漂移"，作为默认值依据
```

### B9 跨维耦合（PAD 三轴不是独立的）

```
引擎：三轴各自独立（signature 只给符号），无耦合
文献：ToM 的 fi = wi·xi + Σ wji·xj + f_input，权重分段常（wji = w+ji if xj>0 else w−ji）
补法（可选）：加 3×3 分段常数耦合矩阵，保持局部线性以免破坏 A1 的 χ² 封顶分析
```

### B10 第二条持续性通道（记忆流）

```
引擎：持续性只有 ρ（指数回落）
文献：genagents —— memory stream：recency（指数衰减 0.995）+ importance(1–10) + relevance(余弦)
      ⇒ "同一件事反复被想起"这条路径纯 ρ 做不到
补法：与 #1（记仇/记爱/记恨）合并考虑 —— 这正是 μ 漂移之外的第二个慢通道
```

### B11 中性类**吸收态**警告

```
文献：EmoChat 自陈 "neutral can be transferred to or from any other emotion categories,
      thus the context information bring confusion" —— 中性连通一切会吸走并污染邻类
引擎：appraisal.js 的 classifyDirection() 里 relevance<0.15 → ΔE=0（这是【设计】不是 bug，但同构风险在）
补法：给"无情感意义"加计数/审计输出，长对话里若占比过高要报警
```

```
我们的辩护：我们【不做】文本→三维回归，而是 LLM 评价（语义层）+ 599 词概念先验；
      该批评针对【分类器式的维度识别】，不针对评价层结构
判定：✅ **已写入 `docs/03-文献依据.md`**（新增「必须正面回应的反面意见 —— ELMO」一节）
```
