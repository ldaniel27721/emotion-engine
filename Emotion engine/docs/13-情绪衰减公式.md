# 13 · 情绪衰减公式 v1 —— 把「情绪衰减」与「记忆衰减」糅合

> **立此文档的原因**（设定者 2026-10-13）：
> 「因为情绪衰减它也有公式理论，但是如果在这个理论上套用记忆衰减理论，
>  那就可以糅合两个公式变成我们自己的情绪衰减公式，**专门针对情绪模型的**。」
>
> 复现脚本：`demo/derive-emotion-decay.js`

---

## 一、两个公式，本来是同族的

**情绪衰减（本引擎 A2 · `dynamics.js`）：**
```
E_t = μ + ρ(E_{t−1} − μ) + g·h(n)·ΔE
  ⇒ 展开：E_t − μ = Σ_i ΔE_i · ρ^(t − t_i)
  ⭐ ρ = 0.927 是【全局常量】—— 所有历史事件共用同一个衰减率
```

**记忆衰减（SuperMemo / Wozniak et al. 1995）：**
```
R = exp(−Δ / S)
  ⭐ S 是【逐事件】的（每条记忆有自己的稳定性）
```

**⭐ 关键观察 —— 两者本来就同族：**
```
ρ^Δt = exp(Δt · ln ρ) = exp( −Δt · (−ln ρ) ) = exp(−Δt · λ)

   λ = −ln(ρ) = −ln(0.927) = 0.075802
   ⭐ 等价稳定性 S = 1/λ = 13.192 轮

核对：ρ 的半衰期 = 9.144 轮 ｜ S 的半衰期 = 9.144 轮  ⇒ ⭐ 一致
```

**⇒ 所以 A2 与 SuperMemo 只差一件事：ρ 是"全局"还是"逐事件"。**

---

## 二、⭐ 糅合公式

```
【情绪衰减公式 v1】

   E_t − μ  =  Σ_i  ΔE_i · exp( −(t − t_i) / S_i )

   其中：
     ΔE_i        = 第 i 个事件的冲击        （评价层产出 —— A2 的现有部分）
     S_i         = 第 i 个事件的【情绪稳定性】
                   = S0 · (1 + k · intensity_i)
     t_i         = 事件发生的轮次
     intensity_i = 该事件的情绪强度          （评价层产出）

   ⭐ 等价写法：每个事件有自己的 ρ_i = exp(−1 / S_i)
```

**⭐ 与原 A2 的【唯一】差别：**
```
A2:  ρ     是【全局常量】
v1:  ρ_i   是【逐事件】的，由该事件的情绪强度决定
```

---

## 三、⭐ 数值验证：A2 是 v1 的特例

**取 `S0 = 1/λ = 13.1923`、`k = 0`（强度不影响稳定）时，v1 必须精确退化成 A2。**

```
三个事件：[@轮1 ΔE=+0.5] [@轮4 ΔE=−0.3] [@轮7 ΔE=+0.8]，算到 T=12

  v1(T=12) = 0.6012345318
  A2(T=12) = 0.6012345318
  差       = 1.110e-16        ✅ 精确退化
```

**⇒ ⭐ A2 是 v1 在「所有事件情绪强度相同」时的特例；v1 是它的推广。**

---

## 四、⭐⭐ 强度不同时的行为（同样大的冲击）

**两个事件，`ΔE` 大小相同，强度不同，都在第 1 轮：**

```
事件 A   intensity = 0.1  ⇒ S = 59.18
事件 B   intensity = 1.0  ⇒ S = 211.35
```

| Δ轮 | A 的残余 | B 的残余 | B/A |
|---|---|---|---|
| 0 | 1.0000 | 1.0000 | 1.000 |
| 10 | 0.8445 | 0.9538 | 1.129 |
| 20 | 0.7132 | 0.9097 | 1.275 |
| 40 | 0.5087 | 0.8276 | 1.627 |
| 60 | 0.3628 | 0.7528 | 2.075 |
| 100 | 0.1846 | 0.6230 | 3.376 |
| 150 | 0.0793 | 0.4918 | **6.203** |

**⭐ 同样大的冲击，强情绪的那份留得久得多 —— 而这正是"情绪衰减"该有的样子。**
**⚠️ 单一 ρ 做不到这件事（它对所有事件一视同仁）。**

## 五、⭐⭐⭐ 一个重要的实现含义

```
⚠️ 变成 v1 之后，【递推写法不再适用】

   原 A2：E_t 可以由 E_{t−1} 递推（因为衰减率全局一致）
   v1：  每个事件的衰减率不同 ⇒ 不能只留"上一轮的 E"
         ⇒ ⭐ 必须保留【事件账本】

⇒ ⭐⭐ 所以「情绪记忆账本」从【附加模块】变成【引擎的必需组件】！
```

**一份账本，两用：**

```
┌──────────────────────────────────────┐
│  情绪事件账本（每轮写入一条）           │
│  { turn, at, summary, emotion,        │
│    intensity, S, ΔE }                 │
└───────────┬──────────────┬───────────┘
            │              │
            ↓              ↓
   ┌────────────────┐  ┌────────────────┐
   │ ① 算出当下的 E   │  │ ② 注入给 LLM    │
   │    v1 的求和     │  │    按残余排序    │
   └────────────────┘  └────────────────┘
```

**⇒ ⭐ 两个模块从"并行"变成"同一件事"。**

## 六、三个层次的关系（理清）

| 层 | 公式 | 管什么 | 参数 |
|---|---|---|---|
| **ρ**（A2 现状） | `E 按 ρ^Δt 回落` | 混在一起的一团情绪怎么散 | 全局常量 |
| **R**（记忆衰减理论） | `R = exp(−Δ/S)` | 单条记忆/单条情绪的残余 | S 逐事件 |
| **⭐ v1**（糅合） | `E−μ = Σ ΔE_i·exp(−Δ_i/S_i)` | 每个历史事件各自剩多少，合成当下情绪 | S 逐事件 |

**⭐ v1 = 用逐事件的 S 取代全局 ρ；A2 是它强度全同时的特例（已数值验证）。**

**⚠️ 而 `ρ` 的角色要重新理解：**
```
ρ = 0.927 不是"情绪的衰减率"
而是"当所有事件的情绪强度相同时，那个共同衰减率" ——
⭐ 它是 v1 的【平均场近似】
```

## 七、与既有裁定的相容性

| 既有裁定 | 与 v1 的关系 |
|---|---|
| **A1 球面约束** | ✅ 封顶仍作用在合成后的 `r = ‖E − μ‖` 上，不变 |
| **A3「μ 是收敛终点」** | ✅ v1 里 `Σ ΔE_i·exp(...) → 0`，仍收敛到 μ |
| **B4「ρ 与 h(n) 是两根轴」** | ✅ 不冲突 —— `h(n)` 作用在 `ΔE` 的写入上（事件轴），`S_i` 作用在衰减上（强度轴）|
| **B1「ρ 按效价分段」** | ⭐ v1 里可以并存：`S_i = S0·(1+k·intensity_i)·trait(效价)` |
| **docs/12「情绪记忆」** | ⭐⭐ 从"附加模块"升级为"必需组件" |
