# 案例 · 桑多涅是不是傲娇

> **案例日期**：2026-10-12
> **证据来源**：`quest_script.txt`（Yatta 剧情对照 EN/CHS，287,161 行 / 1,737 章）
> **判定对象**：「木偶」桑多涅（Sandrone）· 愚人众第七席
> **判定依据**：`04-傲娇机制.md` 的四条判据 + 设定者 2026-10-12 的裁定

---

## 一、为什么用这个案例

粉丝维基（the-dere-types）把 "Tsundere" 定义在**恋爱对象**上：

> *"…has loving **deredere** feelings for their **love interest**…"*

而桑多涅对哥伦比娅是**同伴关系**，不是恋人 —— 所以按 wiki 的字面定义，她**不该被算作 tsundere**。

**⭐ 这个案例就是用来检验：wiki 的定义是「本质」还是「一个特例」。**

---

## 二、证据：游戏原文

### 证据 1 · ⭐⭐⭐ 内心独白与说出口的话**直接对立**（最强）

游戏用**括号**表示内心，**无括号**表示说出口。桑多涅在同一处出现对立：

**【76225】茶会的再邀·哥伦比娅**
```
[「少女」] 谢谢你的茶，桑多涅。我喜欢和你一起度过的时光。
[「木偶」] （再这么坐一会儿吧。）      ← ⭐ 内心：还想再坐一会儿
[「木偶」] 茶会时间该结束了。          ← ⭐ 嘴上：说该结束了
```

**【74248】故事乃最好的茶点** —— 同一句出现两次
```
[「木偶」] （再这么坐一会儿吧。）
[「木偶」] 茶会时间该结束了。
```

**⭐ 这不是推断，是文本写明的「里层/表层分离」。**

---

### 证据 2 · 夸了但用行为否定（【76035】她的过去）

哥伦比娅回忆：
```
[「少女」] …她说我唱得很好听，但那时我加入「愚人众」不久，
           她说其他人听到我唱歌有时会紧张。
[「少女」] 啊，还有一个原因。她说自己晚上基本都在搞研究，
           白天我唱歌会碰上她补觉的时间。
[旅人] （这才是主要原因吧！）
[「少女」] …后来我就只在晚上到桑多涅门口去唱歌。但还是被她赶走了…
```

```
内部评价 = 「唱得很好听」        ← 里层（正面，说出来了）
外部行为 = 不让唱 / 赶走         ← 表层（否定）
⭐ 而且给了【两个理由】—— 一个体面的（别人会紧张）、一个真实的（她要补觉）
```

**⭐ 注意：`s` 不是 0** —— 她能说出"唱得很好听"这个**评价**，
但说不出"我想听你唱"这个**意愿**。**里层的"评价"可泄露，里层的"需要"不可。**

---

### 证据 3 · 否认动机（【76125】无人的庭园）

哥伦比娅失踪后：
```
[「木偶」] ……
[派蒙] 桑多涅！你怎么会在这里？
[「木偶」] 随便出门散散心不行吗？              ← ⭐ 否认动机
[旅人] 她没有回来。
[「木偶」] 我想也是。
[「木偶」] 奇迹怎么可能没有代价呢。
[派蒙] …好不容易遇见了，要不要再一起走一段？
[「木偶」] 算了吧，今天心情不好，说出来的话不会好听。   ← ⭐ 拒绝但给理由
[「木偶」] 而且我看，这里最不需要的就是安慰。           ← ⭐ 在压自己的需要
```

```
⭐ 行为暴露：她出现在【哥伦比娅失踪的地方】
⭐ 言语否认：「随便出门散散心」
⭐⭐ 拒绝同行时给了【理由】（为对方考虑），不是单纯冷淡
⭐ "这里最不需要的就是安慰" —— 她在否认自己需要安慰
```

### 证据 4 · 替她担心却用抱怨的口气（【77668】冬夜，淑女，茶会）

```
[「少女」] 嗯…桑多涅，能帮我再拿一个吗？
[「木偶」] 你注意下吃相…                         ← ⭐ 嘴上嫌弃，行为照顾
```

```
[「木偶」] 哼哼，这不是挺适合你的吗？而且很有趣。      ← 给哥伦比娅写"很坏很坏的吸血鬼"
[「木偶」] 随你便，让我看看你写的——
```

## 三、判据检验

| 判据 | 结果 | 依据 |
|---|---|---|
| **① intentional（故意的）** | ✅ 成立 | 挑理由、刻意说反话、给两个理由 |
| **② 对象特定** | ⚠️ **见第四节** | 对象确定是哥伦比娅，但**不是恋爱对象** |
| **③ 区分真实感受与公开形象** | ✅✅ **最强** | 括号内心 vs 说出口的**直接对立** |
| **④ 在 tsun / dere 间切换** | ✅ 成立，但 dere 侧**极隐蔽** | 只靠**行为**泄露，从不明说 |

## 四、⚠️ wiki 定义的限制与修正

### wiki 的原判据

```
① intentional
② towards their 【love interest】     ← ⚠️ 限制在这里
③ 区分真实感受与公开形象
④ 在 tsun / dere 间切换
```

### ⭐ 设定者裁定（2026-10-12，逐字）

> 「这就是那份 wiki 的限制之处，我个人感觉**傲娇对象并非恋爱对象**，
> 他是一种**人格特质**，是一个**对人事物的反馈路径**，所以这里你可以不听 wiki 的限制太死了」

### 修正后的判据

```
① intentional（故意的，不是失控）
② 对【在意的人 / 事 / 物】            ← 由"在意程度"调制，不绑定恋爱
③ 区分真实感受与公开形象              ← 核心，保留
④ 在 tsun / dere 间切换
⑤ ⭐ 是一种人格特质 = 对人事物的【反馈路径】
```

### ⭐⭐ 这个修正**去掉了不自洽的地方**

```
wiki 观察到「只对喜欢的人冷」——
  但机制上【为什么】？

⇒ 因为只有对在意的人，才有"怕被看穿"的问题。

⭐⭐ 所以"对象特定"不是独立条件，
   它是【在意程度】的一个特例。
```

## 五、引擎参数

```js
const sandrone = new Tsundere({
  subtype: ['Tsundora'],   // 冻原型（s₀ = 0.10，「a higher state」）
});
sandrone.setAttachment(0.55);   // 同伴级在意
sandrone.apply('unobserved');   // 无人在场
// ⇒ s = 0.157  —— 极强抑制，与文本一致
```

| 参数 | 值 | 依据 |
|---|---|---|
| 亚型 | `Tsundora` | 极冷淡、看不出 dere（"a higher state"） |
| `s₀` | 0.10 | 亚型默认 |
| 在意度 | 0.55 | 同伴/朋友级 |
| 泄露通道 | `action` | ⭐ **行动泄露**（出现在庭园、带点心、担心她见女皇） |
| dere 侧表达 | 几乎无言语 | 全靠行为 |

**⭐ 她的泄露通道对应 wiki 的 `Tsun-Ama`（甘え）型：**
> *"…will act like they don't care while at the same time doing everything in their power
> to make their love interest happy"*

## 六、这个案例带来的三个发现

### 发现 1 · ⭐⭐⭐ 「里层/表层」有**直接的文本证据**

游戏用括号表示内心、无括号表示说出口。桑多涅在两处出现**直接对立**：

```
（再这么坐一会儿吧。）   vs   "茶会时间该结束了。"
```

**⇒ 我们模型里的 `E_inner` / `E_outer` 不是类比，是有文本对应的。**

### 发现 2 · ⭐⭐ 「对象特定」应抽象为「在意程度」

```
wiki 的条件（对恋人） → 只是"在意程度高"的一个特例
⇒ 引擎里改为连续量 attachment ∈ [0,1]
   对象偏移 = −0.35 × 在意程度
   ⭐ 越在意 → 越怕被看穿 → s 越低
```

**⭐⭐ 而且 attachment 的来源是【记忆】—— 与 μ 的慢漂移同源。**

### 发现 3 · ⚠️ 「无观众」与「两人独处」是两个状态

```
场景「无人的庭园」：哥伦比娅失踪、无人在场
  若按 alone（两人独处，+0.55）算 ⇒ s = 0.458（中等抑制）—— 与文本不符
  ⭐ 修：拆成
     alone      两人独处（对象在场 + 无观众）  +0.55
     unobserved 无人在场（对象可能也不在）      +0.25
  ⇒ s = 0.157 —— 与文本的极强抑制一致
```

## 七、结论

```
⭐ 桑多涅是傲娇，但属于「结构成立、定义超出」的那一类。

✅ 核心结构完全成立:
     里层: 关心 / 正面评价（"唱得很好听"）
     表层: 冷淡 / 否认 / 抱怨
     泄露: 靠【行为】—— 出现在庭园、带点心、担心她见女皇、给角色卡

⚠️ 与 wiki 的偏差（已被设定者裁定覆盖）:
     ① 对象不是恋爱对象 —— ⭐ 修正为"在意程度调制"
     ② dere 侧极隐蔽 —— 更接近 Tsundora
     ③ "傲"的成分弱 —— 她不是高傲，是【闷】

⭐ 用引擎的话说:
     亚型 Tsundora · s₀ 0.10 · 在意度 0.55 · 泄露通道 action
```

**⭐⭐ 对我们的意义：**

> **不做恋爱关系的陪伴型角色也可以有傲娇 —— 桑多涅就是官方给的反例。**
