## 一、A1 球体与正态互补

### 1.1 空间

情绪是三维 PAD 空间中的一点：

```
E = (P, A, D) ∈ ℝ³
    P = Pleasure  愉悦
    A = Arousal   唤醒
    D = Dominance 支配
```

### 1.2 白化

```
y = L⁻¹ (x − μ)          L 为协方差矩阵的 Cholesky 因子
```

**理由** [文献]：Russell 1980 p.1171「rotation is considered arbitrary」；
P–D 相关实测 ≈ .34–.40，白化消除该相关。

### 1.3 方向与强度

```
γ = y / ‖y‖        方向（单位向量，落在球面）
r = ‖y‖            强度（到球心的距离）
```

### 1.4 量程：χ²(3)

```
r² / σ²  ~  χ²(3)
```

**含义**：强度落在球面附近的概率由 σ 决定。σ 是**角色参数**（"情绪化程度"）。

| σ | 1/σ² | χ²₃ 90% 分位对照 |
|---|---|---|
| **0.40** | 6.25 | 6.2514（≈ 精确对应 90 分位）|
| 0.45 | 4.94 | |
| 0.50 | 4.00 | |

### 1.5 ⭐ 对数封顶（本版新增）

```
f(r) = 1 − (1 + r)^(−k)     =  1 − e^(−k·ln(1+r))
                                 ↑        ↑
                           指数封顶    对数内核

k = 1/σ
```

**性质：**

```
f(0) = 0
f'(r) = k(1+r)^(−k−1) > 0          单调递增
lim(r→∞) f(r) = 1                   上确界 1，【永不到达】
f(r) < r   对一切 r > 0             恒为压缩，不放大
```

**为什么需要它：**

线性 AR(1) 的稳态强度是

```
r_∞ = |ΔE| / (1 − ρ)
```

取 `|ΔE| = 0.35`、`ρ = 0.927`（本引擎默认值）得

```
r_∞ = 0.35 / 0.073 = 4.79        ← 球面是 1，爆了 4.8 倍
```

即**稳态增益 `1/(1−ρ) = 13.7` 过大**。封顶把"球面"从一个**会被打破的阈值**
变成**渐近极限** —— 这反而更贴合原始设定「强度的极致就是球体的表面」。

**k 的作用**：k 小 → 曲线"扁"（很快接近 1）；k 大 → 低区近线性、高区才压。
**k 由 σ 挂接，故"情绪化程度"同时决定①平时波动多大 ②多快被压扁。**

**⚠️ 已知副作用**：`f(1) = 1 − 2^(−k) ≠ 1`，故封顶作用在**每轮累加时**，
而非重新定义球面。

## 二、评价层（两级）

### 2.1 为什么需要评价层

[文献] moors2013：

> *"there is a **variable relation between stimuli and emotions**, but a **stable relation
> between appraisals and emotions**"*

```
刺激 → 情绪：关系【可变】      ⇒ 不能由事件直接算 ΔE
评价 → 情绪：关系【稳定】      ⇒ ΔE 必须由评价算
```

### 2.2 一级评价

**输入变量**（AET p.31）：

```
goal relevance   相关性    ∈ [0,1]
goal congruence  一致性    ∈ [−1,1]
importance       重要性    ∈ [0,1]
```

**输出**：

```
valence   = congruence × relevance
intensity = importance × relevance
            × (1 + 0.5·(1 − expectancy))      ← 意外性调制
            × (1 + 0.3·currentArousal)         ← 既有唤醒调制
```

**依据** [文献] AET p.32：

> *"the **intensity** of the emotion is **directly correlated with the importance
> or desirability of the goal**"*

另加调制项 unexpectedness 与 existing arousal levels（同页）。

### 2.3 二级评价

**输入变量**（moors2013 五核心 + AET 补充）：

```
agency           施动者    ∈ {self, other, environment, none}
coping           应对潜力  ∈ [0,1]
certainty        确定性    ∈ [0,1]
expectancy       预期      ∈ [0,1]     (0 = 预期极坏, 1 = 预期极好)
intentionality   故意性    ∈ [0,1]
```

**输出**：12 方向类 → 八型

```
符合关切（congruent）:
   agency=other ∧ coping<0.55 ∧ intentionality>0.5  → Caring    → Dependent (+,+,−)
   agency=other                                      → Happiness → Exuberant (+,+,+)
   importance<0.35                                   → Calm      → Relaxed   (+,−,+)
   否则                                              → Happiness → Exuberant

阻碍关切（incongruent）:
   agency=self                                       → Remorse   → Anxious   (−,+,−)
   agency=other ∧ intentionality>0.6                 → Anger     → Hostile   (−,+,+)
   agency=other ∧ coping>0.6                         → Contempt  → Disdainful(−,−,+)
   agency=other（其余）                              → Hurt      → Anxious   (−,+,−)
   agency=none ∧ coping<0.35                         → Depression→ Bored     (−,−,−)
   agency=none ∧ certainty<0.4                       → Confusion → Anxious
   否则                                              → Depression→ Bored
```

**⭐ Dependent 这一条是本版新增** —— 它对应设定者说的**「软弱退化想被保护」**，
以及 wiki 的 `amae（甘え）= wanting to be spoiled`。

**变量数 ↔ 情绪数** [文献] moors2013 p.122：

```
"Two appraisal variables with two values each can account for four emotions."
⇒ 3 变量 × 2 值 = 8   ← 正是八型的 2³
```

### 2.4 精度门控

```
α = max( relevance × importance ,  (1 − certainty) × relevance )
```

**依据** [文献] barrett2016 p.15：只有被预期与**资源/生存/奖励/威胁**相关、
或**价值不确定**的误差才被学，其余当噪声忽略。

## 三、ΔE 的生成

### 3.1 乘法结构

```
ΔE = α × ε × signature
```

| 项 | 含义 | 来源 |
|---|---|---|
| `α` | 精度（门控） | barrett2016 p.15 |
| `ε` | 预测误差 | 见下 |
| `signature` | 胜出概念的情绪签名（八型单位向量，或词库中选中词的签名） | moors2013 Proposal 1 |

### 3.2 ε（预测误差）

```
expectedValence = (expectancy − 0.5) × 2          ∈ [−1,1]
ε = |valence − expectedValence| × 0.5 + 0.5·(1 − certainty)
```

**⭐ 三旋钮分解** [文献] topdown2025：

```
ε 可拆为三个正交项：
   起点项  = μ（先验）            只改 starting bias
   漂移项  = 显著度 / 注意增益      真知觉效应
   标准项  = 期望                  只改报告偏向
```

**⚠️ 反直觉坑** [文献] topdown2025 p.394：**期望不增强知觉，只增强"报告倾向"**。
若把「越期待越容易感知到」做成知觉增益，就错了。

### 3.3 signature 的两种取法

| 用法 | signature 来源 | 分辨率 | 稳定性 |
|---|---|---|---|
| **A（默认）** | 八型单位向量 | 8 个 | 高 |
| **B（增强）** | 词库中选中词的 PAD 签名 | 599 个 | 需选词 |

```
用法 B：ΔE = α × ε × signature(选中词)
⭐ 八型是词库的【粗粒度投影】（同一个卦限内还能区分不同词）
```

## 四、A2 情绪动力学

### 4.1 三层结构

```
E_t = μ + ρ(E_{t−1} − μ) + g(策略) · h(n) · ΔE
                                    ↓        ↓
                              策略缩放   习惯化
```

### 4.2 三种"变小"必须拆开 ⭐

| 机制 | 形式 | 时间尺度 | 依据 |
|---|---|---|---|
| **ρ** 自发回落 | `E 按 ρ^t 回 μ` | 半衰期 9.1 轮 `[工程]` | 纯净自发衰减，**不被任何个体差异预测** |
| **h(n)** 重复习惯化 | `ΔE × α^(n−1)` | 半衰期 9.6–17 次暴露 | `α ≈ 0.93–0.96` |
| **g** 策略缩放 | 一次性乘子 | 即时 | 间接回复使效价轴冲击 ×0.35 |

**依据（三批独立汇合）：**

```
衰减习惯化两篇:  ρ 是"唯一不被任何个体差异预测"的指标 (p = 0.415)
强度习惯化两篇:  习惯化速度也不由基线/特质预测
                （基线 anxiety BF₁₀ = 0.04 · excitement 0.12 · trait anxiety 0.55）
SMC2019:        习惯化速率 ∝ SpI/Sl —— 不是常数
```

### 4.3 反应增益 g_i（AET）

```
g_i = (g_正, g_负)     按 ΔE 在 P 轴上的符号选取
```

**依据** [文献] AET pp.38-39 引 Larsen & Ketelaar 1991：

```
高神经质 → 只对【负性】刺激反应
高外向   → 只对【正性】刺激反应
两者对【中性】都不反应
```

**⚠️ 不可用于建模"傲娇"** —— `g_正 = 0.5` 意味着"她对夸奖反应小"，
而傲娇的**里层感受是完整的**，"压"发生在表达层（见第七节）。

### 4.4 半衰期

```
t½ = ln(0.5) / ln(ρ)
ρ = 0.927  ⇒  t½ = 9.1 轮        [工程]
```

### 4.5 封顶

每轮累加后：

```
r_raw = ‖E_next − μ‖
r     = f(r_raw, k)               （见 1.5）
E_next ← μ + (E_next − μ) · (r / r_raw)     保持方向不变
```

## 五、A3 底情绪与原点

### 5.1 定义

```
μ = (方向, precision)

方向       = 底情绪落在哪个方向（用户配置）
precision  = 先验的确定性
```

**⭐ 角色底色 = μ 的【方向】+ μ 的【precision】**

### 5.2 几何含义

```
几何原点 (0,0,0) = 【中性】—— 不是任何角色的底情绪
μ = 球心 = 收敛终点 = 角色"没事时待的地方"
```

**约束：**

```
硬: ‖μ‖ < 1
软: r_μ ∈ [0.40, 0.50]
```

### 5.3 贝叶斯解读（precision 的作用）

```
后验均值 = (μ/var_prior + 事件/var_lik) / (1/var_prior + 1/var_lik)
var_prior = 1 / precision
```

| precision | 行为 |
|---|---|
| 低（1–2） | 先验容易被事件带跑 → 角色"随和" |
| 高（6–8） | 先验难被动摇 → 角色"固执" |

**⭐ 复现「自卑 → 受伤 → 怨恨」** [文献] topdown2025 Box 2 p.393：

```
μ 偏负 + precision 高 → 模糊事件被读成"受伤" → 继而"怨恨"
（"先验因不确定性更低而支配知觉"）
```

### 5.4 慢漂移（#43）

```
μ ← μ + rate · unit(Δ)         rate ≈ 0.02–0.04
上限：‖drift‖ ≤ 0.35
```

**⭐ 这就是「记爱 / 记仇 / 记恨」** —— μ 的慢漂移，不是 E 的快速波动。
**它必须由【记忆】承载**（μ 不在上下文里）。

## 七、表达层（傲娇）

> ⚠️ **本层的理论依据不在学术文献中。** 傲娇是亚文化圈的萌属性，
> 学术理论不支持其研究。定义来自 `the-dere-types` 粉丝维基 + 设定者裁定。

### 7.1 核心式

```
E_outer = μ + s · (E_inner − μ)

s = 抑制强度 ∈ [0,1]
```

```
s = 1  → E_outer = E_inner     不抑制，直说
s = 0  → E_outer = μ           完全抑制，只剩底情绪
```

### 7.2 s 的构成

```
s = clamp( s₀ + 状态偏移 + 事件累积 + 疲劳 )

s₀    角色常量（18 亚型各不同）
状态  场合（幂等，不叠加）:
        audience  −0.40    有他人在场
        alone     +0.55    只有两人独处
事件  一次性偏移（逐轮衰减 ×0.70）:
        calledOut +0.45    用户点到了心坎子上
        flustered −0.25    羞耻 / 慌
        impulse   +0.30    情绪冲动压倒抑制
        intimacy  +0.10    关系深化
疲劳  抑制越强，维持代价越大 → 疲劳累积 → s 上升
```
